# S3 盯防收尾 · ICE 霸榜 / BUG 垫底 · 2026-09-14

**问题**（synergy-flip-baseline-2026-09-14.md 的盯防项 2/3）：
羁绊翻开后 ①ICE（拉普拉斯独苗）随机局 62-70% 连续三个报告霸榜；
②BUG 43.7% 垫底——虫族是补偿型羁绊（弱单位深池），补偿未兑现。
**结论**：修法三条（冰 (2) 收紧 / 治疗衰减机制 / 虫群四档补偿），
`sim/experiment_balance.py` 健康线 **9/9 通过**：BUG 43.7% → **47.1%**、
ICE 合池 61.6% → **60.9%**（主种子 62.1% → 59.1%），既有成果零回退。

## 归因（修法前的因果分解，均为同种子同阵容对照）

1. **随机局 ICE 读数与羁绊无关**：把水治疗整体清零（WATER 表改空），
   ICE 62.1% → 63.6%、WATER 51.2% → 50.8%——都在噪音带内。拉普拉斯
   队伍按 WATER 档位分桶：有水羁绊 74.2%、无水羁绊 50.0%，但清零治疗后
   该分桶纹丝不动——74% 是**组合质量**（第二只水系=又一个水炮同伴），
   不是羁绊喂养。拉普拉斯在 18 只 T3 的「在场胜率」仅第 15（62.7%；
   暴鲤龙 84.1%/雷伊布 80.6%/快龙 77.9% 才是单位质量前三）。随机局 ICE
   读数 = T3 在场信号 + 水炮同伴组合，剩余部分归 S4 单位强度（同 S3 §7.3
   对虫的口径）。另：拉普拉斯实为**近战**（SpA 85 = Atk 85，roster 判定
   SpA>Atk 才远程）——翻牌基线里「远程高坦度」的记载有误。
2. **治疗的喂食通道在定向局**：随机局 WATER(2) 治疗被 `max(1,int(...))`
   地板钳成 ~1HP/s（无关胜负）；真正的喂养是全 T3 水队——冰偏置队
   （拉普拉斯×2+水箭龟/宝石海星/水伊布/暴鲤龙，全 3 费）把 WATER(6)
   1.5%/s 吃成六只高血量旗舰的续航（S3 记录：2.4%/s 时喂到 96-98%）。
3. **BUG 垫底 = (2) 起步补偿落空**：按队伍虫数分桶胜率 x0 55.3% →
   x1 44.8% → x2 43.6% → x3 26.5%——每带一只虫约 -10pp，而 78% 的虫登场
   发生在单虫队（x1），(2) 起步对它们是零补偿。旧 (2) 攻速6%+伤害3%
   与深池平效区的飞 (2) 攻速6% 几乎同档，补偿语义名存实亡。

## 修法（全部落在 sim/synergy.py，机制优先于数值）

| # | 修法 | 说明 |
|---|---|---|
| 1 | 冰 (2) 减伤 4% → **2%** | S3 §5 盯防条款的处方动作（触发条件已满足）。堵双拉普拉斯队 WATER(6)+ICE(2) 套利；(4)(6) 扩池预留不动 |
| 2 | **治疗衰减** `HEAL_TIER3_MULT=0.5` | heal 类羁绊效果对 3 费旗舰减半、1/2 费全额（apply 内按 `u.piece.tier` 缩放）。理由：治疗按「存活价值×血量」放大，天然偏向高血量旗舰；羁绊的补偿语义是抬弱单位不是喂强势单位。**不砍数值**——随机局治疗本来就无关胜负，砍数值只会误伤普通水队 |
| 3 | **虫群围猎 (1)(2)(4)(6) 四档** | (1) 攻速5%+伤害3%（补偿从第一只虫开始）；(2) 攻速10%+伤害5%+**HP12%**（实测 HP 档比纯攻速/伤害更抬虫队：虫是近战肉盾位，多挨一刀就是价值）；(4)/(6) 顺势放大并加治疗。档位阶梯表内自定义（`tier_of(count, key)`），其余 16 系仍全局 (2)(4)(6)，向后兼容 |

数值探路记录（合池 3 种子×1000）：纯 (2) 强化封顶 44.8%（(2) 攻速12+伤害8，
比电系旗舰 (2) 还大）——够不着 47%；(1) 档 + HP 档组合才兑现
（(1)s5+d3 单虫队 44.8% → 47.8%）。虫的 (1) 档与冰阈值单独上调（§5 条款）
同属**档位表内自定义**的先例延伸，不破坏「档位取最高档、数值为总值」语义。

## 不回退自查

- `python3 sim/prototype.py --games 300`：确定性自检通过；A/B **147:153**
  （基线 167:133，回到噪音带）；BUG 43.7% → **50.0%**；ICE 70.4%(n=27) →
  56.2%(n=16)；带宽 26.7pp → 11.9pp。
- `python3 sim/experiment_synergy.py --games 300`：原健康线全部保持——
  带宽关 15.9% → 开 **12.9%**（收窄）、水vs岩 100% → **89%**（大招单发
  中位 51 = 40%×142HP×(1-8%) 承伤上限生效）、冰偏置 vs 散羁绊 **86%**
  不走高、ICE 开臂 60% 不走高、羁绊开确定性自检通过。
- 两臂同种子同阵容序列（comp_rng 独立 + 逐场派生战斗种子，方法与
  experiment_synergy 同构）。

## 遗留与移交

1. **ICE 随机局残值 ~60%**：即「T3 在场」读数，羁绊侧可关的路径已全部
   关上；若要继续压，须动 roster/定价（S4 职责，本任务禁改 roster.py）；
2. **拉普拉斯是近战**（翻牌基线记载有误，已在本报告纠正）；
3. 虫 (4)/(6) 与冰 (4)/(6) 一样当前不可达，扩池激活即重测；
4. 治疗衰减常数 `HEAL_TIER3_MULT` 影响 GRASS/BUG 的治疗档同理（对位
   读数未受扰动，合池各系均在带内）。
