# 技能特效的基础审美与制作规范

本规范用于 PokeTactics 竞技战场及全部配套预览。原版招式参考解决“这是什么动作”；体积、材质、层次和节奏解决“这个动作好不好看”。两者必须同时具备。每轮增加技能都先填写本文末尾的制作卡，再在实际页面尺寸检查动态样片。

## 1. 五项共同标准

| 标准 | 应当看见什么 | 常见问题与修正 |
|---|---|---|
| 主轮廓 | 关闭名称后仍能看出水、角钻、刀击或治疗 | 只剩线条时先补实体轮廓，不能用更多线条补体积 |
| 明暗体积 | 暗侧、主体、受光面和少量最亮点，至少三级明度 | 满屏同亮度会显平；大块纯白会遮住角色 |
| 材质运动 | 水边缘翻卷，钻纹绕轴旋转，花瓣轻飘，治疗向内聚亮再上升 | 同一轨迹换颜色无法区分材质 |
| 力度节奏 | 蓄力收拢 → 释放加速 → 接触压缩 → 余波舒展 | 每帧一样大或持续贴一个符号，会丢失冲击感 |
| 结束形态 | 水面碎成泡沫水滴，硬物变碎屑，光晕分解成星光 | 不把所有尾段统一成直射线、十字或圆圈 |

“大气”来自主形明确、明暗关系和收放，不是把粒子数量、亮度和覆盖范围一起拉满。治疗的舒展和角击的硬接触必须有不同节奏。

## 2. 按实际可见尺寸设计

检查基准是实验室约 **620px宽** 的战斗画面；960px原始画布仅用来检查细节。当前角色在该视图约40px高，像素轮廓缩小后仍须清楚。

- 主体保持一个清楚的视觉中心，少量辅助片段围绕它运动。
- 双水炮要能分出两处炮口。每股水体在页面上有可见宽度和起伏，不成为两条蓝激光；窄处仍连通，宽处有翻边与白沫。
- 角钻可采用约20×35px的斜向锥体作为起点。根部圆润、前端尖锐、螺纹绕轴，旋转时高光和遮挡关系变化。
- 主命中余波可舒展到约1.5–2.5个角色宽，最饱满的画面短促出现，随后分解。扩大视觉不增加真实攻击范围。
- 治疗主体环绕约1.3–1.6个角色宽，2–3颗主星在页面上约6–10px，小星为辅；避免只增加肉眼看不见的小点。
- HUD、HP、能量和数值保持最终层。半透明光不能把角色抹成白影，密集战斗也必须能辨认目标。

这些尺寸是美术起点，不是对所有技能强行使用同一半径。

## 3. 材质设计配方

| 类型 | 原版参考锚点 | 实体与边缘 | 动作 / 收尾 |
|---|---|---|---|
| 水柱、水炮 | 水炮、潮旋、冲浪 | 连续填充水体；不等宽轮廓、螺旋受光纹、局部翻卷白沫 | 水纹向前输送；接触形成厚浪唇，弯曲展开，最后成为泡沫与水滴 |
| 角突、钻击 | 角撞、超级角击、角钻（尖角钻） | 圆底尖端的锥体；暗背面、弧状螺纹和旋转高光 | 提速前刺，接触面受压后弧形张开，碎屑沿曲线散开 |
| 治疗 | 自我再生、生蛋、原版 HealingEffect | 柔和的局部明亮区、错层恢复环、大星与小星 | 先聚亮，再环绕向上升起，光环逐步打开与变淡 |
| 能量光束 | 日光束、冰冻光束 | 亮芯与较暗外层，可有脉冲和小侧向光屑 | 发射与命中保持连贯；纯能量可笔直，有实体的水流不能只复制光束换色 |
| 岩石与金属 | 岩崩、岩石封锁、铁尾、金属爪 | 硬边与明暗平面，碎块有大小关系 | 短促压入／坠落、反弹、碎裂；避免巨大长期图章 |
| 火焰 | 大字爆炎、火焰轮、喷火 | 暗橙外焰、明亮火芯、非对称火舌 | 翻卷上扬、闪烁断裂、带亮头的余烬；保留已确认的大字爆炎基准 |

参考来源与48招对应关系维护在 [36 · 原版招式参考](36-native-pixel-skills.md)。改变参考时补上固定源码入口与观察记录；不得只写一个招式名却不核对其动作。

## 4. 基础能力落点

- `retro_primitives.py`：像素坐标、有限色、局部绘制、有限粒子等基础工具。
- `retro_water.py`：有轮廓的水体、曲面水浪、水旋和低位水迹，供水属性主技能与真实位移反馈复用。
- `retro_physical.py`：立体角钻、曲面冲击、硬质碎片与近战分招编排。
- `retro_support.py`：治疗聚亮／环绕／上升、透明光壁，以及真实辅助效果接收者。
- `retro_feedback.py`：真实扣血触发的身体压缩与局部调色；冻结和死亡优先。
- `web_battle.py`：权威事件、位置、发射锚点与图层组织。竞技试玩、实验室、编辑器和导出共用，不单独给截图做一套效果。

复用的是材质和形状构造能力，不把所有招式合并成同一个特效。水炮、潮旋、治疗都有独立的阶段编排。

## 5. 每招制作卡

新增或修改技能时记录：

1. 当前技能、目标类型与真实副效果；原版参考的固定版本、入口及动作观察。
2. 轮廓关键词（例如“双股厚水柱＋翻卷浪面”）和主要材质，限制在一两个主视觉。
3. 蓄力、释放、接触、收尾各一个关键姿态，说明形状怎样变化。
4. 源端附件、目标位置和持久状态的事件来源；零伤害、零治疗、吸盾和死亡如何表现。
5. 620px动态样片及四阶段联系图，包含主目标和真实副目标；纯图层与实际战场都要看。
6. 复核结论、发现的问题及修正。记录剩余差异，不用“有像素、有颜色”代替视觉判断。

## 6. 验收顺序

先看 **正常速度的动态**，再看关键帧：能否看清发动者、受击者、材质和力度。随后检查0.5×、逐帧与回退采样；确认没有命中提前、接触后重新发射、阶段切换重置或尾迹突然变成另一种形状。

再看6对6：角色、HP与主要落点是否还清楚。遇到拥挤，优先减少次要碎片与残影，不能删除主体、真实受击或数值。最后执行时序、寻址、缓存、透明度与有限生命周期检查。

当前通用粒子计数不包含手绘材质，不能用“计数为0”推断开销为0。记录本机渲染帧耗时，并注明采样场景和分辨率；不据此宣称设备性能通过。

逐招复核要保留清单：物种与技能、原版入口、实际观察到的问题、具体修正或保留理由、复核结论和样片。不能用“全名单能够渲染”代替审美结论，也不要求没有问题的技能为了覆盖率而重画。同属性技能应横向比较：雷链、落雷与电球；岩钉、震波与岩崩；歌声、铃声与风旋，要有各自的主轮廓和动作节奏。

当前完整清单：[48 个原生技能逐招复核](../reports/all-skills-vfx-review-2026-10-07.md)。

持久地形也属于技能画面。岩钉使用贴地裂纹、错落的硬质岩面与少量碎石；阵营标识保留在地面短标记，避免实心椭圆底座遮住格子或看起来像保护罩。地形只读取实际布场与清除事件，瞬态落石不能额外生成持久岩钉。
