# 竞技羁绊与构筑成型

本版先降低基础玩法的成型门槛，不增加新的独立资源或养成系统。宝可梦的本命技能决定个人特点，羁绊连接队伍，装备与技能机选择分支，海克斯提供更强的收益或额外转化。没有抽到指定海克斯，仍应能用基础阵容完成一次有意义的配合。

## 羁绊计数与作用范围

竞技规则使用独立的 `arena_bonds`。只数上场的不同宝可梦种类，同种重复上场、星级、备战席均不增加计数。已激活属性羁绊只作用于对应属性的成员，战术羁绊只由对应战术成员触发。两者可以同时存在。

属性门槛按当前48种竞技池调整：火为2/3，钢和恶为2，冰、幽灵、龙为1，水、一般、毒、地面为2/4/6，其余属性为2/4。单成员属性的1档是轻量专长；重复上场无法继续升级。竞技不再触发按旧属性数量判定的隐藏开场齐射；经典模式继续使用原有属性羁绊、计数方式与齐射。

四种战术采用2/4档。一只宝可梦最多携带两个战术标签，例如喷火龙和尼多王同时能走侵蚀与连击，但实际投入装备、队友和站位会改变它们的收益。

| 战术 | 2档 / 4档 | 成员与搭配方向 |
| --- | --- | --- |
| 侵蚀 | 同一来源对同一敌人造成3次真实灼伤或毒伤后，来源回4/8能量 | 喷火龙、尼多后、尼多王、毒刺水母、火暴兽、千针鱼；持续施加异常，靠保护延长输出时间 |
| 连击 | 同目标有效普攻每层提高5%/8%行动速度，最多3层 | 喷火龙、雷丘、尼多王、怪力、飞天螳螂、大尾立、巨钳螳螂、赫拉克罗斯；前排与援护保护连续攻击 |
| 守护 | 成员因直接命中从半血以上降至半血或以下时，获得最大生命8%/12%的盾，持续3秒，每战一次 | 尼多后、皮可西、风速狗、隆隆岩、魔墙人偶、拉普拉斯、月亮伊布、大钢蛇；盾争取治疗或反击的时间 |
| 鼓舞 | 成员本命技能有效治疗、净化或回能其他队友后，受益者直接伤害提高10%/15%，持续3秒 | 妙蛙花、巴大蝶、胖可丁、宝石海星、大竺葵、猫头夜鹰、电灯怪、幸福蛋；不同辅助以不同方式打开攻击窗口 |

侵蚀要求实际扣除生命、来源仍存活；同一原目标每战一次，来源冷却4秒、最多3次，传播产物不继续触发。回能只记录实际增量。连击转火或4秒没有有效普攻清层，完全被盾吸收、闪避、技能与持续伤害不叠层。守护不由持续伤害触发，不复活致死目标，不覆盖更强护盾；护盾仍通过原有吸收账本结算。

鼓舞只响应对其他队友的实际本命援护，不响应空治疗、空净化、满能量、自身援护、被动或技能机；受益者冷却5秒、最多3次。与海克斯充能鼓舞的25%增伤取较强值，不相加；海克斯仍要求他人本命的真实回能。较强窗口结束后，尚未到期的较弱窗口仍可生效。

## 基础启动与进阶选择

搭配目录分为基础启动、可替换成员、装备／教学升级和可选海克斯。基础启动说明当前不依赖指定海克斯的技能配合；依赖海克斯才能成立的转化会单独标明条件，不把高级效果冒充为无条件效果。

六条进攻路线额外提供1费过渡：尼多后＋千针鱼先玩侵蚀，雷丘＋怪力先玩连击，胖可丁＋电灯怪＋雷丘先玩鼓舞援护。高费核心到手后再换入，装备可以卸下转移；过渡阵容不默认拥有高级装备或海克斯效果。

例子：雷丘和怪力可先组成2连击，搭配胖可丁续航，依靠真实普攻积层。以后给输出携带节拍器，提高连续攻击的成长幅度；或换爆发装备，并加入电灯怪与另一位鼓舞辅助，转向援护窗口内的输出。同一只精灵保留一个装备位和一个学习位，分支之间仍有机会成本。

四个无存档预览使用正常解算、不同低费精灵和三排站位，双方均不装备道具、不学习技能、不选择海克斯：

## 第3、6轮组件补给

每个实际参加第3、6轮战斗的训练家，各获得额外一次8选1组件补给，胜、负、平相同。原有随机战利品仍为胜利2份、失败或平局1份，组件补给独立记录。

玩家可在之后任意准备阶段领取，也可暂存，不要求领取后才开战。机器人同额获得一个组件，优先补齐可合成配方，同分用独立种子选择。玩家淘汰或整局结束时，未领取补给关闭，不自动代选。重复读取、回放和相同领取请求不重复发放；改选、无效选项、战斗阶段或终局领取会被拒绝。

旧存档只从恢复时尚未结算的轮次开始适用，不追溯补发过去的第3、6轮。阵容、仓库、海克斯、普通战利品和历史战果保留，未来战斗使用新羁绊。

## 是否再增加一个系统

现阶段先不增加。已有本命技能、属性与战术羁绊、装备、技能机、海克斯、站位和地形，需要先让玩家能看到、凑出并验证这些组合。

下一步优先观察：前期能否用不同成员启动同一玩法、换装备能否保留核心并改变输出节奏、未拿指定海克斯的队伍能否运作、玩家是否能从战报辨认关键收益。之后若仍缺少同种宝可梦的分支，可以深化“特性”的互斥选择，例如异常延长与首次施法加速二选一，仍占用同一个选择机会，并沿用已有事件和账本。当前竞技特性尚未形成完整系统，本版不提前实现或承诺该机制。

重点是让新选择改变战斗方式。单纯叠百分比、再增加一条随机抽取资源，容易提高成型难度，却未必增加有意义的组合。
