配方修订（2026-09-14 平衡修订，sim 读数定案，详见平衡报告）：
- 幸运蛋改拿「头带+贝壳铃」（原表与剩饭撞车，v1 已裁）；
- **天气石：伤组件+硬石（3 对）→ 硬石×2 / 磁铁+硬石**。原三对宽配方让它
  吸走所有「缺磁铁的伤组件」成为第一霸主（快照口径 18.9%、围巾+天气
  家族 44.7% 超线）；终版改成「守卫最严的防御料余料折算」，伤组件全部
  让给围巾；
- **黄围巾加「雷之石碎片×2」第二配方**：电系棋子稀缺（池内 5 只），
  单靠「碎片+磁铁」时黄围巾 3.2-3.8% 低于 5% 底线（同组件合成沿用
  疾风羽先例）。

## 3. 装备交互规则

- 每单位 1 格；卖棋自动卸下回仓库（无惩罚），战斗中不可换；
- 合成即完成（无等待），演出：两组件飞入 + 白闪（进化光球压缩版复用）；
- 进化石不消耗但有 8s 冷却（防止一局三连通信进化的滚雪球）。

## 4. 棋盘特效语言

| 层 | 表现 |
|---|---|
| 持有者标识 | 底座外圈**金色细环**（1px）——扫一眼棋盘就知道谁带装备 |
| 品质 | 无分级（12 成品平权，靠组合不是数值爬坡） |
| 触发特效 | 剩饭=绿色 +2 跳字；披带触发=白色锁链闪；专爱=锁定红线（攻击者→目标 0.2s） |
| 合成演出 | 两图标从两侧飞入背包格 + 白闪 + 「合成了剩饭！」消息窗 |
| 详情/图鉴页 | 32px 道具图标（缺口资产：12+8 张，程序生成或提取） |

## 5. 与现有系统关系

- S2 通信进化：进化石是**唯一通道**（2026-09-14 裁定：原「3 合 1 需持
  装备」双通道删除，50 局仅触发 1 次、与进化石实质互斥）；
- 羁绊：三色围巾让非本系棋子蹭系别加成（伪羁绊补位）——bot 合成侧
  按池深设门（水 ≥3 / 火 ≥2 / 电 ≥1 只同系棋子），单载体不合成；
- 天气：天气石 + 围巾 = 追天气体系的经济出口；
- 经济（S4）：合成消耗零金币（组件即成本），幸运蛋是唯一生息道具
  （落后方优先合成，docs/03 §5 追赶渠道）；
- 观战：金环 + 触发特效让装备在战斗里「看得见」。

## 6. 开放问题

1. 12 成品是否够/过多（TFT 起步约 10）——随池子扩到 4/5 费时复查；
2. 专爱头巾的锁目标在自动战斗里是增益还是减益（围杀转火问题）；
3. 组件掉落的随机性是否需要「三选一」缓冲（TFT 式）防天崩。
