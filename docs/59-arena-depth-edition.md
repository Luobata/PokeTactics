# 59 · 竞技深度版（arena_v2）与效果引擎

日期：2026-11-15。依据 [57 号评审](57-depth-and-presentation-review.md)，用户批准“先重构，再推进全部提案”。
本文件只写已实现的规则；数值仍需后续平衡实验。

## 1. 版本与兼容

| 规则 | 说明 |
|---|---|
| `arena_v1` | 原竞技规则，行为冻结。`tests/fixtures/arena_golden.json` 记录 3 局完整机器人对局与 240 场随机战斗的逐事件指纹，`tests/test_arena_effect_bus.py` 每次回归都会对账 |
| `arena_v2` | 新开竞技局默认使用（`/api/demo/action?cmd=new&mode=arena`）。`edition=v1` 可显式开旧版 |

旧存档：重构前构建的规则指纹登记为 `PRE_DEPTH_EDITION_FINGERPRINT`，继续按 `arena_v1` 读取；`arena_v2` 存档新增字段（棋子 `depth`、席位 `depth`、`arena.draft`），旧规则存档带这些字段会被拒绝。

## 2. 效果引擎（`sim/arena_effects.py`）

- **事件总线** `battle.fx`：触发点 `tick / basic_settled / direct_hit / native_primary / native_cast / native_heal / native_energy / knockback / debuff`（v1 已有），以及 `battle_start / death`（v2）。
- 旧钩子按**原调用顺序**注册为适配器，`combat.py`、`arena_skills.py`、`arena_fields.py`、`status.py` 中散落的局部 import 链改为一次 `emit`。重构前后逐事件指纹一致。
- **声明式效果** `EffectSpec(id, source, trigger, name, handler, cooldown, limit, tags)` + `EffectInstance`（绑定单位或队伍，统一冷却与次数）。
- **收益账本** `Ledger`：每个来源（海克斯 / 羁绊断点 / 装备 / 技能强化 / 地形）记录触发次数、伤害、治疗、护盾、能量，以及被动加成按真实伤害推算的“增伤≈/减伤≈”。战报“奖励 · 联动”页显示双方账本。
- 海克斯面板改为数据行 `AUGMENT_MODIFIERS`（顺序与旧 if 链一致）。
- 新事件 `(t, 'effect', source_idx, target_idx, effect_id, payload)`，`payload` 含 `source / team / kind / label / value / camera`；渲染端未知事件按通用弹字处理。

## 3. arena_v2 规则（`sim/arena_depth.py`、`sim/arena_session.py`）

### 3.1 属性曲线
费用档预算缩放 `1.20 / 1.04 / 0.94 / 0.92 / 0.90`，星级倍率 `1 / 1.8 / 3.2`。2 星 1 费的生命已高于 1 星 3 费，低费追三星成为可行路线。

### 3.2 阶段地形（每 5 轮轮换，第 1–5 轮为平原）
| 地形 | 效果 |
|---|---|
| 高地 | 己方后排中间四格：开战时站上的远程单位射程 +1、攻击 +8% |
| 能量泉 | 己方中央四格：每秒 +6 能量 |
| 荆棘丛 | 两侧边列：每秒损失 2% 生命，但普攻伤害 +15% |
| 圣域 | 己方后排：每秒回复 1.5% 生命 |
| 泥沼 | 双方前排：移动耗时 +60%，受到伤害 -10% |
| 余烬 | 双方前排：造成伤害 +12%，受到伤害 +8% |

准备页显示本阶段地形、下一阶段地形，并在己方棋盘标出地形格。机器人按地形调整阵型（`arena_depth.formation`）。

### 3.3 本命技能强化（升 2★、3★ 时二选一，永久）
| 定位 | 2★ | 3★ |
|---|---|---|
| 攻击 | 强化（+30% 伤害/治疗） / 扩散（邻格 35% 溅射） | 处决（<15% 直接击倒） / 汲取（回复 30% 实际伤害） |
| 防守 | 坚壁（施放后 15% 护盾） / 震地（邻格畏缩 0.6s） | 反震（4s 内反弹 30% 直接伤害） / 汲取 |
| 辅助 | 溢流（两名队友 8% 护盾） / 迅捷（返还 25 能量） | 圣洁（净化 + 3s 减伤 25%） / 强化 |

未选择时开战按第一项自动确定；机器人按偏好表选择。

### 3.4 规则型海克斯（v2 候选池移除 8 个纯面板海克斯）
| 海克斯 | 规则 |
|---|---|
| 双持专精 | 所有棋子 2 个装备位；战斗中技能机失效 |
| 精兵简政 | 人口 -1；全队生命与攻击 +22% |
| 羁绊共鸣 | 已激活属性羁绊计数 +1（含深度断点）；人口 -1 |
| 速成培育 | 每轮开始自动从卡池补齐 1–2 费家族的同星对子（每局 3 次） |
| 自由刷新 | 每轮前两次刷新免费；定向刷新基础价 1 金 |
| 回收专家 | 卖 2★+ 额外得 1 组件；拆解免费 |
| 寻宝者 | 立即 2 组件；野怪轮胜利再 +1 组件 |
| 理财专家 | 利息上限 5 → 8 |
| 冲锋号 | 开战时近战跃到最近敌人旁并获得 12% 护盾 |
| 先锋壁垒 | 开战时前排获得 20% 护盾 |
| 狙击巢 | 后排远程射程 +1、攻击 +10% |
| 不屈军团 | 每场第一个致命伤改为保留 1 生命并 2 秒减伤 60% |
| 连锁爆破 | 敌人阵亡时对其邻格敌人造成其最大生命 12% 伤害 |
| 巨人杀手 | 对最大生命更高的目标伤害 +22% |
| 斩首令 | 直接命中把敌人打到 12% 以下时击倒（每名攻击者 3 秒冷却） |
| 能量虹吸 | 施放本命后邻格队友 +12 能量 |
| 坚守阵地 | 本场从未主动移动的单位受到伤害 -18% |

保留：5 个条件海克斯、3 个成长海克斯、经验学说。机器人按阵容标签打分选择，不再随机。

### 3.5 羁绊深度断点（改变战斗行为）
岩石 4 岩壁（邻格队友受伤 -12%）、飞行 4 俯冲（开战扑向最远敌人/敌方核心）、幽灵 2 虚化（首次致命保留 1 生命并 1.5 秒不可选中）、水 4 潮涌（溢出治疗转护盾）、火 3 燎原（每 3 次普攻点燃）、电 4 电弧（每 4 次普攻向 3 名敌人传导 45%）、草 4 荆棘缠绕（首次低于 40% 定身邻敌）、毒 4/6 毒蚀（中毒敌人受伤 +12%/+20%）、地面 4 余震、一般 4 团结、格斗 4 连环拳、超能 4 念动（本命推开 1 格）、虫 4 蜕壳、冰 3 冰封、钢 2 反甲（12%）、恶 2 伏击（首击 +40%）、龙 2 龙鳞（技能伤害 -15%）。

### 3.6 核心
准备期可把一只上场宝可梦设为核心：第二装备位、自身属性羁绊计数 +1、生命攻击 +15%；敌方飞行俯冲优先扑向核心。机器人自动指定最高价值攻击手。

### 3.7 装备
- 每件成品额外携带其两件组件的基础属性（头带攻击 +8%、硬石头生命 +8%、磁铁技能 +10%、加速鞋攻速 +8%、贝壳铃开战 +10 能量、木炭伤害 +5%、水滴每秒 0.6% 回复、雷碎回能 +10%）。
- v1 中 4 对无配方组件在 v2 合成新装备：心灵水晶（磁铁×2）、先制之爪（磁铁+鞋）、逃脱背包（水滴+鞋）、爆裂核心（木炭+雷碎）。
- 卸下装备花 1 金；成品可拆回组件（1 金，回收专家免费）或出售（+2 金）。
- 回合奖励每场 1 份（连败 3 场起失败再补 1 组件）；技能机只发放阵容中有人能学的。

### 3.8 共享选秀（第 4 / 9 / 14 / 19 / 24 轮）
8 份“精灵 + 组件/成品”，生命值低者先选。玩家之前的机器人先选，玩家选后其余机器人再选；未选择时开战自动拿第一份。

### 3.9 账本与反作弊
- 收益账本列出本场装配但未触发的效果（“未触发”）以及常驻面板类海克斯（“常驻加成”）；高地、狙击巢按受益单位计次。
- 选秀得到的棋子在当轮出售价格为 0，避免“选棋即卖、白拿装备”。
- 商店卡带 `buyable` 与 `reason`（金币不足、传说限一）。

### 3.10 其他
- 远程单位在射程内优先攻击生命比例最低的敌人。
- 锁定目标够不着时，若已有敌人在射程内就转而攻击它，不再绕路——修复了两个近战互相追逐、原地来回踱步的问题（v1 保持原行为）。
- 前排掩护：远程单位正前方有队友时，受到远程攻击的伤害 -12%；辅助庇护：与辅助型相邻的队友受到伤害 -6%。
- 早期形态不再使用通用“属性冲击”：40 个通用技能形态中 38 个改用终形本命技能的 75% 威力版（“初阶·”前缀）。
- 野怪轮星级随阶段提升（第 5 轮即有 2★，第 15 轮起出现 3★）。
- 定向刷新：按属性重抽商店（同等级概率），基础 3 金，同轮每多用一次 +1 金。
- 输掉 3 场以上每轮多 1 次免费刷新。

## 4. 已修复缺陷
- 三合一后新棋子占回原棋盘格（竞技模式），不再掉到备战席导致人口下降。
- 淘汰后其余存活席位提供 `provisional_rank`。
- 对组件调用装备给出“需要先合成”的明确提示。
- 商店卡显示“已有 n/3”，传说限一在卡片上提前置灰。
