# 不同配队与启动装备实验 · 2026-10-05

**配队互有优劣的目标尚未全部达成。** 原始四队保留不变，24,000场对照显示耿鬼干扰和聚光镜启动有真实收益，但双翼突进仍对另外三队全部占优；幽影控场原阵型没有优势对手。六维预算一致、交换阵营通过或局部改善不能写成全池平衡通过。

## 两项有限修正

仅作用于显式 `budget_v1`：

- 耿鬼舌舔保留原招式ID、名称、幽灵属性、命中率与状态；战斗载荷改为65威力、使用较高攻击端，仅释放大招时优先射程内能量最高的敌人。偷能仍最多20、自获实际偷取量的一半，普通属性免疫仍为零伤害且不偷能。基础面板、卡比兽自愈均未修改。
- 聚光镜改为开场40能量，取消原25%大招增伤。以同样两个组件取得先发机会，代价是放弃持续大招增伤；经典 `legacy` 保留旧效果。没有增加免费属性预算。

前排多次受击回能、后排较迟首次施法是初探中观察到的时序差异；现有成装缺少启动资源。聚光镜因此提供一种可付费配置的启动选择，而非给所有法系直接加数值。

每队六人口、15费、三件成装、一个主搭档、一个独立教学；装备数量与合成组件数相同。使用真实物种、原生技能、羁绊、状态及手工部署。基线与新规则使用完全相同的四队、部署、种子与资源。

## 原四队改前 / 改后

改前同时使用耿鬼旧20威力物理载荷与聚光镜旧25%大招增伤；改后使用两项新规则。每行显示左队胜率，本次没有平局。

| 左队 → 右队 | 改前 | 改后 | 改后时长中位数 |
|---|---:|---:|---:|
| 花园续航 → 电流法阵 | 100.0% | 100.0% | 12.80s |
| 花园续航 → 双翼突进 | 16.7% | 25.0% | 20.60s |
| 花园续航 → 幽影控场 | 94.2% | 87.5% | 19.90s |
| 电流法阵 → 双翼突进 | 0.0% | 0.0% | 9.80s |
| 电流法阵 → 幽影控场 | 40.8% | 96.7% | 8.80s |
| 双翼突进 → 幽影控场 | 100.0% | 76.7% | 14.10s |

法阵对幽影从40.8%增至96.7%，但对突进仍为0%。幽影对突进从0%增至23.3%，尚未成为优势对局。花园对突进由16.7%增至25%；不能将卡比兽单挑100%直接解释为团战需要削弱。

## 有成本的适配与失败读数

适配全部保留原六名成员。装备和站位适配保留三件装备与一个学习槽，去TM消融则明确撤去这一资源；各行与自己的原配置比较。

| 调整 | 对手 | 原配置胜率 | 调整后 |
|---|---|---:|---:|
| 幽影控场：前后排互换 | 花园续航 | 12.5% | 67.5% |
| 幽影控场：前后排互换 | 双翼突进 | 23.3% | 0.0% |
| 幽影控场：三件装备改为聚光镜 | 双翼突进 | 23.3% | 41.7% |
| 花园续航：三件装备改为聚光镜 | 双翼突进 | 25.0% | 14.2% |
| 电流法阵：聚光镜与首名前排的装备互换 | 幽影控场 | 96.7% | 69.2% |
| 幽影控场：聚光镜与首名前排的装备互换 | 双翼突进 | 23.3% | 5.8% |
| 花园续航：撤去学习招式 | 双翼突进 | 25.0% | 14.2% |
| 双翼突进：撤去学习招式 | 花园续航 | 75.0% | 67.5% |

幽影只交换前后排即可针对花园取得67.5%胜率，同时对突进降至0%；有可操作的应对，也有明确代价。三镜幽影对突进提升到41.7%，还不能宣称已克制突进。花园三镜把对突进胜率从25%降至14.2%，撤掉剩饭、披带会失去续航与保护。花园睡觉、突进居合斩对部分对局有用，也存在不改变胜负的对局。

JSON含每队对每个对手的去装备、去TM、去搭档、前后排互换、前排聚光镜、三聚光镜六种消融，保留零收益与负收益。双翼突进原装没有聚光镜，因此其“前排镜互换”为无操作对照。前排镜按部署前排第一个单位选择，幽影队对应隆隆岩。

## 六件装备压力测试

双方都获得六件成装，与三件装备主实验分开统计。包括原四队两两“双方六镜”“双方六专爱”各一组，以及同阵容六镜对六专爱；没有用六镜打一队三件装备来证明优势。

| 同阵容 | 六镜对六专爱胜率 |
|---|---:|
| 花园续航 | 8.3% |
| 电流法阵 | 45.8% |
| 双翼突进 | 67.5% |
| 幽影控场 | 55.0% |

六镜没有成为所有队伍的最优装备，但突进同阵容六镜为67.5%，说明启动资源也能强化前排爆发。该结果只排除这四队上的“全镜普遍碾压”，不能排除全池其他套利组合。六镜花园对六专爱花园有5个独立试验超时，依原规则按存活HP比例裁决；其他保留试验无超时。

## 接口、兼容与验证

`Battle(..., learned_a=None, learned_b=None)` 接收与对应comp等长的list，各元素为None或招式ID，由 `techniques.validate_learning` 验证物种相容。普通棋子可以独立学习，同物种复制体可各学一种。显式学习优先，None回退旧team_options搭档技能；每个单位只执行一种学习技能，已被覆盖的旧技能不再影响随机绑定。归属由OwnedPiece/存档层提供。

攻击和施法tuple字段未改变。独立教学沿用现有 `partner_effect` 注释事件，普通棋子的partner_id为None；全部伤害、治疗、初始能量和偷能仍输出权威 `unit_state`。聚光镜初始40能量在开场第一份状态中即可读取。UI可用 `build_rules.item_description(item_key, stat_mode)` 获取模式说明，其他装备或经典模式返回None回退原说明。

- 12项新增定向测试通过：物种/长度校验、重复物种独立学习、旧搭档回退与覆盖、cut/surf无额外回能、rest行动代价、耿鬼按模式载荷/能量目标/免疫、聚光镜取舍和阵营交换。
- 旧搭档8项、预算4项、战斗合同13项、专属技能15项测试通过。
- 100组经典规则随机六人队，包含聚光镜及旧搭档技能，与当前HEAD旧combat的完整事件流逐条一致。
- 保留24,000场（12,000个成对试验）阵营交换失败数为0。JSON的 `all_have_favorable_and_unfavorable` 为false。开发20种子原始失败矩阵及20/30/40/50能量镜子探查另存 exploration.json，未隐去没有提升的读数。
