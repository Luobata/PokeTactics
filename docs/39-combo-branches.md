# 玩法分支与跨系统联动

本版将护盾、净化、击退接到装备与海克斯上。同一战术允许不同宝可梦提供不同的启动方式、保护范围和收益；组合依赖真实生效事件，不因凑齐名单就保证触发。竞技规则专用，经典模式沿用原结算。

## 1. 系统分工

| 系统 | 构筑作用 |
| --- | --- |
| 宝可梦本命技能 | 决定行动方式：单体大盾、群体小盾、减伤盾、单体净化、群体净化、击退等 |
| 技能机 | 补足队伍缺少的能力；功能型教学在成功普攻后等待合适的场地条件 |
| 道具 | 把事件转成另一种收益，占用唯一装备格，必须与启动装、生存装取舍 |
| 海克斯 | 让整队沿一个方向构筑，同时保留单个触发者的冷却与次数限制 |
| 属性、羁绊、站位 | 决定选人代价、克制、支援范围、受击对象与连招顺序 |

不要求每个队伍集齐全部系统。特性、更多场地和其他新系统属于后续扩展；应复用可观测的真实事件，每次新增机制都同时给出不同来源、收益分支和反制。

## 2. 新增装备与海克斯

| 名称 | 获得方式 | 生效规则 |
| --- | --- | --- |
| 守势护腕 `ward_bracer` | 力量头带＋加速鞋；竞技成品奖励也可获得 | 携带者在连续护盾期间实际吸收累计达到自身最大生命8%，获得4秒反击蓄力；下一次有效普攻伤害翻倍。触发冷却4秒，每战最多蓄力3次；不强化本命、教学、持续伤害或反伤 |
| 清明坠饰 `clarity_charm` | 贝壳铃＋木炭；竞技成品奖励也可获得 | 携带者本命技能成功净化其他友军一个主要异常后，提供该友军最大生命8%的护盾，持续3秒；冷却4秒，每战最多3次。空净化、自净化不触发 |
| 屏障回流 `barrier_feedback` | 竞技海克斯 | 为其他友军提供的护盾实际吸收累计达到受盾者最大生命5%，原施盾者回复8点能量。一次连续护盾至多触发一次，施盾者冷却4秒、每战最多3次；死亡或满能量时无有效回能 |
| 乘隙追击 `breach_momentum` | 竞技海克斯 | 成功击退仍存活的敌人后，给其施加12%易伤、持续4秒。原生击退和吼叫均可触发；每位推动者冷却4秒、每战最多3次。堵路、边界、自然移动、友方救援和自身闪现不触发 |

护盾继续采用单槽：更弱或等量的盾不能覆盖、续时或叠加。连续护盾期间更强覆盖不会重置吸收触发资格；更换来源需重新累计该来源的吸收量，来源的冷却和总次数不重置。过期或耗尽才结束该次连续护盾。

回能上限仍是80，接收者在自己的下一次行动判断施法，不即时递归。易伤沿用单槽、不叠加规则；技能施放前的状态决定其原生追击收益，不能倒过来使用本次击退刚施加的易伤。反击增强记录实际额外生命损失，护盾吸收和过量伤害分别处理。

## 3. 同一战术的不同成员

| 战术职责 | 可选成员 | 替换带来的差异 |
| --- | --- | --- |
| 提供护盾 | 皮可西／拉普拉斯／魔墙人偶 | 皮可西单体20%大盾、可自保；拉普拉斯给两名其他队友14%盾并解冻；魔墙人偶单体14%盾与20%减伤，减伤也可能让吸收阈值更晚达到 |
| 使用守势护腕 | 风速狗／怪力等需要普攻的持盾者 | 风速狗短时嘲讽吸引攻击，便于盾被命中；怪力攻击定位更适合利用强化普攻，但需要其他前排保护。尼多后毒刺要求实际掉血，护盾与毒刺存在机会成本 |
| 提供净化 | 巴大蝶／大竺葵／猫头夜鹰 | 巴大蝶单体净化兼治疗；大竺葵群体净化兼治疗；猫头夜鹰针对睡眠与麻痹、兼回能。拉普拉斯虽可解冻，但同时提供更强的14%原生盾，清明坠饰不能再加盾，不作为推荐搭配 |
| 提供击退 | 水箭龟／飞腿郎／大钢蛇／吼叫教学 | 水箭龟兼贯穿，飞腿郎提供进攻，钢系前排兼减伤；吼叫每战一次并占用教学格，可给相容精灵补能力 |
| 利用易伤 | 太阳伊布／巨钳螳螂／普通攻击手 | 太阳伊布在施法前易伤存在时追加追击；巨钳螳螂强化多段连击；其他攻击手受益于易伤增伤但没有专属追击 |

典型分支包括护盾反击、施盾回能、净化接护盾、击退接集火，也可与治疗护心铃、岩钉推阵交叉。多名地形手仍共享三格岩钉；主要异常仍互斥，叠加毒与灼伤来源不等于两者同时生效。

## 4. 功能型技能机的时机

两种技能机仍每战一次，不新增玩家设置或存档字段。

- 吼叫：成功普攻后检查空闲击退落点。有存活铺钉队友或本队有效岩钉时，先等落点处于本队岩钉；开战6秒后不再等待场地。没有铺场条件时可在首次成功普攻后使用。无合法落点始终保留次数。
- 高速旋转：敌方存在存活铺钉手或有效岩钉时，先等自身一格内出现敌钉；开战6秒后不再等待。没有铺钉威胁时仍在首次成功普攻后补攻击。发动后清除范围内至多三格敌钉，敌方后续重新铺场仍有效。
- 其余教学保留既有规则。施放过早、被控制、敌人改变位置、目标先被击倒，都可能改变连招兑现。

## 5. 可见性、验证与后续

图鉴提供适配成员、替换取舍、站位和反制。准备期检查上场构筑条件，战报只统计实际发生的蓄力、额外生命伤害、有效回能、新增护盾、吸收与易伤施加；具备条件不等于保证收益。

验证包含触发顺序、空效果不触发、冷却与次数、盾生命周期、反击伤害归因、经典规则对照以及精确前驱存档恢复。阵容实验验证多个合法成员变体能实际使用这些机制；不能据此宣称所有分支已经平衡。

后续优先改善不同成员的战术选择和收益可读性，再根据对局证据扩展特性。新反应必须有明确来源、有限触发和可反制窗口，不能通过回能、护盾与反击相互调用形成同拍无限循环。
