# 26 · 有代价的反制与自然终局

2026-10-05。承接24号规则与25号进化复核。现行84只关都形态，不加入二世代。新开战术远征使用 `tactics_v4`；旧局按保存的显式版本继续。

## 规则边界

| 版本 | 生效行为 |
|---|---|
| `base_v1` | 原版远征 |
| `tactics_v1` | 护卫、共享天气教学 |
| `tactics_v2` | 上述＋九尾/拉普拉斯入场天气 |
| `tactics_v3` | 上述＋封疗针；作为独立节奏对照 |
| `tactics_v4` | 上述＋R20起终局压力；新战术入口 |

封疗针用头带＋木炭合成，占唯一装备槽。旧版本该配方仍按旧规则；主动合成通信石仍可用这两个素材。新版本可取消、确认、卸下、卖棋返还和保存恢复。

佩戴者每场首次**成功造成主命中伤害且最终目标仍存活**的原生大招施加60%恢复削减，持续八秒。普通攻击、派生包、未命中、免疫和致死目标不消耗成功施加机会。护卫拦截后作用于最终承伤者，不能越过护卫落到被保护者；来源退场不提前清除已施加窗口。

剩饭、水羁绊、睡觉及招式/搭档恢复共用真实治疗路径：先限定实际缺血，再按最强有效削减计算；不同来源不相加，每个来源独立到期，等于到期时刻不再生效。满血不制造“被减少恢复”，死人不复活。每场重新部署不继承这个战斗临时效果。

机器人仅根据已遭遇对手的可见阵容识别恢复威胁，再决定是否优先用素材合成；选择可施放原生技能的空装备位。固定队实验不证明机器人整局合成/使用频率已合理。

`tactics_v4` 在R20及以后将**败方**扣血设为 `max(旧扣血, 21)`，包含普通PvP、幽灵、空场和PvE失败；胜方不扣血，平局按各自损失处理。R30野怪轮及胜利奖励保留。准备界面和开战详情提前提示压力，不引入额外按键。旧版本不启用压力。

## 反制与系统联动证据

每队六人口、15棋子费、三装备、一教学。正式100独立种子 `2026100550000–2026100550099`；换边只校验，不扩大N。原四队及失败探索保留。

| 对照 | 正式结果 | 能支持的结论 |
|---|---|---|
| 原花园 → 幽影护阵，对原突进 | 20% → 83% | 幽灵前排、阵型及资源选择有反突进收益 |
| 同候选对镜像突进 | 23% | 对手能从侧翼破坏方案 |
| 同候选对花园/控场/电流 | 0% / 32% / 71% | 不是通吃的替代阵容 |
| 同候选学护卫但未选 → 已选 | 胜负无变化；原突进18/100发生拦截 | 本批没有证明护卫独立翻盘 |
| 控场对花园，旧聚焦镜 / 针无封疗 / 完整针 | 8% / 11% / 34% | 封疗本身净增23个百分点，26赢转变/3反向；实际减少7402HP恢复 |
| 控场对突进，同三臂 | 16% / 1% / 1% | 牺牲40启动能量的代价主导，没有净收益 |
| 控场对电流，同三臂 | 4% / 4% / 4% | 有施加但无实际可阻断恢复；胜率无净变化 |

“针无封疗”只关闭施加方法、保留针占槽与启动损失，是实验控制，不是玩家可获得装备。有限样本和固定队不等于全池平衡或真人体验。自镜像同种子校验的期望及修订见原始证据README，不把相同输入下胜者复现误判为阵营偏置。

证据：[反制原始数据及方法](../reports/evidence/counterplay-2026-10-05/README.md)。

## 自然收官证据与代价

同AI、同反制规则的100完整局种子 `2026103000–2026103099` 比较v3/v4。自然冠军必须终局恰好一人存活、完整名次1–8且存活者为第一名；零人存活不算自然冠军。

- 自然冠军21/100 → 93/100；R31强制排名79 → 7；平均收官轮30.68 → 28.79。
- 93%的Wilson95%区间为86.25%–96.57%。观察率达到D12的90%初筛目标，区间下界未达到90%。
- R19及以前旧节奏不变；R15/R20样本成长记录同态。R20后的压力不能被表述为“尚未生效”。
- R25玩家仍存活45 → 25，全桌存活席位450 → 335；全桌已领技能机均值38.05 → 35.24。存活者条件平均等级更高，不意味着成长机会增加。
- 自动解算时间不替代真人三键准备/播放时间，D12的人类操作时长验收仍待做。

证据：[自然终局报告](../reports/natural-end-2026-10-05.md)。

## 表现、存档与后续

画面只消费实际命中、治疗和权威HP事件。封锁徽记、减少恢复浮字与实际回血同步；徽记到期或目标退场消失。演出倒放、2倍速、跳过不能写回模拟。演出倒计时按已公布时长显示，实际恢复取模拟时钟的到期裁定。

现有 `tactics_v2` schema4档在旧指纹下，动作后全状态、89条完整事件的哈希都与冻结基线一致；旧版本不能通过伪造新装备或借旧指纹启用v3/v4。验收使用临时目录，不改用户原档。

进化本批不删改；25号文档建议先保留，优先补合成前后预览与暂缓，再决定训练。暂缓、实例训练、终卡升星、天赋、完整功能位AI、额外世代与真机均未交付。
