# 像素招式演出：大字爆炎样板

本文记录已验收的大字爆炎样板。当前全员原生技能扩展见 [48 个原生技能像素演出](36-native-pixel-skills.md)。

竞技呈现版本 `web-arena-v3-fire-blast` 为喷火龙原生技能接入独立像素演出。显示名为「大字爆炎」，内部 `flame_storm` / `arena_flame_storm` 标识保留，兼容已有存档、事件归属和组合逻辑。主技能威力仍为 70，相邻至多两名敌人的追加伤害仍为 50%。

`retro_moves.draw_fire_blast` 使用原创的有限色像素帧：嘴部聚火、火球飞行、命中展开「大」字、余烬消散。描边、橙红焰体与亮黄色核心构成清晰轮廓，使用最近邻缩放，不依赖外部动画资源。形态参照早期掌机招式的辨识度，未复制原作动画素材。

火焰质感修订：笔画亮芯采用断续的高温斑块，横向与斜向边缘都有随帧变化的火舌。主、副命中增加带亮头和暗红尾迹的飞散火星及碎焰，后段上浮消散；副目标溅射保持局部范围，并且只在真实命中后出现。

火星可见性修订：飞散范围与火星自身尺寸分开控制，副目标的火星不再随溅射范围一起缩成细点。亮头与长拖尾沿连续轨迹飞散，跨越命中/余烬阶段时不会重新从中心发射。主、副火星分别有18/12条可用轨迹，粒子密度控制实际数量；主火星最大飞出约87px，副火星约48px，再应用编辑器倍率。

只有原生 `arena_flame_storm` 使用该独立演出，并跳过通用属性材质和图形叠加。喷火龙普攻、技能机技能和其他火属性精灵维持原有路由。副目标的小型爆炎来自实际 `skill_effect / flame_storm / side_hit` 正伤害事件，不按画面中的距离推测受击者，也不添加新的伤害。

蓄力跟随真实嘴部锚点；火球发射后固定起点。所有阶段采样已有 `ActionTiming`，主副目标特效均从真实命中时刻起播放。大型火焰主体仍在约0.5秒内消散，火星尾部延续到0.8秒；只延长大字爆炎的视觉尾部，不改变伤害、动作恢复或其他技能的演出时长。配色、特效尺寸与粒子密度沿用编辑器参数；身体动作继续使用现有喷火龙部件动画。

试玩新生成战斗、实验室、编辑器与竞技导出共用该实现。代码内容哈希使工具预览缓存失效，呈现版本写入新战斗 metadata。已有历史战斗帧保留生成时版本；不为更新画面重新模拟历史战斗或改写存档。

查看：`/animation-lab?mode=arena&species=6&kind=cast`，可逐帧查看蓄力、发射和命中；编辑器同参数可调整表现。这一版本仅完成喷火龙样板，其他技能尚未整体改为此风格。
