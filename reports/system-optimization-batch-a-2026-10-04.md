## 自动验收入口

```sh
python3 tools/acceptance/system_acceptance.py --demo --balance --output .build/acceptance/full.json
```

执行器保留每个命令完整输出、返回码、耗时、失败原因。输出出现 FAIL、发现零测试、超时、
非零返回都视为失败；未选项为 skipped。`--demo` 固定种子 7/42；`--balance` 默认 40 局、
种子 20261004。运行前需有本项目现有资源目录与 Pillow，不自动安装依赖。

最终结果以 `.build/acceptance/full.json` 为准。本批包括 50 项单元合同、编译检查、差异检查、
两局 Demo HTTP/帧验收和 40 局整局验收。小样本 smoke 只证明执行链，不能替代平衡结论。

独立补充验证：

- `python3 sim/prototype.py --games 100 --seed 20261004`：确定性通过，双方 50:50，
  无平局或超时，中位 12.1 秒、均值 13.0 秒、最长 31.1 秒。
- `python3 tools/mockups/r1_contract_check.py --output .build/acceptance/r1-contracts.json`：
  旧事件、回卷及角色演出合同通过（执行产物已归档）。
- 40 局整局四条现有健康线通过，但 32/40 局达到 31 轮上限；L1/L2/L3 平均名次为
  3.23/4.50/4.80，难度仍不单调。不能把四条通过解释为局长与 AI 已完成优化。

## 实际浏览器验收

使用本机 `127.0.0.1:8807/demo`、Codex 内置浏览器和公开按钮，未修改浏览器内部对局状态。

1. 种子 7，买入小磁怪，角色卡显示「散射：额外攻击目标附近最多 2 名敌人，各 40% 伤害」
   与射程 3；点选后摆到前排右角。事件流出现 `[0.0] 小磁怪 落位 (5, 2)`。
2. 锁定商店后开战、下一轮：空位/卡蒂狗/腕力/小磁怪原样保留，锁定按钮仍显示已锁定。
3. 新局种子 7，每轮通过「开战 → 确认空场开战 → 下一轮」操作。R12 淘汰、名次 8；
   R13 准备页可见「观战下一轮」「快进至最终排名」，不存在只能停在禁用开战按钮的死路。
4. 点击观战进入 R14，再快进到 R31。主页面显示最终八人排名及「第 12 轮阵容：空场」；
   终局无需保持回放浮层打开。浏览器采集的 console error 列表为空。

浏览器人工操作路径与 API 整局脚本分开记录；没有做真实新手测试、设备按键或真机验收。

## 审查与工具边界

独立审查由未编写游戏实现的子代理执行，复现并修复了预览后换位、玩家鬼影丢失坐标、
备战未满时潜在合成溢出、凯西错误技能说明四处问题；各自加入回归。
最终结论为 `pass_with_risk`：本批无新增阻断项，保留历史演出时序风险。
审查范围指纹为 `9f7bb5e15933500b6c9cbe65707895f5a6d48a340f31640d7d19f01ba7132027`。

QualityGate MCP 在当前会话未注册；本机 runner 检查报告部分依赖缺失。尝试本地 CLI gate
得到原始 `pass`，但对本 Python 项目 **matched_rules=0**、Go 检查文件数 0，属于无有效规则覆盖。
因此不将它计为本批质量通过证据；原始输出保存在 `.build/acceptance/qualitygate.json`。
未安装 mutation 工具，也未修改用户 QualityGate 配置。有效验收来自上述项目合同、整局脚本、
浏览器路径与独立审查。

## 仍需推进的工作

- 规则修复改变了随机消费顺序、受击回能和状态覆盖；v2 的同种子可重放，旧 seed 不保证复刻
  旧引擎战果。没有通过修改 TICK 或伤害常量来凑胜率。
- 回放 HP/能量跟随模拟时钟；投射物与死亡演出尚未统一为命中时钟。历史致命弹道被取消的问题
  仍存在，需要独立的演出时间验收；不把数值一致误称为所有视觉时序正确。
- 侧击/齐射仍记录理论伤害，可能含过量伤害；伤害贡献统计还不是有效扣血口径。
- 伊布继续默认水伊布，没有三选一；没有独立星级。凯西当前没有属性招式，角色卡已如实显示，
  补齐其可触发技能属于后续角色闭环。
- 同轮淘汰排名、长局强制裁决、AI 难度、重复棋子羁绊、装备供给与玩家操作时间预算继续待验收。
- 存档与刷新恢复未实现；当前会话仍存于内存。本批没有宣称局外成长或硬件端可交付。

下一包优先做小核心池/角色闭环、独立升星和统一 AI 价值；随后做教学、三键交互、存档与复盘。
每包沿用“具体行为 → 可复现输入 → 自动检查 → 玩家动作 → 证据 → 剩余风险”的交付方式。
