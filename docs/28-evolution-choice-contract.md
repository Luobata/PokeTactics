# 进化预览、暂缓和一步确认合同

2026-10-05。第十一批；本包不加入二世代、不新增训练或星级、不调整战斗强度。公平性分析见27号，路线取舍见25号。

## 规则入口与旧局

新战术远征入口为 `tactics_v5`，继承v4天气、封疗针和R20败方至少21生命压力。v5新增的是实例进化选择。`base_v1` 与v1–v4仍按原来的自动递归合成继续；旧存档不静默升级。schema4保持不变：仅v5拥有必填布尔字段 `evolution_locked`，旧版本禁止该字段。此前v4完整源码指纹只对旧版本白名单接受，不能给v5冒用。

## 购买与暂缓

- 商店预览复制当前棋盘、备战、库存与卡池，调用真实合成函数。覆盖此次购买可能触发的所有递归合成；不改变金币、卡池、UID计数、教学、装备或随机流。
- 每步显示目标职责、属性和大招、累计真实投入、目标池余量、上场/备战数量、上场羁绊、沿用UID、装备与教学继承、多余/不兼容教学退回。合成品落到备战席，需要重新部署；不能把“合成后战场人口”冒充“重新部署后人口”。
- 存在合成时，三键提供“购买并进化”“购买并暂缓”，默认取消。长按C查看详情。
- 暂缓购买跳过本次所有自动合成，并把购买形态全部现有实例设为暂缓。后续购买尊重锁定，不能消耗刚保留的两只。终点形态和通信石专属形态不可用普通暂缓购买。
- 两种购买选择分别检查金币与最终备战容量：自动合成能空出备战位置时可买；暂缓仍超六格时必须拒绝，且零资源变更。

## 实例选择

- 暂缓/解除暂缓只改所选UID的标志，不立即触发进化；移动也不触发。再次自动购买时仅未锁定实例可参与合成。
- 明确进化包含选中UID，再按现行棋盘＋备战顺序选择另两只同形态；继承仍按三个材料在此顺序中的首个装备/兼容教学和首个UID。选中第四只必须被消耗，但不保证选中UID作为产物UID。
- 明确进化允许使用已锁实例，且只进化一步；不能递归吞掉更高形态或额外第四张。目标缺货或产物无备战位置时拒绝并保留材料。新形态默认解除暂缓。
- UID持久化；三键确认提交时按UID定位，不能用旧备战下标重新选人。过期序列、重复release、取消、失败保存不产生第二次经济变更。护卫/天气配置按已有部署与教学规则失效。
- 通信进化仍仅使用通信石；终点/天生单阶段同名卡仍可独立上场或卖出，当前不自动升星或训练。详情必须如实说明。

## 保存与验收

v5锁标志参与已有原子保存、备份、恢复与checkpoint。缺失/非布尔值、终点或通信形态的true锁、旧版本携带锁字段和旧指纹伪造v5都拒绝，不能“修复”成默认false。UI确认前不执行资源动作。

验收：预览零变更；递归预测与真实结果一致；暂缓＋第四张；选中第四张与一步确认；满备战自动/暂缓分叉；缺货；装备/教学/战术联动；恢复、备份回滚和写失败；三键取消/过期/重复release；base/v1/v2/v4完整状态和事件金样本。证据与最终测试结果写入第十一批报告。

本包证明选择与记账合同，不证明整池平衡、锁定策略AI、真人三键局长或真机性能。AI仍沿用原自动策略，当前不会主动暂缓；共同的终点成长仍待独立设计与同预算整局实验。
