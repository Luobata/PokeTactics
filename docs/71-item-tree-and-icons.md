# 71 · 装备合成树、图标与扩充（arena_v2）

## 1. 合成树

背包 → 组件合成图标题旁的「合成树 ⟶」，或任一道具卡片 / 合成格里的「在合成树中查看」打开（`tools/acceptance/play_tree.js`）。

- 三列：**组件 → 成品 → 觉醒**，连线即配方；同组件双份的配方用虚线。宝物单列在下方（不可合成）。
- 点组件：高亮它能合成的所有成品，以及以它为觉醒材料的装备；点成品：高亮两个组件、觉醒版（金色虚线 = 觉醒材料）和双持搭档。再点一次取消。
- 右侧（手机为下方）详情卡：图标公式 `组件 + 组件 → 成品 + 组件 → 觉醒`、组件属性、效果、觉醒条款、双持；可以直接「合成」「觉醒」。
- 筛选：全部 / 能做的 / 已拥有 / 五个共鸣标签。
- 数据：`state.interactions.item_tree`（`interaction_view.tree_block`），规则部分按规则集缓存，只有库存 / 拥有 / 可合成随状态变化。

## 2. 图标

`tools/acceptance/play_icons.js` 是一套原创矢量图标（不使用任何官方美术）：8 种组件与全部可获得装备都有专属造型，
觉醒版加金色虚线光环和星芒，宝物加金框。用于合成树、组件合成图（行列表头和格子）、道具卡片、配装建议、觉醒卡片与双持列表。
`ItemIcons.html(key, {size})`；未知 key 回退为通用宝石。
