# 第二世代竞技卡池

本版从第二世代选入18种进化形态或独立精灵，竞技池从30种扩为48种。每种有专属原生技能、普攻轨迹和技能演出，技能机仍是独立学习槽。经典模式保持关都151种资料、84种可购买形态和原进化规则。

## 可组合的战术

- 岩钉与推阵：大岩蛇、班基拉斯铺场，大钢蛇或学会吼叫的伙伴击退。班基拉斯只对施法前已站在己方有效岩钉上的目标改用击退，刚铺钉不会同次自触发。战舞郎清除近身敌钉；厚底靴免疫入格伤害。
- 控制、易伤与追击：沼王定身，赫拉克罗斯对已有控制的目标追击并施加易伤；凯罗斯或赫拉克罗斯的易伤可为太阳伊布、巨钳螳螂提高条件伤害。前置状态、目标一致与行动顺序都影响收益。
- 毒与警戒：千针鱼主命中与一名侧击分别尝试中毒，大尾立追击施法前已有主要异常或定身的目标。毒性催化只认施法前中毒和原生主命中实际生命损失，毒伤、侧击与教学不递归触发。
- 麻痹信标：雷丘、电灯怪或十万伏特铺垫麻痹；电龙对施法前已麻痹的目标主命中扣血后，导向目标两格内最近的一名其他敌人。地面免疫与净化仍能拆掉前提。
- 灼伤喷发：火暴兽的侧击对施法前已灼伤的主目标由45%提高至65%；火属性伙伴可提供铺垫。本次主命中刚产生灼伤不计入条件。
- 治疗与接力：幸福蛋和大竺葵治疗附近其他队友，大竺葵净化主要异常；猫头夜鹰仅净化麻痹和睡眠。电灯怪治疗一位队友并给另一位附近攻击型补10能量。可与护心铃、守望回响连接；自疗、被动回复、睡觉不触发治疗联动，过量治疗不计收益。
- 双属性贯穿：刺龙王以水属性主命中，沿施法前直线对至多两名其他敌人进行龙属性侧击；伤害克制与回放材质均采用实际命中的属性。

新增条件追击均读取主命中前快照，并以主命中实际扣除生命为前提；免疫、闪避、全额护盾不会开启条件追击。有限侧击不再次施加原生联动；原有地形数量、时长、触发冷却和次数上限不变。

## 图鉴与呈现

战术图鉴新增全部/第一世代/第二世代筛选，可叠加定位、名字、属性和技能搜索，支持`generation=2&role=defense`深链。每卡展示世代、近远程、原生技能和可学技能。10套搭配参考补充18种新伙伴的加入方式与限制，准备页六条联动检查也识别新队员。

新增普通与闪光各18张水晶风格源PNG。原PNG字节保留，运行时按该资源包的调色板索引0解码透明背景；原FRNT二进制仍使用原索引3透明规则。每只新精灵有不同普攻与原生演出，恶属性采用暗色月影，钢属性采用金属切片。新增中文名和技能缺字仅在默认字库中补齐，原有字形与显式自定义资源保持原行为。

## 存档与数据来源

只迁移已验证指纹的18种和30种旧竞技存档，增补缺失新物种的完整库存。原阵容、商店、装备、技能、资源、奖励和海克斯选择不变，不重跑回合。未知指纹、删除原物种、当前版本缺少新物种与库存不守恒均拒绝。经典数据以独立查找器读取补充精灵，不合并进原151种进化查询。

金银种族值、属性和升级招式来自固定`pret/pokegold`提交`656583c939d30f920a316177311a502dd222b57c`；普通/闪光像素资源来自固定`PokeAPI/sprites`提交`8491ffde1b247e4de574d4bb8e24b7bd9fa876fa`的generation-ii/crystal目录。数据在`data/pokemon_gen2.json`，来源和逐文件SHA-256在`assets/gen2/sources.json`。猫头夜鹰特攻76、电龙防御75，采用金银口径。原生技能是本游戏设计，未写入原作升级招式表。

本版是可试玩的机制扩展，完整强度校准仍需后续多轮对局统计；自然样本与单元验证见本版验证报告。
