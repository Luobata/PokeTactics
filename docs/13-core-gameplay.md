# 13 · 核心玩法重设计：主角团 / 天赋 / 深道具 / 单体档案 · 2026-09-15

状态：**v2（已吸收 Codex 交叉评审，2026-09-15）**。评审原文见
[reports/design-review-codex-2026-09-15.md](../reports/design-review-codex-2026-09-15.md)——
其结论「方向通过；卡池/星级/事件合同修订后再进入核心规则实施」已落实到
本版：卡池参数改为目标倒推（不再拍数字）、分期重排为**三角色纵向原型
先行**（§7）、渲染端能量等推算改为事件携带权威值（§5）、内部矛盾与
旧方案收口进迁移表（§9）。对标王者荣耀·自走棋的可玩性拆解，回应用户
五个核心关注点。本文是方向文档：定系统、定数据模型、定分期；
数值全部走既有 sim-first 管线（先实验后落盘），不在本文拍数值。

## 0. 一句话诊断

当前版本的失误不在系统数量（羁绊/装备/天气/齐射/状态都有了），而在
**棋子是数据行不是角色**：84 只泛池 + 种族值推导 + 9 档模板特效，
没有一只宝可梦有"追它"的理由。王者自走棋的可玩性核心是
**英雄单体设计 × 天赋随机性 × 装备构筑** 三角，本方案把三角立起来。

## 1. 对标拆解：王者自走棋的五个可玩性来源 vs 现状

| 王者自走棋 | 玩法作用 | PokeTactics 现状 | 差距 |
|---|---|---|---|
| 英雄独立技能/演出（每个英雄一技能一特效） | 追卡目标感、辨识度 | 84 只全部种族值推导，大招=本系招牌招查表 | **结构性缺** |
| 天赋三选一（随机强化，多次） | 每局构筑差异、翻盘点 | 无 | **缺** |
| 装备合成链 + 专属装备 | 后期 build 定义 | 8 组件 12 成品，通用乘区为主 | 有骨架、深度浅 |
| 核心卡（3费4费怪）+ 三星合成 | 攒卡节奏与高光时刻 | 进化链做升级（buy→3合1→进化） | 语义绕：升级=变形不是变强 |
| 战斗演出节奏慢、技能镜头 | 观赏性（自走棋一半乐趣是看） | 战斗中位 7.5s，特效 9 档属性模板 | 节奏快、单体辨识低 |

## 2. P1 核心池：84 泛池 → 28 只「主角团」（最终形态直售）

**裁定**：上场池收敛为 ~28 只**最终进化形态**，直接按 1/2/3 费定价出售
（现 3 费档拆为 3 费旗舰 + 2 费中坚；部分弱最终形态降 1 费做开局位）。
升级语义改为**星级**：同种 ×3 → 2 星（属性 +35%），×3 → 3 星（再 +50%）。
**进化系统整体退役**（含基础形态池；进化石改造为「星级护符」：任意
2 星棋直升 3 星的稀有道具，每局一次通道语义保留）。

- 为什么砍进化：进化把"升级"和"变形"绑在一起——玩家追的是妙蛙花，
  不是先追妙蛙种子再等变形；王者式直售+三星让攒卡目标始终是那张卡。
  BST 定档的公平性成果（S2）迁移为星级成长曲线的配平输入。
  **命名纪律（评审采纳）**：最终形态不变时只叫「升星」，2 星可播进化
  风格光效作纯演出——不能让玩家误以为还会变形。
- 名单原则：17 系羁绊每系 ≥2 只载体（阈值 (2)(4)(6) 可达）；定位覆盖
  坦克/近战输出/远程主 C/功能位；招牌度优先（一代人气角色）。

**核心池 v1 名单（28 只，待用户过目可换；评审修正方向已并入）**：

| 费 | 名单 |
|---|---|
| 3费旗舰（9） | 快龙、喷火龙、水箭龟、妙蛙花、卡比兽、耿鬼、拉普拉斯、风速狗、暴鲤龙 |
| 2费中坚（12） | 胡地、怪力、隆隆岩、宝石海星、雷丘、九尾、大比鸟、三合一磁怪、呆壳兽、飞天螳螂、蚊香泳士、尼多后 |
| 1费开局（7） | 大针蜂、巴大蝶、大岩蛇、火暴猴、拉达、大嘴雀、海刺龙 |

名单待修点（评审指出，定稿前复查）：九尾/火伊布功能重复（v2 先移
火伊布留九尾，换入尼多后补毒/地）；冰系单载体拉普拉斯，扩池方向
白海狮/刺甲贝；恶系零载体——**明确暂不开放恶系羁绊**，不为覆盖数字
破坏池子。费档归属以配平实验为准，表内为初判。

**共享池张数不定数字、定目标（评审 P0 修正）**：v1 的
「1费×14、2费×9、3费×5」是数学错误——3 费每种 5 张则**九张三星
天然不可达**，2 费 9 张则一人三星须独占全量；且 draw_slot 按物种
均匀抽（不按剩余张数加权），缩物种数会直接抬高指定牌命中率
（L1-2 指定 1 费命中率 11%→46%）。张数改由目标倒推：
**每费段满足「一人追三可达、两人同行可行、三人争抢才枯竭」**，
并按下式进 R2 配平实验：
- 自然三星需要该种 ≥9 张（无人竞争时）；
- 同行二人各成二星需要 ≥6 张 + 商店预留余量；
- 命中率回归：缩池后指定牌出现率不高于现池 ×1.5（实验口径）。

## 3. P3 天赋系统（海克斯式，新系统 S13）

**规则**：R2 / R8 / R14 三次，暂停出**三选一**（1/1/1 稀有度混合），
选完进入下一准备阶段。种子协议新增 purpose `talent`（S7 分层派生，
重放/存档零成本）；bot 按估值表选择（人格加权：梭哈型偏好战力、
攒钱型偏好经济）。

**池设计（v1 约 40 条，示例 15）**：

| 类 | 示例 | 稀有度 |
|---|---|---|
| 经济 | 利息上限 +2；连胜/连败金币 +1；每次刷新 10% 概率免费 | 普通 |
| 战力 | 全体攻速 +12%；全员大招起始能量 +15；野怪轮战利品 ×2 | 普通/稀有 |
| 羁绊 | 指定一系计数 +1（视为多 1 只）；下次达成 (4) 档时全体 +10% HP | 稀有 |
| 单体 | 指定 3 费旗舰专属强化（快龙：大招后 3 次普攻溅射；耿鬼：击杀回能 40%） | 稀有/传说 |
| 通道 | 进化石免等（开局即得）；装备槽 +1（见 P2） | 传说 |

数值守则沿用既有纪律（评审补强）：一条天赋 = 一个语义（不做
「+X% 且 +Y%」复合）；单体天赋优先**行为变化**，条件数值（如
「大招期间减伤 40%」）可用但须写成显式条件而非永续乘区；**反馈环
审计**——攻速/吸血/溅射/击杀回能各自单一但可成环，入池前逐条标注
可与谁叠加；**同次三选一等预算**——三档稀有度同现时强度须同级
（否则传说恒为默认答案），稀有度表达的是「风格差异」不是「更强」；
**供给意识**——现节奏每局约 6 组件（→3 成品），天赋若再发装备
（通道类）需先测供给曲线。

## 4. P2 道具深化

- **双装备槽**：武器槽（输出向）+ 防具槽（生存向），成品按槽分类；
  组件 8 → 12，成品 12 → 20（新增：吸血/溅射/光环/复活类语义）；
- **专属装备**（每 3 费旗舰一件，9 件 v1）：只能由对应宝可梦携带，
  效果 = 行为变化或显式条件数值（暴鲤龙·龙之鳞：开战嘲讽最近敌人 3s；
  水箭龟·硬壳：大招期间减伤 40%）——单体设计的装备延伸，天赋/装备/
  档案三系统在"角色"上汇合。**死件规则（评审补）**：无对应棋子时
  可分解回 2 组件；专属占武器槽；第三槽只能由传说天赋开出且仅武器类；
- **供给先行**（评审 P1 补）：现节奏每局约 6 组件（3 成品）——双槽
  扩容前先做「掉落 ×1.5」供给实验，槽位多而装不满比槽少更伤构筑感；
  组件 8→12 需同步稀释检查（指定配方命中率回归）；
- 装备健康线换口径（评审补）：「每件 ≥5%」的分母改为**有合适载体
  条件下的选择率**（专属装备分母 = 持有对应旗舰的局），20+ 件不再
  全池同分母；
- 进化石 → 星级护符（§2）；掉落与合成门规则沿用 S5 修订。

## 5. P4 单体设计档案（UnitProfile，工作量最大也最核心）

**数据模型**（评审修正：渐进叠加，不是全面替代）：`sim/profiles.py`
只存**有理由的覆盖项**——未覆盖的字段回落到既有种族值推导链
（宪法「数据派生优先」条款不被整体推翻）。四层结构：

1. 原始物种数据（data/，保持可重建）；
2. **静态档案**（profiles：费档/定位/技能/射程/普攻节奏/覆盖参数+理由）；
3. 持有实例（星级/装备/投入/池占用——现有 OwnedPiece 扩星级字段）；
4. 战斗实例（Unit 现状：HP/能量/控制/冷却）。

```python
PROFILE[9] = {          # 水箭龟——只写覆盖项，其余回落推导
  "role": "远程坦克主C", "range": 3, "atk_interval_ms": 1600,
  "basic": {"kind": "单发水弹", "proj": "直线慢弹"},
  "ult": {"name": "水炮", "arch": "蓄力狙击", "target": "current",
          "effects": ["knockback_1", "slow_2s"],   # 有限效果枚举，可组合
          "vfx": "water_heavy", "cutin_ms": 600},
  "move": {"speed_mult": 0.8, "gait": "steady_2f"},
  "ai": {"kite": "max_range", "retreat_below_hp": 0.4},  # 有限策略枚举
}
```

- **档案三张完整示例先行**（喷火龙/胡地/卡比兽）作为模板定调；
- 28 只分批精设计：首批 = 示例外 5 只旗舰 → 次批 12 → 收尾 8；
  每批走「档案 → sim 配平实验 → 动画验收页逐只过」流程；
- **bot 同步升级**（评审 P1）：bots.py 的买入/上场/装备估值现依赖
  BST——档案棋子改用 profile.value（定位×星级×羁绊贡献），
  否则 bot 会卖掉低 BST 高星角色，平衡实验结论失真；
- **事件流携带权威值**（评审 P1）：能量/HP/位移由事件显式携带
（attack/cast 事件加 energy_after 字段），渲染器删掉
  「普攻回能 15/受击回能 10」的硬编码推算——天赋改回能后画面才不会
  失真（宪法 2.6 的补强）；
- 边界规则入档（评审补）：击退遇阻、同时移动争位、嘲讽目标死亡、
  施法被打断的裁决写成有限枚举，不留给实现自由发挥；
- 验收后台新增**档案页**：单只上场打标准靶场（三种：木桩/近战群/
  远程群），自动渲染普攻/大招/移动/受击四段动画，逐只签收；
- 特效从「9 档属性模板」升级为「模板 × 单体签名参数」（主色/形状参数/
  轨迹类型/命中行为），单只可辨识但不做 28 套全新图形（渲染器参数化）。

## 6. P5 节奏与美术

- **战斗时长：消融先行，不拍全局倍率**（评审 P1 修正）。全局减速
  不是纯美术调速——近战接敌前挨打次数、首次大招时间、治疗/DOT
  相对收益、控制覆盖率全部随之重排（近战移动倍率 0.60→0.61 就有
  61%→43% 时序悬崖的前科）。顺序：先测现状前/中/后期时长分布与
  首次施法时间 → 分臂消融（只改表现时钟/只改攻速/只改移动/只改
  能量）→ 组合定参。**14-20s 只作为中后期 1× 候选带**（前期少单位
  不拖长），25-30s 否决（整局观战时长失控）；
- **走路**：两帧步态交替（GB 风：左右脚 2 帧互换 + 1px 上下起伏），
  近战冲锋与远程走位因此可读；
- **射程表现**：远程普攻弹道可视化（弹速与射程成反比，**弹道是
  表现层且不产生因果倒置**——目标先死则弹道中途消散）；近战冲刺
  留残影 2 帧；选中棋子时准备阶段显示射程圈（设备端：脚下亮环）；
- **击杀镜头**：轻量版——击杀瞬间 0.35s 全场慢放（时间轴 ×0.3）+
  白闪，不切镜；**多杀合并、每场上限 2 次、倍速下随回放时钟缩放**
  （确定性播放时间映射，双端同参）；
- **预算三本账**（评审 P1）：模拟时间/播放时间/操作时间分开记——
  1× 累计战斗 6.5-10 分钟可接受（默认 2×），但 Web Demo 的整场
  预加载会放大首帧等待（改流式分帧加载列入 R4）；ESP32 峰值内存
  取决于事件/帧缓冲策略，弹道/步态/光环对象数设上限并进
  fx_visibility 同款预算纪律；
- 倍速/跳过语义不变（回放属性）；fx_visibility 红线与「特效不盖精灵」
  缩幅纪律（79e9d71）继续硬卡，新增步态可见性检查项。

## 7. 分期路线（v2：评审重排——三角色纵向原型先行，每期一个变量）

v1 的 R1 同时改池/经济/成长/数据模型四个变量，出问题无法归因；
R4 的全局减速又会在天赋/装备配平后重排一次价值。v2 改为：

| 期 | 切口 | 放行条件 |
|---|---|---|
| **R1 三角色纵向原型** | **不动池**。喷火龙/胡地/卡比兽三张完整档案 + profile 渐进叠加 + bot 估值改 profile.value + 事件携带权威能量/HP + 靶场页 + 签名特效 + 节奏消融臂 | 无档案棋子保持现基线（回归零漂移）；三角色行为画面一致；「围绕它组队」的欲望成立——不成立则方向重议，不进 R2 |
| **R2 核心池与升星** | 先定羁绊骨架与阵容路线（开局/转型/终局/反制），再定名单/张数（§2 目标倒推）/概率/成长曲线；进化通道正式退役（含 S2/S5 条款收口）；全局节奏在此期定参 | 同行竞争/升星时点/池守恒/经济与整局回归全过 |
| **R3 装备构筑小集** | 双槽 + 少量行为装备（吸血/溅射/嘲讽先做 6 件）+ 供给实验；验证后再扩 20 件与 9 专属 | 有真实取舍、无死件、触发链有界（效果冲突裁决表） |
| **R4 小天赋池** | 先 9-12 条（覆盖经济/战力/羁绊三语义）+ 三选一状态机（双端共用，三键全屏列表）+ purpose=talent + bot 估值；**同种子配对 + 样本外验证**，选项确有竞争再扩 40 条 | 发牌/选择/恢复一致；三选确有竞争（无恒默认答案） |

步态/弹道/签名特效随角色批次验收（不单独占期）；Web Demo 流式加载、
击杀慢镜等演出细化收在各期尾部。R1 完成即可发「三主角体验版」Demo——
**评审同款判断：三只角色在现有系统里若立不住，缩池和 40 条天赋都
救不了；立得住，后面的系统都是放大器。**

## 8. 待拍板（v2：评审立场已并入，供用户终裁）

1. **核心池名单**：评审赞成 28 只规模、反对直接定稿——九尾/火伊布
   重复已修（v2 换入尼多后）、冰系扩池方向白海狮/刺甲贝、恶系暂不
   开羁绊。终稿在 R2 骨架设计后随配平实验定；
2. **进化退役 vs 演出保留**：双方一致——玩法统一升星、2 星播进化
   光效作纯演出、命名只用「升星」；先解决三星记账（自然九张 vs
   护符通道）再正式废止 S2/S5 旧条款；
3. **节奏目标带**：评审立场=14-20s 只作中后期 1× 候选、反对全阶段
   硬指标、25-30s 否决——与 v2 §6 消融方案一致，待 R1 消融臂读数。
