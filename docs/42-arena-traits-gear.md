# 固定特性与装备分支

本文记录首批固定特性版本。当前版本已加入尼多王/水箭龟的互斥特性、天气和属性接力，现行规则与数量见[特性、属性反应与天气构筑](43-arena-synergy.md)。

本版先给12种竞技宝可梦接入固定特性，补充8件机制装备；后续版本已把固定特性铺满全部48种竞技宝可梦。特性随物种自动生效，不抽取、不购买、不占学习位或装备位。本命技能仍决定主动招式，学习技能保留每战一次的节奏。

所有特性都是原作概念在本作规则内的改编，不能套用原作完整效果。例如蓄电是受到电属性直接生命伤害后、存活时的有限回复，不是完全免疫电属性。

## 合成出口

组件仍为8种。竞技成品从19件增加至27件，有效无序配方从21对增加至29对；36种可能组合仍有7对未配置。水滴从1种成品出口增至5种，雷碎从1种成品、2条配方增至5种成品、6条配方。普通装备可重复制作，每只精灵仍只有1个装备位；幸运蛋全场上限规则保持不变。

## 联动边界

治疗、回能、防伤与护盾都以真实结算为准，空治疗、满能量、失败净化不消耗对应收益次数；护盾不覆盖更强者。装备或特性生成的治疗、净化与回能不会再冒充本命回调，因此不会形成无穷的援护循环。特性保命、防伤与护盾实吸分开统计，强化命中的差分只解释原命中，不再次加到总伤害。

准备期、侦察、精灵卡和独立特性目录说明固定被动；合成图自动使用当前装备配方。新战报补充治疗、净化、施加异常、防伤、命中挽救和削弱记录，一次特性可能产生多条收益记录，不把记录条数当作特性的实际使用次数。旧战报保持原始形态，不补写不存在的数据。

机器人只根据自己已经持有的精灵及学习技能，为新增机制装备选择可触发的携带者。普通战利品和第3、6轮组件补给沿用已有发放规则，新增装备进入竞技成品目录；不会追溯重发旧奖励。

## 查看与试验

- `/pokedex?tab=traits`：查看48种特性的触发条件、次数和定位；覆盖提示为48/48。
- `/pokedex?tab=items&view=recipes`：查看8种组件的合成矩阵，点击交叉格了解配方与机制限制。
- `/pokedex?tab=builds&core=68`：对照怪力的四臂续战与四臂脉冲路线；汲取之牙把普攻实伤转为自疗，脉冲腕带把有效普攻转为回能。
- `/scenarios`：使用预置联动场景观察回能、护盾和援护接力，战报记录实际生效收益。

幸福蛋的治愈之心负责足量本命治疗后的净化，甘露坠饰负责把治疗接到原患者附近的第三位受伤队友。两者各有独立条件，第三位队友未受伤时不会产生接力收益。装备或被动生成的治疗不再触发这条本命链。

本地完整回归1140项通过，32场预置自然战斗与4次确定性复跑检查了账本、来源及触发上限；具体自然覆盖范围与中央语义审查未执行的限制见[本版验收报告](../reports/arena-traits-gear-2026-10-07.md)。

## 后续观察

先观察固定特性是否能改变站位、队友和装备选择，以及水滴与雷碎能否被不同阵容利用。自然战斗触发检查只证明机制能发生，不代表商店成型概率、胜率或平衡已得到验证。若同物种仍缺少分支，再考虑可规划的互斥特性选择。
