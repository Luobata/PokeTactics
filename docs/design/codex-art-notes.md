# PokeTactics · GSC 视觉重设计说明

设计核心：以暖米色双线窗框、灰绿／沙色道馆地砖、红 HP 槽统一三屏和动画。高饱和度留给原作精灵，属性和费用退到脚下的细环与铆钉。所有轮廓落在整数像素上。

## 各区域的改动

### HUD 与字排

28px 高度保持不变。HP、金币、等级、回合、模式分别放入统一切角双线窗，数字共用 5×7 点阵字。心形、硬币和播放符号也落入容器，不再裸浮。

中文继续使用原 16px 字库；英文招式名按 8px 字宽排列，避免 `Solarbeam` 被拉成长串。消息按实际像素宽折行。绘制层补入字库缺失的“拔”“群”“…”三个 UI 字形，不修改 `Font16`、字库文件或解码器。

### 棋盘与中场

删除原来的高对比满屏斜纹，改为低反差交错地砖、1px 砖缝与少量角落刻点。沙色和灰绿在明度接近的情况下区分敌我；中场以墨灰／米色窄带和三枚菱形铆点分隔。

静态稿继续使用 6×6、40px 格、棋盘起点 `(0, 28)`。准备页为敌方三行、我方两行、备战一行；备战区使用嵌入式暗槽。动画继续使用 7×6、34px 格、起点 `(1, 28)`，保持与模拟坐标一致。

### 底座与选中态

底座分为落地阴影、旧金灰台面、墨灰内芯、属性细环；第二属性只占内侧弧线。费用彩点从棋格四角移到底座前沿，合并成 1–5 颗小铆钉。选中格使用带深色衬线的米色 L 形角标。

棋子按原图不透明部分的脚底对齐底座。战斗 HP／能量移至脚下，减少原稿血条穿过精灵面部的问题。原生 40／48／56px 精灵在 34px 动画格上仍允许前后遮挡，不以压缩素材解决密集近战。

### 商店与准备页信息

保持底部 48px、五个 40px 商品槽和右侧操作列。每个商品使用米色头像视窗与独立价格底栏；精灵以原尺寸显示，视窗仅裁去超出区域的下身／边缘，避免相邻商品串格。右列用刷新环箭头和经验上箭头，加费用数字。

删除在 4px 棋盘／商店间隙中绘制 16px 文字的做法。选中信息放到准备页空白后场的独立小窗，内容与当前选中的小拳石一致；4px 间隙恢复为结构分隔。

### HP、能量、伤害与消息

HP 统一为深槽＋朱红填充＋浅色端帽；能量使用哑金细槽，满能量沿用原有相位闪烁。零血量和零能量不绘制填充像素。低血警报仍按原相位切换深浅朱红。

普通伤害用纸色、大招用哑金、克制用浅朱红，均置于有描边和底影的小牌。动画保留原弹出、上升和消隐时间，只减小字号；同帧数字牌优先避开其他数字牌与精灵轮廓，移得较远时用细引线关联受击位置。

战斗消息窗使用与静态稿一致的暖米色双线框。动画原棋盘下方空白区变为固定日志窗，显示已有消息或自动战斗状态，并保留原消息出现／消退条件与闪烁光标相位。

### 特写与结算

特写采用左上目标、右下施法者的斜向对战站位，两侧都有暖米色名牌和 HP 框。舞台用三阶硬边色块表现渐晕与聚光，椭圆落脚台与棋盘底座呼应。招式类别位于顶部条，效果提示和伤害放在左侧留白，底部保留完整招式消息。

大精灵只做 2× 最近邻整数像素复制。精灵本体不做白闪、变色、镜像或步行压缩；原命中／濒死闪白时刻改画周围或脚下的十字星闪，原位移与消失相位保留。结算横幅同样使用双线框，按真实字宽居中，修正原来的右侧文字溢出。

## 为什么更接近 GSC

界面的识别主要来自受限色板、硬边像素、浅色双线消息窗、紧凑点阵数字、带端帽的 HP 槽和对角对战站位。背景降低对比后，原作精灵的轮廓与色彩更突出；边框、底座和状态条重复使用同一组颜色与线宽，使三张静态稿和动画形成同一套界面。

所有公用绘制组件位于 `render_mockups.py`，动画直接复用；两套棋盘只传入各自原有几何参数。没有新增素材下载、运行参数、依赖或随机源。

## 第 2 期：自动对战特效

本期把普通棋盘战斗的节奏串成“突进留影 → 属性火花落点 → 1px 顿挫”，同时补上步行、满能量准备、阵亡和开战反馈。颜色继续使用上期的米纸、旧金灰、哑金与低饱和属性色；当前帧精灵保持原尺寸和原调色板。最明显的提升是普攻落点：挥击弧现在有对应的受击火花，震屏又把这个落点传达给全场。

### 设计意图与参数

| 特效 | 设计意图 | 绘制参数与时序 |
| --- | --- | --- |
| 普攻命中火花 | 让挥击明确落在受击单位身上 | 从已有 `attack` 后 0.1s 的突进相位开始，持续 2 帧；每击 4 瓣，拥挤时降为 3 瓣。采用攻击者主属性色与纸色端点，1–2px 短线从半径 4px 向外扩至 11px，并沿正弦弧上扬至 4px。伤害为 0 时不生成命中火花。 |
| 攻击拖尾 | 把短突进变成可读的发力动作 | 攻击后 0.1–0.3s 显示两层属性色剪影，沿攻击反方向偏移 7px／4px，透明度 32／64（满值 255）。持续约 2 帧，原精灵最后覆盖；挥击弧同步进入这一相位。 |
| 移动残影 | 为一次走格增加速度感 | `move` 插值后的第 1 个 100ms 相位只画 1 帧；取前一帧插值位置差的 45% 作向后偏移，旧金灰、透明度 48。与攻击拖尾同帧时优先攻击拖尾。 |
| 蓄力吸能 | 让施法准备阶段有向内汇聚的方向 | 每次 3 粒，采用大招属性色与纸色亮点；半径由 21px 按二次曲线收至 3px，纵向压至 65%，持续 0.35s（至多 4 帧），叠加原有双光环与星闪。排队大招沿用已有切镜前 `CAST_WINDUP`；即时大招的准备起点从已回放事件中首次达到 80 能量的时刻推导，避免原即时 `cast` 没有可见抬手的问题。 |
| 命中震屏 | 用 GBC 的整数像素顿挫统一全场反馈 | 普攻火花出现时向下 1px、1 帧；有伤害的大招在已有切镜落点时向下 2px、下一帧向上 2px，大招优先。只裁切平移棋盘内容，包含精灵、特效和状态条；HUD、棋盘外框与日志保持原位。 |
| 死亡消散 | 在下沉与消失之间留一个轻的收尾 | 从 `die` 起持续 4 帧，3–4 个主属性色粒子；竖直上升至 16px，水平漂移幅度 2px。最后一帧即使精灵已隐去仍绘制粒子，星闪与粒子均计入预算。 |
| 开战演出 | 开场先给一个明确节拍，再进入走格 | t=0 的第 1 帧为整盘纸白闪，透明度 176；“开战！”横幅持续 0.4s／4 帧，使用双线消息窗。横幅放在固定日志区，适应随机入场阵型；白闪之后重绘状态条。 |
| 能量满辉光 | 在底座提示即将具备大招条件 | 能量 ≥80 且未阵亡时保留哑金内环，外加 1px 纸色微光。6 帧为一个呼吸周期，透明度按 48、80、112、112、80、48 切换；能量清零即退出。 |

蓄力阈值的临时计数仅用于定位视觉相位；不回写能量，不修改游标，也不读取尚未回放的事件。所有新轨迹、漂移和呼吸只取事件时间、方向、单位编号和帧相位，没有新增随机源。普通伤害读数、受击位移、切镜调度及结算时长保持原契约。

### 特效与动作规则

变体使用 `(floor((t + 1e-9) / 0.1) + unit_idx) % 2`，即稳定取整的 `(t*10 + unit_idx)` 奇偶交替。切镜与棋盘落点共用第二轮廓：电为双叉闪电、火为爆燃环、水为环形水花、草为四叶绽放、虫为蝶翼、超为菱形念场、幽灵为双螺幽魂、毒为破裂毒泡、恶为交错月牙、冰为六角雪晶、斗为拳压方环、岩为棱角岩簇、地为分叉地裂、钢为旋转刀片、普为交叉斩线、龙为彗尾、飞为双卷风刃。第一变体保留原有八类图形语言。切镜旧有的 seeded RNG 闪电也改为时间／序号的整数公式；剩下的 `random.Random(seed + 1)` 仅用于原模拟器战斗生成，视觉层零随机。

伤害以目标 maxHP 为分母，**轻 <6%、中 6%–<15%、重 ≥15%**，阈值用整数交叉相乘。轻击用小白芯与空心冲击环，中击保留标准爆花，重击增加粗十字。普攻基础爆点半径为 11／18／22px，逐帧扩张；第二变体轮廓更尖、半径另加 4px。普攻震屏保留两帧，轻／中为 ±2px、重为 ±3px；大招保留三帧，普通为 ±3px、重为 ±4px。拔群保留红环，另加八根放射短线，与伤害档位分别判断。每次普攻仍有 8 粒、大招仍有 12 粒，粒子整体沿攻击向前漂移，属性继续控制锥形、抛物线、环绕或升腾轨迹。

重击与所有大招落点留下 **8 帧**地痕，使用 14 个 2×2px 属性色簇与一条浅裂纹；透明度为 112／98／84／70／56／42／28／14。印记在地砖之上、单位之下，落点取命中时已经发生的最后一次部署／移动格，不跟随目标移动，不增加事件或回放状态。结算后的 0.6s 再乘淡出系数，预渲染结算背景不保存旧地痕，避免冻结残留。本期未加入缺少事件证据的护盾／伤害上限反馈，也未采用可选连击标记。
