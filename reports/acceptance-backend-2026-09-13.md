# 验收后台上线 · 2026-09-13

**需求**（用户）：参考 ESP 项目的预览服务做一个验收后台，后续验收都在后台进行；
动画先行上稿待验收；并学习其渲染引擎的动画逻辑。

## 从 PokeWalk 学到的四条（直接落进实现）

| PokeWalk 经验（docs/11、12） | PokeTactics 验收后台的对应 |
|---|---|
| 浏览器不自行计算画面，只消费后端产出的帧 | 帧由本地 Python 渲染器产出（M4 换 C 内核），浏览器 canvas 只 drawImage |
| 确定性时间轴：暂停/单步 60ms、标签页隐藏停钟 | 播放器支持暂停/单步（←→）/0.5-4x 倍速，`visibilitychange` 自动停钟 |
| 构建按源哈希键控 | 帧缓存目录 = `seed + render_battle_gif.py 源码哈希`，改渲染器自动失效缓存 |
| stdlib HTTP + `/api/*` JSON 路由 | `SimpleHTTPRequestHandler` 扩展，`/api/prepare`、`/api/reports` |

## 交付：`tools/acceptance/server.py`（stdlib 服务 + Pillow 渲染）

- **首页 `/`**：验收清单——待验收项（战斗动画 v3，附验收点清单）、静态设计稿
  （prep/battle/cutin HD + 分镜）、全部验证报告链接；
- **动画验收台 `/anim?seed=N`**：双栏布局——左侧 240×320 canvas（2x 整数放大、
  pixelated）+ 播放条（空格播放/暂停、←→ 单步、0.5/1/2/4x 倍速、进度拖拽），
  右侧**事件流面板**（82 条事件随播放时间高亮滚动）——动画与事件流同屏对照，
  这正是「渲染端=事件流回放器」契约的日常验收形态；
- **帧生成**：`/api/prepare?seed=N` 按需跑 sim 战斗并渲染 PNG 帧（首次数秒，
  之后命中缓存）；`/frame/<key>/<i>.png` 供帧；
- `.build/` 加入 .gitignore。

## 端到端验证记录

- 全端点 curl 冒烟：`/`、`/anim`、`/api/prepare`（95 帧/82 事件/胜者 A）、
  `/frame/...`（PNG 240×320）、`/mockups/...`、`/api/reports` 均 200；
- 真浏览器（IAB）端到端：播放/暂停/时间显示（1.5s/9.5s）、事件面板 82 条渲染、
  canvas 画面与右侧事件高亮同步，截图确认；
- 过程中修掉一个页面模板的语法错误（多余 `]` 导致整段 JS 不执行）——
  教训：服务端模板拼 JS 需要最小冒烟（本次靠 evaluate 重放定位）。

## 启动

```sh
python3 tools/acceptance/server.py --port 8799   # http://127.0.0.1:8799/
```

## 后续演进（对齐 M4）

C 内核落地后，本服务的 `/api/prepare` 换成调用 native 进程编译执行固件渲染代码，
浏览器协议不变——届时升级为 PokeWalk 式「固件同源预览 + 像素对账」。

## 改版（同日第二版）：视觉语言对齐 PokeWalk inspector

用户反馈首页粗糙，「抄 ESP 项目」——直接采用 PokeWalk firmware.html 的设计语言：
米纸底 `#f2efe5` + 墨绿字 `#29302b` + 奶白控件 `#fffdf5` + 深绿设备壳 `#363e35`、
等宽字体、双栏 grid、绿色 primary 按钮、note 竖线提示块。

- **首页**：header 双线 + 待验收项（primary 载入按钮 + 折叠验收点清单）+
  设计稿卡片网格 + 报告列表；
- **动画验收台**：三栏——左设置（种子输入 + 载入场景 + 倍速 + 像素缩放 +
  快捷键说明 + 验收点）、中舞台（设备壳 + 240×320 canvas + 三大键 |◀退/⏯/进▶|
  + 进度条 + 单步 0.1s + **保存 PNG**）、右事件流面板（高亮同步）；
- 模板拼 JS 从 `.format` 改为占位符替换，杜绝花括号转义类语法错误
  （上一版多余 `]` 的教训）。

改版过程中视觉复核抓到并修复两个问题：
1. **首帧不上屏**：帧加载完成回调没有重画，画布一直空白——首帧到达立即
   `show(0)`，全部到达后重画当前帧；
2. **低视口挤出行**：2x 画布（480×640）把控制键挤出首屏——视口高度 <760px
   自动退 1x（PokeWalk 的「像素缩放」选择器保留手动切换）。
