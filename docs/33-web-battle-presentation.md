# 网页战斗画面

竞技试玩、竞技动画实验室、编辑器和新样片通过 `presentation_modes` 共用 `WebBattleRenderer`，在 960×640 画布上绘制六列、双方各三行的森林竞技场。显式经典模式与设备样片继续使用原尺寸渲染器，网页呈现不修改战斗规则或事件。

`BattleAnimation` 仍负责把模拟事件转换为演出时间轴。网页渲染器读取同一个演出视图，所有移动、命中、生命、能量、护盾、地形与死亡都随该时间轴推进。向过去拖动时重新回放已发生的事件，不读取模拟单位的最终生命来绘制中间帧。

网页帧 metadata 增加 `presentation` / `render_revision`、开场 `combatants` 和逐帧 `team_frames`。后者记录双方当前存活数及生命总量，长度与 `n` 一致；顶部比分使用对应帧的数据。最终 `statistics` 仍来自这场权威战斗，只有末帧或主动查看战果时展示。

浏览器只解码当前位置附近的帧，并限制缓存数量。远距离拖动与重播按需加载；加载状态与播放位置分别记录。关闭弹窗取消未完成请求的回调和计时器，旧回放的迟到结果不能更新新回放。帧载入失败保留明确的继续结算入口。

保留暂停、倍速、全场阵容、下一轮、重开一局与历史统计入口。已有存档不包含动画帧时继续显示已保存的战果和统计，不重新模拟历史战斗。

## 身体部件动作与发射点

`web-arena-v2-articulated` 增加独立的 `web_motion` 局部关节管线。怪力的四条手臂分别拆成肩部与前臂，使用原图的多边形轮廓掩码分层；每只手都有独立的旋转轨迹和拳头锚点。蓄力抬臂、四拳交替释放、收招分别采样已有 `ActionTiming.start/release/impact/recover_end`，不会增加战斗时长或提前结算伤害。雷丘的双耳与尾巴、巨钳螳螂的双钳与双翼也采用局部动作。原有喷火龙、水箭龟、妙蛙花继续使用已有身体部件管线；其余精灵保留原动作，尚未为全部 48 种制作关节。

关节素材保留原像素颜色，使用最近邻采样与局部接缝覆盖；脚锚固定，镜像同时变换部件和发射点。冻结采样停在状态首次生效的时刻；死亡停止关节动作并由原淡出流程接管。采样不写回模拟单位，进度与源图缓存有固定上限。

蓄力材质按属性区别：火焰上升、电弧聚集、水滴汇流、格斗收拳、钢刃反光、草叶旋转、冰晶生长、超能环轨等。网页特效从可见的拳头、双炮口、嘴或脸颊锚点出发。弹道起点固定在释放时的位置，避免施法者后续移动改变已发出的弹道；命中闪光、扩散粒子与四拳轨迹均服从原命中时刻。蓄力阶段不叠加大块技能图案，以保留身体动作的可见性。

## 打击感层(v14)

`web-arena-v14-impact-r1` 增加仅作用于呈现的打击感层,不再坚持早期"命中窗口固定、震屏 0px"的约束(经需求方确认):

- **双时钟**:`frame(seconds)` 仍是模拟时钟契约(第 s 秒显示模拟时刻 s),供实验室、编辑器与契约测试使用;`frame_playback(seconds)` 是观众时钟,在重击(原生大招、击倒)命中点插入 ≤90ms 的确定性停顿(hitstop),全场停顿预算 0.6s,其余区间以 ≤1.05 斜率补回,总时长不变。`presentation_time(t)` 给出逆映射,回放帧与 meta 的 events/fx 时间戳一律使用观众时钟。
- **震屏**:命中瞬间战场层做 1.2–4px 阻尼震动(普攻/大招/击倒三档,合计上限 5px),由命中序号确定性驱动,可任意 seek。血条、能量条与底部 HUD 在震动之后绘制,逐像素稳定。
- **命中强调**:每个真实命中点绘制元素色径向闪光(击倒为白闪)、贴地冲击波环与带重力碎屑,计入既有 192 粒子预算,1/3 分辨率最近邻放大,与像素风一致。
- **受击反应**:`retro_feedback.body_cue` 增加 weight 参数,重击压缩量与白闪增强(有上限),脚锚与关节锚点配准不变;weight 缺省时行为与 v13 逐字节一致。
- **氛围粒子**:按天气(雨涟漪/晴光尘/沙飘沙)或无天气时的近地浮尘,低密度、确定性点阵,绘制在单位层之下。
- 四个特性各有模块级开关(`IMPACT_SHAKE / IMPACT_HITSTOP / IMPACT_ACCENTS / AMBIENT_PARTICLES`),默认开启,可单独回退。以上全部只是画面呈现,不改事件、伤害、时长与结算。
