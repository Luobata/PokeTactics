# 竞技原生技能定位与构筑组合

本版适用于 `arena_v1`。48种精灵各有一个固定原生技能，战斗中按80能量反复施放；另有一个学习槽和一个装备槽。经典规则继续使用原招式体系。图鉴、试玩卡片、对局事件、动画预览和调试演出读取同一份原生技能元数据。

## 1. 定位应当决定行动

技能除了属性与威力，还公开 `targeting`、`category`、`behavior`。目标分为敌方、友方、自身和地形；辅助动作不进入敌方伤害或异常判定。13种精灵进行纯友方支援，尼多后与风速狗使用自身姿态，大岩蛇铺设地形，其余32种技能有敌方主命中，包括妙蛙花的伤害反哺。

职业保留基础数值差异：攻击型攻击与特攻提高12%；防守型生命提高25%、减伤18%，攻击与特攻降低15%；辅助型攻击与特攻降低20%，每秒获得4能量，眩晕或死亡时暂停。删除全体辅助每4秒自动治疗的旧规则，让治疗、护盾、净化与回能各自形成选择理由。辅助的原生支援范围统一为曼哈顿距离两格，普攻距离仍单独显示近战／远程。

治疗技能只在有有效治疗目标时消费能量。净化、护盾、回能、救援各自判断可用目标；无人受伤并不妨碍有价值的护盾或回能。无法提供支援时保留80能量，可以继续普攻或移动，不会替换成经典攻击大招。学习睡觉且生命不高于50%时，仍先使用这次自疗。

| 巴大蝶 #12 | 净化蝶粉 | 优先净化一名带主要异常友军，再回复15%，可支援自身 | 处理单个关键队友的异常；没有异常时治疗弱者 |

| 魔墙人偶 #122 | 屏障接力 | 其他友军获得14%护盾及20%减伤，均持续3秒 | 护盾和减伤组合；不治疗、不净化 |

| 猫头夜鹰 #164 | 守夜安抚 | 优先解除其他友军睡眠或麻痹，并补16能量 | 解控与施法节奏；不清除中毒、灼伤或冰冻 |
| 电灯怪 #171 | 灯塔接力 | 为至多两名其他友军各补14能量，优先攻击型，再按能量排序 | 集中加速输出；不提供生命或护盾 |
| 幸福蛋 #242 | 幸福合唱 | 至多两名其他伤员各回复18% | 群体急救，不能治疗自身 |

所有回能按实际空余容量结算，能量上限80。受益者等到自己的下一次行动才施法，不会在支援动作内部立即连锁施法。

护盾使用一个共享槽：更强护盾可以替换，更弱或等量护盾不能延长现有强护盾。护盾不是治疗，吸收量和生命承伤分开统计；临时减伤也有自己的强弱与到期判断。

## 3. 前排与输出的技能身份

风速狗的炽焰守护不直接攻击：获得3秒30%减伤，嘲讽两格内至多两名敌人2秒。每个敌人有4秒嘲讽间隔；被嘲讽者优先攻击施法者，施法者死亡或效果到期后恢复普通索敌。敌方的特殊索敌同样遵守有效嘲讽。

尼多后的毒刺护甲不直接攻击：获得3秒25%减伤及反击姿态。受到两格内敌人的有效主攻击伤害时，以35威力毒属性反击并尝试铺毒；每次姿态至多反击3次。反击不引发另一次反击或主受击回能。施法来源与当前触发攻击分别记录，回放把反击放在触发命中的时刻。

大岩蛇的岩钉场只铺地形。铺在目标所在格时不立即扣血，站立不受伤，进入敌方岩钉格才触发。前排推移负责制造第二步，地形与击退不是一次动作自动保底的额外伤害。

| 功能 | 精灵与差异 |
| --- | --- |
| 连锁与范围 | 雷丘至多跳跃两次，55%／35%；喷火龙主目标周围至多两名敌人各50%；毒刺水母侧击40%并自我减伤；电击兽与电龙需要预先麻痹才导流；火暴兽预先灼伤时侧击从45%提高到65% |
| 多段与收割 | 怪力追加至多两次30%追击并击退；巨钳螳螂追加两次20%，预先易伤时变为35%；大尾立在施法前目标生命不高于35%时追加一次60%收割 |
| 瞬移与控能 | 胡地寻找残血敌人的合法邻格；耿鬼选择射程内能量最高的敌人，偷取至多20并获得其中一半；呆壳兽影响主目标和其邻格至多两名敌人的能量；月亮伊布控能并保护一位队友 |
| 铺毒与破甲 | 尼多王对预先中毒目标追加40%；千针鱼铺毒并追加一名侧目标；凯罗斯施加12%易伤；太阳伊布对预先易伤目标追加50%；赫拉克罗斯既施加易伤，又能利用预先控制追击 |
| 定身与控制追击 | 蔓藤怪、沼王在有效生命损失后定身；飞天螳螂、赫拉克罗斯对预先定身／冰冻／麻痹目标追加35%；大力鳄先定身，后续利用控制推移；隆隆岩震击并尝试造成短暂畏缩 |
| 推移、贯穿与清场 | 飞腿郎、肯泰罗、怪力、水箭龟、大钢蛇等击退一格；水箭龟水属性贯穿，刺龙王水属性主命中加龙属性贯穿；化石翼龙清除附近至多一格敌钉，战舞郎清除至多三格 |
| 地形壁垒 | 班基拉斯对施法前位于本队岩钉上的存活目标尝试击退，否则铺钉；当次新铺岩钉不能反过来触发当次击退 |

条件来自施法前快照。当次主命中新造成的麻痹、灼伤、易伤或定身，不能激活同一次动作的条件追击。大尾立主命中把生命从35%以上压到35%以下，也不会立即获得收割。主命中之后死亡的施法者不再启动新的追击。

## 4. 原生技能与学习槽

原生技能固定精灵身份，学习槽提供有限补位。学习不改原生技能、不消耗其能量，每场教学最多一次；下一场重新获得这一次机会。同一精灵只有一个教学槽，替换需要重新支付费用，旧教学不退款，技能机必须符合该精灵的属性限制。

竞技模式当前开放九种教学：居合斩、冲浪、睡觉、十万伏特、冰冻光束、污泥弹、地震、吼叫、高速旋转。睡觉在受伤阈值使用；竞技冲浪及六种新增攻击／位移教学跟随首次成功且主目标仍存活的普攻。居合斩在成功普攻后斩击邻近敌人，主目标被普攻击败也不阻止邻目标斩击。冲浪以35威力水属性攻击主目标与其邻格至多两名敌人，适用于水属性纯辅助；原生施法不会触发或消费它。经典冲浪仍跟随原生大招命中施放侧波。十万伏特、冰冻光束、污泥弹可以提前铺垫状态；吼叫补击退；高速旋转补清场。纯辅助可以使用攻击教学，教学攻击不会使它的原生支援变成攻击技能。

每种教学有独立事件名称与受益目标。教学、侧击、反击、持续毒伤和岩钉不冒充原生主命中；教学回合与原生循环也不互相消费。护卫、晴天、求雨属于战术规则，不列入竞技九种教学。

## 5. 可组合的构筑

| 构筑 | 组成与顺序 | 有效条件与反制 |
| --- | --- | --- |
| 续航转节奏 | 胖可丁／吉利蛋／幸福蛋等原生治疗 + 护心铃 + 守望回响 + 两格内攻击型伙伴 | 护心铃要求对其他队友的实际回复达到其最大生命5%；提供8%护盾3秒、携带者冷却4秒。回响补8能量、每名辅助冷却4秒且每战至多3次。自疗、睡觉、剩饭、纯护盾或纯回能不触发 |
| 岩钉推阵 | 大岩蛇／班基拉斯 + 陷阱透镜 + 飞腿郎／怪力／水箭龟／大钢蛇，或吼叫教学 | 先铺钉再推入，有空位和正确方向才有效。厚底靴免疫入格岩伤，高速旋转与清场精灵能移除敌钉 |
| 反击铺毒 | 尼多后前排承伤 + 尼多王追击 + 毒性催化，或相容队员先用污泥弹 | 先中毒，后由原生主命中造成实际生命损失。催化每次补8能量，冷却2秒、每战至多3次；首次铺毒、反击、侧击和毒伤不自我触发 |
| 破甲集火 | 凯罗斯／赫拉克罗斯先施加易伤 + 太阳伊布／巨钳螳螂后施法 | 易伤12%、持续4秒、单槽刷新不叠加；需要同一目标与施法先后，追击不能再递归触发 |
| 控制收割 | 蔓藤怪／沼王定身或冰冻光束铺控制 + 飞天螳螂／赫拉克罗斯追击 + 大力鳄推移 | 定身1.5秒，每个来源每战至多3次；定身不禁止攻击或强制移动。净化解除的主要异常与定身是不同机制 |
| 麻痹导流 | 雷丘或十万伏特铺麻痹 + 电击兽／电龙导流 | 麻痹概率、控制保护、单主要异常、地面免疫与敌方站位共同影响成功率 |
| 灼伤轰炸 | 喷火龙／火属性伙伴先尝试灼伤 + 火暴兽范围追击 + 相容火伤装备 | 需要预先灼伤，不能用火暴兽这次主命中反向满足条件；属性抵抗与分散站位降低收益 |
| 施法加速与拒能 | 宝石海星／电灯怪加速高能量队友；耿鬼／呆壳兽／月亮伊布压制敌方能量 | 支援不自我回能、能量不会溢出80；攻击型优先与最高能量优先是不同选择。不能无限即时连锁施法 |
| 主动保护 | 风速狗吸引攻击 + 皮可西单体大盾，或魔墙人偶减伤盾、拉普拉斯群盾 | 保护替代生命恢复，需在承伤前施放；反击次数、嘲讽间隔、护盾到期和单槽规则限制持续压制 |

这些组合强化选择与顺序，没有把凑齐几个组件视为必胜。场上人数、站位、属性免疫、受伤程度、有效治疗量、能量时机、教学位和装备位共同限制收益。

岩钉每队最多三格、持续6秒。单次入格伤害以最大生命6%为基数，岩属性倍率最多按2倍计算，陷阱透镜提高25%，最终单次上限12%最大生命；同一目标触发间隔1秒，每片地形对其最多两次、每战总计最多四次。护盾可以吸收入格伤害，站立不反复扣血，地形伤害不获得主受击回能、不铺异常、不递归推移。

## 6. 表现、统计与兼容

施法事件记录真实目标：治疗／净化／回能从施法者到友军，护盾在受益者身上展开，自身姿态围绕施法者，地形使用实际落点。回能与护盾不出现生命恢复数字；治疗数字来自真实 `regen`，同一治疗不会重复显示。反击使用当前攻击的接触时刻，不重新播放先前姿态施法。

战报伤害使用实际生命损失，治疗量使用有效恢复，护盾吸收独立记录。治疗溢出、全额吸收和仅请求的伤害不计入错误的输出或承伤；历史报告不会被新技能规则重算。

已验证的升级前指纹为 `14536e0d3642dda0ac35f764c565d580e117cd8c5931732c198c8e68056b7214`。其存档已经包含48种卡池、完整教学字段、奖励账本和本局战报，迁移只更新规则指纹并给出提示。它不能走早期扩池补字段的回退，缺失卡池、教学、战报或不一致结算仍拒绝。阵容、星级、装备、教学、海克斯、金币、商店、待选项、奖励、胜负与历史统计保持原样；读取不会执行开回合、战斗、抽奖或发奖。未知新指纹仍会阻止静默加载旧备份。

兼容测试使用冻结升级前模拟器生成准备／战后场景；经典对照使用相同旧模拟器的四个固定种子，验证胜负、时长、生命和有效统计。规则与表现测试覆盖有用目标、无目标保能、免疫、封疗、上限、期限、教学次数、施法所有权与回放重复 seek。实际存档库通过只读校验与字节哈希核对，验证期间不写回或迁移到磁盘。
