# 持续状态与场地特效改造

按异常状态、护盾与增益、岩钉、天气顺序集成。只修改呈现，不修改战斗数值、事件顺序和随机源；回放前进、倒退和直接跳转必须得到相同画面。

1. 灼伤、中毒、麻痹、睡眠、冰冻使用不同的局部身体形状，定身与易伤使用脚部标记。徽标优先显示控制与关键负面状态，最多四项，剩余项显示 `+N`；层数仍可见。
2. 常驻叠层最多一个防护主层、一个充能/增益标记和一个湿润脚部标记。防护优先级为护盾、减伤、反击架势；短暂施加、命中、净化反馈仍由真实事件驱动。
3. 保留分面岩钉造型，范围使用低亮度队色脚印。每个区域只显示一个标签，最后一秒逐渐淡出。清除、到期、进入、免疫有不同的短反馈。状态只在记录的移除事件发生时消失；剩余时长从模拟时钟转换到呈现时钟。
4. 天气显示剩余秒数。同天气重复申请不播放切换提示，也不延长现有呈现截止时间；实际切换与到期保留提示。

验收覆盖真实场景、合法模拟事件构造的状态生命周期、同天气重复请求、部分清场、倒退重放、源事件哈希、预览缓存版本及接口健康。图像诊断样本与真实对战分别记录。
