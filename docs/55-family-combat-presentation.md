# 家族普攻与本命演出补齐

## 范围与验收口径

本轮补齐 `families_v2` 中原有 62 种普攻注册以外的 89 个可部署形态：丰缘 31 个，以及前置形态、伊布分支与暴鲤龙等 58 个。原有战斗数值、目标选择、伤害事件、卡池与存档规则不变。

每个形态登记普攻主题、本命主题、身体发力与发射位置。家族共享视觉语言，进化阶段调整轨迹、规模与节奏；不再统一显示「家族冲击」。本命保留真实技能 ID，视觉不靠改名、换属性或复用另一个物种的身份接入。

这轮给 88 个形态新增原贴图整身发力轨道；暴鲤龙沿用已有轨道。没有增加源图切片或重绘角色，也不将整身位移、旋转、缩放称为四肢独立动画。目录继续单独显示身体、部件、特效三项覆盖。

## 接入约束

- 实际试玩、动画实验室使用同一套分发，不能只有目录标签显示「已完成」。
- 前置形态共享旧技能机制时，以实际施法者选择图形；水伊布不会因共享守护机制而播放风速狗的火焰。
- 丰缘的技能事件使用机制键、施法事件使用物种技能键。关联时同时校验真实父事件和机制映射，避免丢失连击、治疗等子事件的归属。
- 普攻及敌方本命的接触图形须对应有效生命伤害；未命中、免疫或完全被盾吸收时不补画虚构的伤害接触。实际护盾、治疗、控制反馈仍由其结算事件显示。
- 特效只使用真实来源和目标；不生成额外受击者、假地形或额外伤害。释放后的发射位置固定，不跟随角色之后的移动。
- 可调整色板、特效规模、粒子密度与身体幅度；支持暂停、逐帧和回卷。特效规模保持局部，身体可单独放大验收。

## 动态验收

`/animation-lab?mode=arena&species=257&kind=cast` 打开火焰鸡。页面新增家族样片入口，可切换本命、普攻与「仅身体」，沿同一时间轴检查蓄力、释放、命中和恢复。

## 验证结果（2026-10-18）

- 相关回归测试 109 项通过，含 89 形态覆盖、真实本命与子事件归属、有效伤害接触、身体采样与发射点、前端取消/重试/切换、旧角色演出。记录见 [测试日志](evidence/family-vfx-tests.txt)。
- `python3 tools/acceptance/family_vfx_probe.py` 对 89 个形态 × 2 种动作各采样 3 个阶段，共 178 条动作、534 张真实战场帧；全部通过回卷像素一致、事件不变与非静态检查。见 [覆盖报告](evidence/family-vfx-probe.json) 与 [代表分镜](evidence/family-vfx-contact.png)。
- 本机抽帧耗时中位数 18.89 ms、p95 30.42 ms，冷启动最大 708.04 ms。这是独立样片的服务端绘制耗时，不代表满场战斗帧率或浏览器呈现帧率。
- 浏览器实测：火焰鸡本命 37 帧、普攻 33 帧以及仅身体视图均播到末尾；暂停、阶段定位与逐帧正常。沙奈朵守护 38 帧播完，生效目标为实际友军怪力，护盾由 0 增至 424。见 [实验室截图](evidence/family-vfx-lab.png)。
- 独立审查结论为 `pass`。审查发现并修复兼容渲染缺少 `PIL.Image` 导入的问题；补充两套新特效包在 RGB / RGBA 画布的四阶段回归。
- 8813 服务已加载新渲染版本 `web-arena-v18-family-effects-r1`。重启前备份本地存档；本轮未修改 `sim/`、`data/` 或源角色素材。

这批演出完成的是当前竞技池的普攻/本命覆盖；家族共用视觉语言，进化阶段有尺度、轨迹或节奏变化。它不表示每个物种已有逐帧重绘或独立四肢动画，后续视觉精修可直接在这些动态样片上验收。
