## 1. 教学总纲：非模态四铁律

三键 + 240×320 上不能做弹窗轰炸——弹窗每弹一次就打断一次操作流，
而准备阶段的操作流（γ 光标拿起放下）本身就是要教的肌肉记忆。
教学全部走「页面内信号」，载体三件套全部复用已有组件：

| 载体 | 实现 | 复用来源 |
|---|---|---|
| 消息窗 | HUD 第二行（徽标/焦点摘要行）被教学消息**优先占用**：前缀 ◆ 区分，≤14 字单行，完成或换轮后淡出 | docs/10 §1.1 双行 HUD；battle 稿的金银式消息窗文案风格（02 §4.5） |
| 高亮引导 | 四角括号放大 + 呼吸（选中态语言，零新增动效）；每轮最多亮一个目标 | 02 §1.3 零成本清单 |
| 音频反馈 | **不新增教学音**——买棋响 caught、羁绊跳档响琶音，动作自带的音效就是「做对了」的反馈（08 §2.4 UI 音挂动作结果） | docs/08 §2.4 |

四铁律（一票否决级，与 docs/10 §5 红线同权重）：

1. **一条一轮**：每个准备期最多一条教学消息，教一件事；下一条不进场，
   上一条不重播（完成位图置位）。
2. **非模态**：教学永不拦截输入、永不独占屏幕。玩家可以做任何已解锁的事，
   教学消息只是「亮着的路标」。
3. **操作即确认**：完成标志 = 玩家做出对应动作（买了、摆了、刷了），
   消息立即淡出；没有「下一步」按钮，没有确认弹窗。
4. **跨局持久**：完成位图入局外档，老玩家永不再见（§2.5）。

教学的听觉仪式：教学局 R1-R5 准备期 BGM 用 `elmslab`（博士实验室=有人在教你），
R6 起 转 `goldenrodcity` 标准曲——「毕业」不用文字说，换曲即毕业
（08 §3.1 备用曲行已预留「教程」场景，此处兑现）。

## 2. 教学局与前 5 轮脚本

### 2.1 教学局定义

| 项 | 裁定 | 依据 |
|---|---|---|
| 触发 | 局外档 `tutorial_state==0` 且 `career.matches==0` → 开新局前一次性页面：「新手引导？A 开始 / B 跳过」（两项字母直达，C 无效反馈；B 空着不合惯例故两项占 A/B） | PokeWalk S11 先例：一次性流程由存档存在判定跳过 |
| 跳过 | B → `tutorial_state=2`，直接标准局；此后永不再问 | 同上（按任意键跳过先例） |
| bot 池 | 教学局 = **4×L1 + 2×L0 + 1×L2**（标准局 3×L1+3×L2+1×L3 的降档版），整局静态不回调 | docs/03 §4.1 L0 定位原文「前期沙包，教学期对手」；局内不动态调节不违反「无 rubber banding」（那是局内动态，此处是局型静态配置） |
| 重看教学 | 系统菜单（准备页 B~）加一项「重看新手引导」→ `tutorial_state=1`，**下一局**生效（当前局已过教学轮，重放无意义），菜单行文案「下一局重现引导」 | 系统菜单已为光标式 >3 项（docs/10 §2.3） |
| 中断续打 | 门控 = 纯函数 `tutorial_gate(round_no) → 允许动作集`，恢复后由当前轮直接推导，**单局档零新增字段**；完成位图在局外档 | docs/09 轮边界快照天然支持 |

### 2.2 门控矩阵（仅教学局生效；标准局全解锁）

| 动作 | R1 | R2 | R3+ | 门控实现 |
|---|---|---|---|---|
| 买棋（Z4 商店格 C） | ✅ | ✅ | ✅ | — |
| 开战（[战▶] C） | ✅ | ✅ | ✅ | — |
| 拿起/放下/交换 | ✗ | ✅ | ✅ | 灰置 + 无效反馈（闪+短震），不解释 |
| 卖出（拿起态 B~） | ✗ | ✗ | ✅ | 同上 |
| 刷新 / 买经验 | ✗ | ✗ | ✅ | 同上 |
| 信息页（羁绊/图鉴/战绩） | ✅ | ✅ | ✅ | **从不禁锁**——只读信息无害，R5 才高亮教学 |
| 战斗页调速 | ✅ | ✅ | ✅ | — |

- 灰置项按 C 走标准「失败操作零副作用」路径（红闪+抖动，docs/10 §5-5），
  摘要行**不**追加解释文案——R2/R3 的开场消息自然预告「本轮解锁什么」，
  两条消息说同一件事就是噪音；
- 锁定顺序的教学逻辑：先会买再会摆（买了自动上场，docs/10 §3.1 落点判定）、
  先会摆再会卖（R1-R2 没有卖出动机：人口不满、不缺钱）、金币四用途 R3 齐活
  （乐趣支柱 1「每轮至少一个真决策」从此开始运转）；
- 经济自洽性核对：R1 开局 `START_GOLD=2` 恰好买一只 1 费棋（人口 3），
  刷新 2 金买不起——**经济本身已把 R1 的选择空间压到「买棋」一件事**，
  门控只是把 UI 灰置与经济事实对齐（`sim/economy.py` 常量）。

### 2.3 逐轮脚本

| 轮 | 解锁 | 教学点 | 消息窗文案（原稿） | 高亮目标 | 完成标志 |
|---|---|---|---|---|---|
| R1 | 买棋+开战 | 花钱买兵→自动打架，本作最小闭环 | ◆ 买一只宝可梦 | Z4 商店首格；买入后转亮 [战▶] 钮 | 完成 1 次买入 + 按 C 开战 |
| R2 | 摆位 | γ 双击轴：单击竖移/双击横移/C 拿放 | ◆ C 拿起棋子 重新摆放 | 场上棋子（四角括号） | 完成 3 次拿起-放下（与手势退场阈值一致） |
| R3 | 刷新/经验/卖出 | 金币四用途：抢棋 vs 刷新 vs 升人口 vs 存款吃息 | ◆ 刷新商店 或 买经验 人口+1 | [刷2] 与 [验4] 钮 | 执行刷新或买经验任一次 |
| R4 | （无新解锁） | 三合一进化=升星，本作核心差异机制 | （无固定消息；T4 进度提示见 §3） | 无固定目标；T4 触发时亮该棋子合成进度 | 首次进化演出播放完成 |
| R5 | （野怪轮+羁绊面板） | PVE 无损奖励；羁绊=同系凑数有加成 | ◆ 野怪来袭 击退有赏 | [羁] 徽标（HUD 行 2，教学消息让位给徽标高亮时消息移入战斗结算横幅） | 打完首个野怪轮（进羁绊页不强制） |

战斗阶段不教学（观战本身零输入）；R2 起战斗页的调速教学不设文案——
A/B 调速在 4x/跳过刚需出现前不需要被知道。

### 2.4 R4 裁定：演出即教学，不等待不造假

三合一是本作卖点（00 §0），理想教学 = 玩家在 R4 亲手凑出第一只进化。
但商店序列纯 RNG（docs/03 §3 红线「不做逼氪式随机」），不保证 R4 恰好凑齐
三只同名。裁定：

1. **不等待**：R4 不设门控、不暂停脚本；T4（「再买 1 只皮卡丘即可进化！」）
   在首次出现 2/3 进度时触发（docs/10 §3.1 已定），首次进化演出在哪轮发生，
   教学就在哪轮完成——**演出本身就是教学**（2.5s 光球 + 面板跳变 + `evolve`
   音效 + `evolution` 曲，全复用，02 §1.3 / 08 §2.4）；
2. **不造假**：不为教学做伪进化演出或保底商店扭曲；
3. 兜底：到 R8 仍未发生 2/3 进度（概率极低），摘要行重发一次 T4 后永久退场。

### 2.5 手势教学 T1-T6 收编

docs/10 §3.2/§3.3 已定义 T1-T6（手势类：成功 3 次后永久退场，进度入存档）。
本文将其收编进统一编号空间与统一位图（§3）：手势类触发挂「首次事件」
（首次拿起、首次双击……）而非固定轮次——教学局与非教学局都生效
（老玩家换新设备也会遇到首次拿起）。轮次脚本（§2.3）与手势文案的分工：
轮次脚本教「做什么」，手势文案教「怎么按」，同一轮最多出现各一条
（消息窗优先级：轮次消息 > 手势消息，手势延到下一空闲摘要帧）。

## 4. 局结算页

### 4.1 布局（240×320，像素账闭合）

│ 3 你     Lv6 火④  ◀     │  本行高亮；C 展开该行详情（终局阵容+统计）
│ 4 …                     │
│ … 8 …                   │
├────────────────────────┤
│ 败于 小茂（水④）R14 -17 │  败因 2 行 = 40px
│ 最大威胁 小茂 累计-46    │

- 淘汰即进此页时，排名 1-4 位可能未定——未定行显示「对战中」，

- 名次表行内「主羁绊」= 该训练家 `synergy_formed_type`（sim 已有），
  未成型显示最高计数属性；你自己的行展开态追加关键统计（§4.2 下表右列）；
- BGM = `pokemoncenter`（08 §3.1「最终名次/图鉴/战绩」行已定，兑现）。

### 4.3 三键模型

| 键 | 动作 |
|---|---|
| A / B | 名次表上一行/下一行（首/末行钳位） |
| C | 展开该行详情（终局阵容前 3 只 + 关键统计）；再 C 收起 |
| B~600 | 返回上一上下文（主菜单或战绩页） |
| A/B/C 在出口条 | 字母直达：A 回放（进 §6.2 回放页）/ B 战绩（进 §6.1）/ C 再战（直接开新局，见下） |
| C~1.5 | 熄屏 |

「C 再战」无确认弹窗的裁定：局终时单局档已清、上一局已入 recent（docs/09 §5
生命周期），再战不销毁任何数据；误触代价 = 新局里 B~ 退回菜单（新局档保留可续）。
不违反「不可逆操作必有确认」红线（docs/10 §5-8）——没有东西被逆。

## 5. 淘汰体验：观战 vs 直接结算

### 5.1 裁定：名次先行，观战降级为播报

取舍表：

| 方案 | 优点 | 缺点 | 裁定 |
|---|---|---|---|
| 淘汰后完整观战剩余轮（实时渲染 bot 战斗） | 决赛圈有观赛价值 | **破坏省算设计**（bot 对 bot 不渲染是 docs/03 §1 关键省算）；被淘汰者被迫看别人打 5-15 分钟 | ✗ 默认否决 |
| 淘汰直接踢结算+主菜单 | 快 | 丢掉「谁淘汰你之后走多远」的叙事；单局档生命周期悬空 | ✗ |
| **淘汰演出 → 局结算页（名次即时锁定）→ 快进播报（可跳）** | 名次先落袋；播报串行 ~1s/轮看完结局只需十几秒；想细看的人走回放 | 决赛圈的实时情绪弱一些 | ✅ 定稿 |

### 5.2 快进播报模式

- 进入：淘汰演出（低钟音 + BGM 停 + 低两音，08 §2.4/§3.1 已定）→ 局结算页 →
  出口条此时显示「C 快进看结局」；
- 画面：轮简报串行——每轮一行，格式复用 `match.py::_fmt_events` 语义：
  「R16 小茂 vs 阿桔 → 阿桔 -9」「R20 淘汰 阿桔（第 4 名）」，~1s/轮，
  有人淘汰时该行停 2s + 低钟音；
- 交互：C 跳到局终；播放完毕自动回局结算页（名次补全刷新）；
- 省算本质：播报走解算器裸跑结果（同 seed 已算完的事件），**不渲染任何 bot 战斗**
  ——与 docs/03 §1「bot-vs-bot 不渲染，只在战绩页回放事件流」同一纪律。

### 5.3 深度观战选项（决赛圈）

剩 2 人时（`championbattle` 起）播报页追加一行「B 完整观战决赛」：
按 B 切入实时渲染的决赛圈战斗（bot 战斗临时渲染，一次性、该轮该场）。
默认不进——想学决赛圈阵容的人的进阶入口，且尊重 08 §3.1 决赛圈情绪阶梯
（进了就给完整视听：championbattle 曲 + 1x 慢放，docs/03 §1 决赛圈行）。

### 5.4 败因提示

两行结构（结算页 40px 区）：

```
败于 小茂（水④）R14 -17      ← 淘汰轮：对手名 + 对手当轮主羁绊 + 该轮掉血
最大威胁 小茂 累计-46          ← 全局：掉血溯源第一名的对手与累计值
```

数据实现：`damage_taken_by` 在 `_pvp_round` 掉血结算时按对手 seat 累积
（events 元组现含对手名与存活数，加一个 attacker 引用即可）；对手主羁绊 =
对手当轮 board 的最高计数属性（`synergy.py` 现成计数）。文案纪律：
陈述事实、不安慰不评判（「你的阵容缺乏控制」这类 AI 点评不做——
设备上没有篇幅，且容易说错，见 §8 否决项）。

## 6. 战绩历史与对局回顾

### 6.1 战绩页（recent[8] 摘要）

局外档已定 `recent[8] = 8 × (seed u32, rounds u8, rank u8)`（docs/09 §5，
「战绩页回放入口」原注释此处兑现）。N=8 定稿：与存档字段对齐，不扩容。

```
┌────────────────────────┐
│ 战绩                  12 局│  24px 标题（12 = career.matches）
├────────────────────────┤
│ #2 27轮 决赛圈          │  8 行 × 24px：名次 + 轮数 + 阶段标签
│ #5 21轮 中期            │  阶段 = 轮数对 STAGE_FACTOR 边界推导
│ #8  9轮 前期            │  （≤8 前期 / 9-16 中期 / ≥17 后期，
│ …                       │   打满 31 轮另标「打满」）
├────────────────────────┤
│ 生涯：3胜 7次前4 27轮/局均 │  生涯摘要 = career 四字段
├────────────────────────┤
│ C 回放此局   B~ 返回      │
└────────────────────────┘
```

生涯行 = `career (matches/wins/top4/rounds)` 直出（docs/09 §5 已定）；
「放弃进行中对局」的口径沿用 docs/09 开放问题 2（未定前暂不计胜、计局）。

### 6.2 回放页（游戏内三键模型）

回放 = 「一场已经知道结局的战斗」，按键模型完全复用战斗页（零新学习成本）：
入口链 = 战绩页选局 → C 展开该局轮列表（重演产出的 round 简报，同 §5.2 格式）
→ C 进该轮全屏回放。页面栈：战绩 → 回放（替换式入栈，栈深仍 ≤2，
docs/10 §4.4）。

| 键 | 回放页动作 |
|---|---|
| A / B | 降速/升速（1x/2x/4x/跳过，同战斗页） |
| C | 暂停/继续 |
| B~600 | 返回轮列表（回放是只读信息页，返回合法——区别于真对局战斗页的 B~ 红线） |
| C~1.5 | 熄屏 |

验收后台播放器（`/anim?seed=N`）与游戏内回放的功能分工：

| 功能 | 验收后台 | 游戏内 | 说明 |
|---|---|---|---|
| 播放/暂停 | ⏯ | C | — |
| 单步 0.1s / 60ms | ←→ | ✗ | 验收工具，不是玩家功能 |
| 倍速 0.5-4x | 按钮 | A/B | 玩家档位收敛为战斗页同款四档 |
| 进度拖拽 | 拖拽条 | ✗ | 设备无指针；「选轮」即选起点 |
| 事件流面板同步高亮 | 右栏 | ✗ | 240px 装不下；战斗画面即信息 |
| 保存 PNG | ✓ | ✗ | — |

重演边界（docs/09 §2.3 兑现）：回放从 master_seed 只读重演，
`rules_fp` 不一致时该局回放入口**灰置**（摘要行仍可看，不整行隐藏）；
重演不触碰共享池与任何存档状态。

## 8. 被否决的方案

| 方案 | 否决理由 |
|---|---|
| 弹窗式教学（模态分步引导） | 每步打断操作流；要教的正是连续操作肌肉记忆（γ 拿放），弹窗教的姿势到了实操全忘；三键上「下一步」按钮徒增按键 |
| 独立教学关（打木桩/沙盒关卡） | 自走棋的教学价值在真实经济压力下的决策；木桩关教不出「利息 vs 抢棋」；多一个局型多一份维护 |
| R4 强制触发进化（商店保底/送棋） | 违反「不做逼氪式随机」（docs/03 §3 红线）；被送的一局与真实一局手感不同，教学反而失真 |
| 图文手册/帮助长文页 | font16 在 240px 上一屏 ~15 字，长文不可读；三键翻页地狱 |
| 教学进度每局重置 | 老玩家第二局起被重复打扰（docs/10 §6-5 已倾向跨局，本文定稿确认） |
| 淘汰后强制完整观战 | 破坏 bot 战不渲染的省算设计（docs/03 §1）；被淘汰者罚看 5-15 分钟 |
| 淘汰直接踢回主菜单 | 名次虽定但结局叙事断裂；单局档清理时机悬空（docs/09 §5 要求「观战完」） |
| AI 败因点评（「你缺乏前排」） | 小屏无篇幅；静态规则生成的点评容易说错；事实两行（谁/什么羁绊/多少血）已够复盘起点 |
| 战绩存终局快照供复盘 | docs/09 §9-5 已裁定：只存 seed 进 recent[8]，复盘走只读重演，不占 NVS |
| 回放页做事件流面板/单步/拖拽 | 验收台富控件是开发形态；玩家回放复用战斗页按键模型即零学习成本 |
| 教学完成配音效（叮/欢呼） | 与动作自带音效叠成噪音；违反「音效挂动作结果」（08 §2.4） |

   验收后台的帧管线原型验证）；

## 11. 开放问题

1. 教学局 bot 降档配比（4×L1+2×L0+1×L2）的实测量：教学局玩家平均名次
   是否落在 3-5 名（有点甜头但别碾压），读数超标则调 L0 数量；
2. R2 完成标志「3 次拿起-放下」是否过严（玩家摆 2 次就懂了）——
   真机走查后可降为 2 次；
3. recent[8] 无时间戳：玩家分不清「昨天那局」与「上周那局」——是否值得
   加 u16 日戳（schema 变更，docs/09 §4 追加区可吸收，但会挤 reserved）；
4. 深度观战决赛圈（§5.3）默认值：不进（当前定稿）vs 剩 2 人时自动进
   ——真机看情绪收益与打断感；
5. 教学局是否给「毕业奖励」（如首局通关图鉴标记）——倾向不做
   （教学不是成就，避免为奖励而跳教学的歧义），待成就系统（S17 对位）定稿再议；
6. T1 文案 14 字内能否真正教会 γ 双击（本文案「A·B 上下　快按两下左右移动」
   已是压缩极限）——若真机走查不通过，教学局 R2 追加一次可重放的
   「手势演示动画」（光标自动演示双击横移，非交互），成本一次演出；
7. 播报模式一行简报的停留时间（~1s/轮）在淘汰密集局（多轮双亡）的节奏
   ——实测定 0.8-1.5s。
