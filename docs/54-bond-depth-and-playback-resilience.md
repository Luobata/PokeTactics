# 羁绊战法扩展与对战回放恢复

本轮回应两个问题：羁绊选择少、效果多是面板加成；战斗画面播放到一半停止。

## 羁绊设计

目录从 21 条扩展到 25 条：17 条属性基础 + 8 条战术。保留侵蚀、连击、守护、鼓舞，增加四条按当前形态属性决定成员资格的战法。

| 羁绊 | 门槛 | 实际收益 | 配队取舍与反制 |
| --- | --- | --- | --- |
| 寒脉 | 2 / 3 个冰家族 | 同目标最近5秒内三次有效直接生命损失，令其行动间隔增加15% / 20%，持续3秒；每来源每战最多4次 | 需要持续集火；转火、护盾和击杀来源可拆条件。不占异常位，不属于可净化异常 |
| 魂缚 | 1 / 2 个幽灵家族 | 直接伤害使成员从55%以上降至55%或以下且存活时，束缚1格内攻击者1.2秒 / 2格内1.5秒；每成员每战一次 | 近身压迫需付出停步代价；远程消耗和致命爆发可绕过。束缚限制移动，不是眩晕 |
| 脑波 | 2 / 4 个超能家族 | 完成本命后，为2格内最近、能量未满的另一名超能队友回3 / 5能量；受益者冷却3秒、每战最多3次 | 邻近布阵换轮转，容易受范围攻击和击退影响；满能量与无合适队友不消耗次数 |
| 龙威 | 1 / 2 个龙家族 | 有效本命主命中后，标记10%易伤3秒 / 12%易伤4秒并影响目标邻格敌人；每来源每战最多2次 | 后续输出需要跟进窗口；分散站位、护盾和控制龙成员可反制 |

超能基础回能从10% / 20%降为5% / 10%，给脑波留出预算。其他属性基础暂保留。新战法只消费真实结算结果，不发起额外攻击，不递归触发本命链；强效果不会被弱效果覆盖。

家族池每项羁绊按家族去重，进化形态的实际属性决定资格：伊布未进化时没有脑波，太阳伊布可以加入；青绵鸟进化成七夕青鸟后才能加入龙威。图鉴分别显示家族数与可用形态数，补充玩法、搭配、反制，并提供八条战术的真实对战预览。

图鉴与对局共用合法成员目录，并随每条羁绊下发物种到家族的映射。历史战报从实际参战形态按这份映射去重，避免同族多形态虚增门槛，也避免遗漏家族池新增形态；旧物种池保持原计数口径。

寒滞、束缚在回放显示有期限的标记；减速/束缚次数与伤害、回能分开统计。新增控制统计只在实际产生控制时出现，紧凑战报使用版本2；旧报告继续保持原形状与版本1。

## 回放卡死与恢复边界

后端原来的明确故障窗口是：帧生成恢复过一次后，线程再次停滞或退出但没有错误文件，状态检查会无限返回“生成中”。缺帧图片还会各自等待12秒，叠加请求和图片重试后画面长期停在中间。

后端将渲染状态划分为生成中、就绪、不可恢复，提供已生成帧数、总帧数、心跳和排队状态。帧端点最多短等1秒，暂缺返回425，完成后真缺帧返回404。后台绘制限制为两路并发，登记并清理工作线程，停止无界重建。绘制失败不影响已经结算的战果和奖励。

首次明确崩溃可使用留存参数重建一次，再次失败进入终态。任务启动前同步发布排队心跳；声明渲染归属与删除旧目录共用线程锁及跨进程文件锁，最终检查与删除在同一锁内完成，避免清理误删刚启动的回放。清理争锁失败直接跳过；有存活进程声明归属的目录即使心跳过期也保留。此锁实现使用 POSIX `fcntl`，覆盖当前 macOS/Linux 本地服务。

前端以健康状态和有限预载窗口驱动回放；失败时可重新读取画面或直接查看已结算战果。动作请求超时后需要继续存档确认结果，避免自动重发购买、开战或奖励动作。

渲染状态请求5秒超时，连续3次失败或180秒无进度即提供明确恢复入口；手动重试重新计时。等待过程中保留拖动目标和播放意图，画面就绪后继续。关闭回放取消图片请求、健康查询和重试定时器，缓存上限为桌面72帧、窄屏36帧。

## 验收范围

验证包括：真实命中边界、控制期限和回卷、实际羁绊场景、图鉴家族计数、旧档研习保留、紧凑战报往返、渲染失败/停滞/排队、前端中途断帧恢复，以及隔离存档的整局模拟。测试文件和前任完整对局 fixture 一起提交。

2026-10-17 验证结果（分组存在交叉，不相加）：

- 竞技规则回归：709 项通过。
- 最终前端回放与战报：35 项通过，包含请求超时、断帧恢复、重试期限、关闭取消、家族去重与历史回合口径。
- `python3 -m unittest tests.test_deferred_render`：21 项通过，包含扫描与删除之间本地线程、真实外部进程抢占渲染归属的确定性并发用例。
- 页面、回放契约、存档、HTTP、迁移、表现、侦察和目录集成：52 项通过。
- 真实家族池整局模拟：10/10 完成、1130 场战斗、0 错误、10/10 存档往返一致，研习层数无超限；证据见 `docs/evidence/bond-depth-family-n10.json`。
- 浏览器实测：完整播放、重播、暂停、收起再打开、服务重启后恢复战果，并进入第2轮；截图见 `docs/evidence/bond-depth-catalog.png` 和 `docs/evidence/bond-depth-restored-result.png`。

这些验证证明机制与恢复路径可用，不代表竞技胜率已经完成长期平衡。后续应依据成型成本、各羁绊出场率和对局数据调整数值。
