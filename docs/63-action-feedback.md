# 63 · 操作反馈层

日期：2026-11-15。问题：购买伙伴、装备、学技能、选择棋子等操作后几乎没有反馈；且每次操作服务器要 0.9–2 秒才返回，期间页面没有任何变化。

## 1. 响应速度
`state_json` 每次都会重复计算羁绊成员关系（`arena_bonds.memberships` 每次刷新约 7 万次调用）。该结果只取决于物种，现已缓存：一次操作的状态刷新从约 0.9–2 秒降到 0.15–0.3 秒。规则行为不变（arena_v1 逐事件指纹对账一致）。

## 2. 反馈层（`tools/acceptance/play_feedback.js` + `play_feedback.css`）
- **按下即响应**：`api()` 开始时在点击处画一个“处理中”金色框和小转圈，服务器返回后移除；它挂在独立浮层上，不会被页面重绘清掉。
- **结果对比**：返回后比较操作前后的状态，在变化发生的位置播放反馈：

| 变化 | 反馈 |
|---|---|
| 新伙伴加入（购买、选秀、速成） | 精灵从商店卡飞到备战席落点，绿圈 +「+ 名字」 |
| 出售 | 原位置精灵淡出下沉，「+N 金」 |
| 移动 / 上场 / 回到备战席 | 蓝色落点圈，跨区时提示「上场」「回到备战席」 |
| 装备 / 第二装备位 | 装备标签从道具卡飞到宝可梦身上，紫圈 +「◆ 装备名」 |
| 卸装 | 装备标签飞回「背包」入口，入口弹跳 |
| 学会技能机 | 靛色圈 +「学会 技能名」 |
| 技能强化 | 金圈 +「本命强化 · 名称」 |
| 设为/取消核心 | 金圈 +「♛ 成为核心」 |
| 升星 | 沿用原三合一聚合动画 |
| 金币变化 | 状态栏数字滚动、弹跳，「±N 金」 |
| 买经验 / 升级 | 「+4 XP」；升级时屏幕中上方金色横幅「升级！Lv.N」 |
| 合成 / 拆解 / 出售装备 / 组件入库 | 在点击处提示，并飞入或弹跳「背包」入口 |
| 刷新 / 定向刷新 | 商店卡依次发牌入场 |
| 锁店 | 锁按钮弹跳 +「已锁定 / 已解锁」 |
| 选海克斯 | 金色横幅「获得海克斯 · 名」，徽章飞入已选条 |
| 换一批海克斯 | 候选卡重新发牌 |
| 战术指令 / 模拟 | 状态栏对应标签弹跳发光 |
| 失败 | 点击的控件左右抖动，红色提示；不显示任何成功效果 |
| 其他无可见状态变化的成功操作 | 点击处绿圈 +「✓」，保证每个操作都有反馈 |

- **选择状态**：选中棋子、商店卡或道具时有一次弹起动画；选中的棋子/格子保持呼吸发光（备战席改为内描边，避免被容器裁掉）。
- **声音与震动**：开启音效后，不同操作有不同短音（买、卖、装备、学习、升级、选择、错误）；触屏设备有轻微震动。
- **减少动态**：系统开启“减少动态效果”时不飞行、不抖动，只保留淡入淡出的文字与静态光圈。
- 底部提示条加了 ✓ / ! 图标。

## 3. 扩展
新操作只要通过 `api()` 发出，就会自动获得“按下即响应 + 成功 ✓ / 失败抖动”；若要专门效果，在 `after()` 中按前后状态差异添加一段即可（`float / ring / bump / fly / banner` 已导出到 `window.PlayFeedback`）。

## 4. 验证
- `tests/test_play_feedback.py`（含 `tests/frontend/play_feedback.js`）：购买、装备、学技能 + 核心 + 升级、无状态变化的操作、失败、只读命令。
- 浏览器实测截图：`reports/evidence/action-feedback-2026-11-15/`。

## 5. 卡顿优化（2026-11-15 第二轮）
- **精简返回**：准备阶段的操作请求带 `lite=1`，服务器不再重复返回静态目录（物种 / 特性 / 羁绊目录）和其他 7 位训练家的侦察数据，只给自己的那一行和一份卡池剩余数；前端 `mergeLite` 与上一份完整状态合并。单次操作响应从约 785KB 降到约 100KB。下一轮、开战、续玩等仍返回完整状态。
- **避免重复计算**：保存外层原先会在动作执行后再算一遍完整状态，现在只算一次。
- **前端**：请求进行中不再整页重绘（只切换忙碌样式）；棋盘威胁连线的几何计算挪到下一帧，与绘制共用一次排版；音乐引擎不再在玩家第一次点击时同步创建。
- 实测（同一台机器）：双击买伙伴从点击到出现在备战席 650ms → 约 400ms，最长阻塞任务 243ms → 96ms；单纯选中 108ms → 56ms。

## 6. 操作流程
- **双击 / 连点**：商店卡双击直接招募；备战席宝可梦双击按定位自动上场（防守→前排、远程/辅助→后排、其余→中排，从中间列开始找空位），场上宝可梦双击回到备战席；人口已满时抖动并提示。
- **即时动画**：招募与移动在点击时立即播放飞行动画（不等服务器），原格子上的宝可梦变淡；结果返回后只补落点光圈和文字。
- **战斗后推进**：关闭战斗回放（× 或 Esc）直接进入下一轮准备阶段，并弹出“第 N 轮 · 准备阶段”横幅；需要回看可在“战报”面板打开上轮战果。页面重载停在战斗阶段时，底部按钮仍为“查看战斗回放”。
