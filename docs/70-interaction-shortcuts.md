# 70 · 交互快捷：右键菜单、再点取消、预览与新手引导

试玩反馈三条：右键菜单完全没用上；选中后再点一次应该取消选中；查看详情太费劲，新手不友好。
本篇把这三条落到准备阶段（代码：`tools/acceptance/play_context.js`、`play_preview.js`、`play_guide.js` 及同名 `.css`，
`play.js` 的选择规则与 `ctx.actions`）。所有操作仍走 `ctx.api`，乐观渲染（docs/66）和操作反馈（docs/63）照常生效。

## 1. 右键菜单 / 长按操作单

打开方式：

| 设备 | 打开 | 关闭 |
|---|---|---|
| 桌面 | 右键；或聚焦后按 Menu 键 / Shift+F10 | Esc、点外面、滚动、窗口缩放 |
| 触屏 | 长按 450 ms（移动超过 10 px 视为拖动/滚动，取消） | 点遮罩或「取消」 |

- 桌面是指针旁的小菜单，竖屏手机是底部操作单，横屏手机是右侧操作单（不挡棋盘）。手机操作单顶部带预览卡（见 §3），长按即可读完整信息。
- 键盘：↑↓ 移动，Home/End，Enter/空格执行，→ 进入子菜单，← / Backspace 返回，Esc 关闭并把焦点还给原来的格子，Tab 关闭。
- 有子菜单的条目（装备…、学习技能机…、放置备战席精灵…）在同一个菜单里切换，带「‹」返回。
- 客户端能判断的限制（阶段、金币、装备位、人口、备战席空位、核心需在场上）一律显示为**灰色条目 + 红色原因**，点击只抖动、不请求服务器。
- 长按松手产生的那一次点击会被吞掉，不会顺手点到刚滑上来的操作单，也不会选中/购买；长按后浏览器原生拖动被取消。

### 菜单内容

| 对象 | 条目 |
|---|---|
| 我方精灵（棋盘 / 备战席） | 详情 · 上场（→ 最佳空位，注明前/中/后排）或 下场到备战席 · 选择技能强化（待选时） · 装备…（成品装备列表，配装顾问的推荐排第一并标「最佳」，其余按携带者排名） · 卸下装备 / 卸下第二装备（深度版注明金额） · 觉醒（可觉醒时） · 学习技能机…（只列能学的；注明仓库数量或金额、推荐；进入确认单，替换不返还的提示保留） · 设为核心 / 取消核心（深度版） · 出售 +N 金 · 取消选择 |
| 商店卡片 | 购买（注明升星） · 购买并上场 · 详情 · 锁定商店 / 解除锁定 · 刷新商店 · 取消选择 |
| 敌方精灵 | 侦察详情 · 查看对手整队 |
| 背包装备卡 | 装给 X（推荐携带者中第一个有空位的，直接装上） · 选择携带者…（进入点亮可装伙伴的选择模式） · 觉醒 · 拆解 · 出售（深度版） |
| 技能机卡 | 学给 X（推荐） · 选择学习者… |
| 棋盘空格 | 把 X 放到这里（已选中精灵时） · 放置备战席精灵…（子菜单，直接放到这一格） · 一键上场 |
| 备战席空位 | 把 X 撤到这里（已选中棋盘精灵时） |

其他位置不拦截浏览器原生右键菜单。

## 2. 选择规则

同一规则适用于精灵和商店卡片：

1. **单击选中**；选中后有高亮（`selected` + `aria-pressed`），提示行变成信息条（§3）。
2. **隔 300 ms 以上再点同一个 = 取消选中。**
3. **300 ms 内连点两下 = 双击执行**：备战席精灵上到最佳空位、棋盘精灵回备战席、商店卡片直接招募。不管之前是否已选中，双击都执行。
4. **Esc**、操作条的 ×、详情里的「取消选择」随时清空选择；焦点停在刚点的格子上时 Esc 也有效（之前会被按钮焦点拦下）。

为什么是 300 ms：自己计时而不用系统 `dblclick`，因为格子重绘会打断原生双击，而系统双击间隔最长 500 ms，会把「看一眼再点掉」的慢速再点吞成双击。刻意双击两次点击通常相隔 100–250 ms，再点取消通常在 400 ms 以上，300 ms 两边都有余量。原规则中「再点已选中的商店卡片 = 购买」改为只在双击时购买，避免误买。

其他可选中的东西也遵守「再点取消」：

| 对象 | 再点一次 |
|---|---|
| 敌方精灵（打开侦察并高亮） | 关闭侦察、取消高亮 |
| 侦察面板里的精灵 / 最近实战 | 收起详情 / 统计 |
| 对手列表里的训练家 | 关闭侦察 |
| 背包装备「选择携带者」、技能机卡 | 退出选择模式（原有） |
| 海克斯徽章、合成图格子 | 关闭说明单 |
| 背包类型筛选、图鉴角色筛选 | 回到「全部」 |
| 底栏 / 侧栏入口、天气胶囊 | 收起面板（原有） |

## 3. 预览、信息条与术语表

- **预览卡**：一个复用的浮层 `#pv-card`。桌面鼠标悬停 300 ms（术语 150 ms），键盘聚焦（`:focus-visible`）同样显示；触屏对没有操作单的对象（羁绊、海克斯徽章、天气/地形/指令胶囊、术语）长按显示并钉住，再点任意处关闭。不重绘任何区块、不发请求，数据全部来自已有的 state。
  - 精灵（我方 / 商店 / 敌方）：名字、星级、费用或价格、属性、定位、近战/远程与射程、本命技能、学习技能、特性、携带装备、羁绊，以及文中出现的关键词解释（最多 3 条）和本对象的快捷操作提示。
  - 装备：类型、用法、属性条、效果、觉醒、推荐携带者；技能机：说明、可学属性、推荐；海克斯；羁绊各档门槛（已达成高亮）；天气、地形、战术指令。
- **选中信息条**：棋盘下方的提示行在选中精灵或商店卡时显示「名字 · 本命技能说明 · 特性 · 装备」，右侧小字给出当前可用快捷（双击上场、再点取消、右键更多、Esc）。不用打开抽屉就能读懂它做什么。窄横屏（< 760 px 宽）原本就隐藏提示行，此时用长按操作单。
- **术语表** `PlayGlossary`：一份共享字典（灼伤、中毒、麻痹、冰冻、睡眠、畏缩、定身、易伤、湿润、护盾、击退、嘲讽、净化、封疗、吸血、闪避、溅射、本命技能、学习位、技能机、能量、特性、羁绊、共鸣、觉醒、双持、核心、海克斯、技能强化、升星、三合一、共享池、人口、利息、连胜、连败、天气、地形、射程、近战、远程、三种定位），带别名（原生技能→本命技能 等）。
  - `mark(text)` 转义文本并把每个术语第一次出现处包成虚线下划线的 `.gl-term`（可聚焦，悬停/聚焦/点按显示解释）。
  - `decorate(root)` 在绘制后（rAF）给精灵情报、确认单、羁绊、侦察、海克斯卡片等已有文字加术语标记；跳过按钮、链接、`summary` 等控件，同一面板每个术语只标一次，「近战/远程/射程」在面板里不标。

## 4. 新手引导

- 五步，指向真实控件：招募伙伴（商店卡片，抽屉关闭时指向商店入口）→ 上场布阵（备战席）→ 三合一升星 → 装备道具（背包入口）→ 开始战斗（开战按钮）。
- 首次进入准备阶段、没有海克斯/选秀/确认单/弹窗时，延迟 600 ms 自动开始；高亮框可点穿，玩家可以直接照做，前两步做到后自动进入下一步。
- 每步可「跳过引导」，Esc 也会关闭；完成或跳过都写入 `localStorage["poketactics.play.guide"] = "done"`，以后不再自动出现。
- 重看：HUD 右上角「?」按钮（`#guide-button`），或玩法指南弹窗里的「重看新手引导」。
- 自动化浏览器（`navigator.webdriver`）不自动开始，避免挡住其他验收脚本；`?guide=1` 强制自动开始，`?guide=0` 关闭。

## 5. 性能与接入

- 点击 → 可见的路径不变：选择仍只切换 class（docs/66），信息条是一次带记忆的 `innerHTML` 写入；术语装饰放在 rAF 里。
- `play.js` 每次渲染调用 `PlayContext / PlayPreview / PlayGuide.render(ctx)`；`ctx.actions` 提供 `selectUnit / selectShop / selectEquip / clear / quickPlace / bestBoardCell / buyAndPlace / autoDeploy / openEnemy / openScout / openDetail / toast`。
- `PlayInteractions` 新增 `target(kind, key)`（进入装备/技能机选择模式）、`learn(key, uid)`、`equip(key, uid)`（确认单）和 `openMods(uid)`（技能强化二选一）。
- 三个脚本放在 `play_interactions.js` 之前加载，保证它们的捕获阶段监听先于选择模式的点击拦截运行；样式放在 `play_motion.css` 之前。

## 2026-11-21 调整（按推荐方案）

- **右键装备 = 直接装上 + 免费撤销**：菜单里的「装备…」不弹确认，装上后底部出现 5 秒「撤销」条。
  服务端规则：紧接着装备的下一个操作如果是卸下同一件，不扣卸装金币（`demo._last_equip/_undo_equip`）；中间做过别的操作则照常扣费。学技能机仍走确认（替换不返还）。
- **棋盘预览不挡棋盘**：棋盘上的单位悬停 650 ms 才出卡片，卡片放在棋盘左右外侧；已选中单位或正在装备时不弹（选中信息条已经显示）。商店、面板里的预览不变（300 ms）。
- **术语数值**：灼伤、中毒、麻痹、冰冻、睡眠、畏缩、护盾、核心、连胜/连败、利息、能量、觉醒、天气已对照 `sim/status.py`、`sim/economy.py`、`sim/arena_depth.py`、`sim/arena_item_synergy.py` 校正为准确数值。
