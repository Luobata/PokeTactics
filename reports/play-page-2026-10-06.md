# PokeTactics 全新试玩页

试玩入口：[http://127.0.0.1:8799/play](http://127.0.0.1:8799/play)。
使用原有经典对局内核，从零设计了森林棋盘、商店、训练家状态、备战席、羁绊、装备、指南和战斗弹窗。
购买、移动与交换、出售、经验、刷新、锁店、合成和装备都通过原有动作 API；浏览器不另行计算金币或战果。
真实战斗帧按六个并发请求预载，支持暂停、倍速、查看战果和下一轮。
支持自动存档、恢复、备份下载、淘汰后观战及最终排名；新的浏览器存档编号与旧 `/demo` 页面分开记录。

新增 `/play`、`/play/` 和两个固定资源路由，保留原有验收后台、`/demo`、存档和战斗 API。
首次进入从第 1 轮开始，结束浏览器实测后已重新创建第 1 轮对局供用户试玩。

## 验证

- 新路由 4 项测试通过：页面/资源 MIME、内容、无缓存、nosniff、未知及穿越资源拒绝；访问页面不创建会话，旧入口保持可用。
- 原有游戏动作合同 15 项测试通过。
- 单种子整局回归及同种子重放通过：两局均推进到第 31 轮，28 场玩家战斗、7,264 帧、66 种精灵图和 515 次成功 HTTP 请求。覆盖 10/12 个动作，出售、卸装未被该回归采样覆盖；出售另由浏览器实测验证。
- 浏览器验证：空场提示、购买、点击布阵、一键上场、经验购买、出售、锁店、刷新解锁、真实战斗、2×速度、查看战果、下一轮、刷新续玩、战斗阶段存档恢复的无帧提示、指南及新局确认/取消。
- 浏览器连续完成 12 轮真实对局，验证淘汰后第 8 名结果、观战快进、完整八人最终排名及重新开局。交付页面已重置到第 1 轮、100 HP、7 金币和空阵容。
- 1280px 桌面及 375px 手机布局检查通过；没有横向溢出，手机版指南和经验购买均可操作。新页面控制台无错误。
- JavaScript 语法、Python 编译、HTML ID 唯一性及 diff 空白检查通过。
- 独立代理对 play.js、server.py 和 README 的静态审查未发现阻断问题；HTML/CSS 和浏览器行为由主代理验证。

## QualityGate 范围

本地 CLI 返回 `gate=pass`、`raw_gate=pass`、`block_merge=false`、`execution_complete=true`、`quality_confidence=full`。
`incomplete_engines=[]`，有效阻断、shadow、advisory、deferred、waived 及修复数量均为 0。
`agent_action=local_checks_passed`；未匹配当前文件的脚本规则，因此此结果不能代替 JavaScript/Python 功能验证或中央语义评审。
Mutation 没有启用、实际未执行；本 CLI 对当前非 Go 范围返回 `mutation_status=not_applicable`。
本任务未暴露 QualityGate 中央 MCP，预编辑规则上下文、双层中央语义评审和反馈均不可用，未宣称其通过。
独立静态审查与本地浏览器实测不等同于中央 QualityGate 语义门禁。

## 保留边界

没有修改模拟器规则、原有存档格式或旧页面。使用现有本地宝可梦素材和自行绘制的 SVG 森林，未添加游戏框架依赖。
后端仍需要原有 Python/Pillow 及兄弟项目像素素材；此交付为本地可玩页面，未发布到外网。
字体有 Google Fonts 声明，无法联网时使用本地字体回退。操作音效为默认关闭的 Web Audio 提示音。
当前浏览器实测没有覆盖装备卸下和原生拖动手势；这些路径分别复用原有 API，已作静态检查。
