# 第七批：配队取舍、技能机库存与三键操作

本批将强度目标改为“不同配队有用处、有应对成本”，不要求物种单挑胜率一致。已交付三键 host 入口、普通棋子技能机教学与两项远征规则修正；四队克制循环仍未达标，硬件输入仍未移植。

## 已实现

- `/device`：240×320 只读屏幕，A/B 上下、C 确认，长 B 返回，长 C 详情/睡眠。选行再选列替代双击补轴。覆盖远征配置、商店、摆位/交换、卖出确认、道具合成/使用、教学、羁绊、侦察、挑战图鉴、真实战斗回放、结算和淘汰观战。
- 按键手势抽到 `esp32_runtime/input.py`，不依赖宝可梦规则。长按释放不补短按、醒来后整次手势被消费、转场消隐、失焦取消和断网先取消再读状态。未知结果的提交不自动重试。GPIO 去抖与唤醒驱动未实现。
- 每只持有棋子有稳定 uid 和一个教学槽。移动、读档保留；进化继承首个兼容教学，其余返还。卖出返还技能机，替换要确认，重复或不兼容教学不扣库存。提交时同时验证 uid 和存档序号。
- 开局选定的招式归开局搭档；随后购买的同族不会被免费复制教学。远征野怪轮每个参战席位掉一台机器，普通棋子按属性学习；机器人获得相同掉落。永久解锁决定开局携带资格，局内拾取独立。
- 局内 schema 3 保存 uid/技能机/教学与对手教学快照，兼容 schema 1/2。旧家族教学迁移到一只持有棋子，家族已售出则返还仓库，迁移只执行一次。
- 远征耿鬼舌舔改为 65 威力、较高攻方轴，优先干扰射程内高能量目标；普通系免疫与偷能边界保留。远征聚光镜用开场 40 能量交换旧 25% 大招增伤，提供有成本的启动选择。经典规则保留。

## 强度读数与剩余工作

[完整组合报告](build-diversity-2026-10-05.md)保留原四队与失败样本：24,000场为12,000个成对试验（换边不作为额外独立样本）。阵营交换失败0，但突进原阵型对其他三队全占优，幽影原阵型没有优势对手。

已有可操作取舍：幽影前后排互换对花园胜率12.5%→67.5%，代价是对突进23.3%→0%；三镜幽影对突进升至41.7%，仍未形成优势。没有把改动包装成全局平衡完成。

后续验收优先级：

1. 用同一批队伍和独立种子验证有成本的前排保护/控制选择，解决突进对脆弱后排持续占优；不能靠删除失败队伍、增加装备数量或换种子得到通过。
2. 真机三键长按/误触/操作时长、GPIO去抖、休眠唤醒、NVS容量和写寿命、240×320阅读性与刷新性能。
3. 首次体验引导、海克斯/天赋、天气决策、更多教学内容与专属动作仍按独立工作包推进。本批未认领这些系统完成。
