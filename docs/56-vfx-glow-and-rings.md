# 技能特效公共层：辉光与地面环

日期：2026-10-18。接续「前20个上场宝可梦技能特效审美复核」，先做公共层，让所有技能同时受益；逐招重做另批进行。

## 复核结论（前20只）

按 `ROSTER` 顺序取 26、68、31、76、40、12、34、94、59、73、36、45、6、65、9、80、3、121、95、106，用真实渲染器截普攻与本命技能关键帧。

- 较好：6、94、80、73、76，有实心体积与命中爆发。
- 线条感重：26 链电是细锯齿线；65 只有一对括号弧；121 是珠串加 2px 描边椭圆；12/45 是点串加小十字星；36 几乎无主体；40 的粉色条块过大且遮挡队友。
- 通病：描边椭圆环像UI选框；护盾泡泡在 2× 下只剩一圈虚线、各技能一样；普攻命中只剩几个色块，余韵很短。

## 本轮改动

| 改动 | 位置 | 规则 |
|---|---|---|
| 共享辉光 | `retro_primitives.bloom`，`WebBattleRenderer._render_frame` | 技能动作、命中强调、大招爆发与结果层先画到同一透明层；只取亮度>70的像素，3px格上扩散、4档量化、上限150透明度，铺在特效下方。单位、数字和HUD不受影响；只处理特效包围盒，本机帧耗时约+3ms。 |
| 地面环 | `retro_support._ring` | 描边改为25% Bayer抖动地面片＋前半圈亮唇；填充只占近半个地面，不遮身体；仍满足接触cel只用不透明像素。 |
| 护盾泡泡 | `retro_support.draw_dome` | 加厚整圈边缘、下半深色层与左上高光弧，地面环改为实心底盘。 |

不改模拟、事件、时序或受击归属；只改呈现。

## 验证

- `tests/test_vfx_bloom.py`：空层/暗层不发光、亮核外溢且不改原层、3px整格与4档上限、环为不透明抖动地面片。
- 全量 `python3 -m unittest discover -s tests -q`：1691项，剩余2项失败（`test_item_recipes` 图表、`test_unified_presentation` 路由）在未改动的HEAD上同样失败，与本轮无关。
- 前后对照：`reports/evidence/vfx-glow-2026-10-18/before-after.png`、`floor-patch.png`；截图脚本 `capture.py`。

证据为PC渲染目视，不等于独立美术验收或ESP32真机性能。
