# 25 · 进化方向复核：保留还是移除

2026-10-05。范围：只复核现有 84 只关都形态，不引入二世代；复核时未改 `sim` 实现。本文是按用户要求重新权衡后的**建议**，不把本次结论表述为用户已选定的方案或新的产品裁定。
证据读取顺序为交接文档、24 号当前合同、22 号联动评审，以及当前 `economy` / `shop` / `roster` / Demo 保存与动作代码。本文只写设计结论，不把候选数值当作已交付平衡。

## 结论

**建议当前游戏保留进化，但把它从“自动面板跳升”继续推进为“有预告、可暂缓、职责明确的形态决策”。** 这个结论不是因为已经写了很多代码；删除现有进化并不能关闭当前最明确的问题：自然终局不足、反制不成熟、AI 只会近似 BST/羁绊估值、四项局外挑战太快耗尽。相反，现行 84 形态池与经济入口是相互咬合的：34/32/18 的费档分布给 1–7 级商店提供了早期、中期、后期供给；三合一与通信石已经是共享池、装备、教学、UID 和存档账本的一部分。

保留不是无条件放行。当前进化只有少数形态发生可读的职责变化；自动三合一会减少人口和羁绊计数；重复终形态没有成长用途；训练、暂缓进化、转训和训练退款账均未实现。下一步应先做**合成前后预览与暂缓/锁定形态**，再做实例训练账。移除进化只保留为独立规则原型，不能直接替换现行规则或旧档。

## 1. 事实与冲突核对

### 1.1 现行实现

- 卡池是 84 只形态，不是 84 个家族：1 费 34 / 2 费 32 / 3 费 18；每物种 22/18/12 张，8 人共享，抽取时先预留（`sim/shop.py:30`、`sim/shop.py:75`、`sim/shop.py:118`）。
- 买入价等于形态 BST 档位；卖出价是累计投入 −1；三合一把三个来源账和目标形态并入新的 `sources`，卖出/淘汰时全部归还（`sim/shop.py:93`、`sim/shop.py:175`、`sim/shop.py:224`）。
- 普通族凑三只同图鉴号立即自动合成；目标形态无库存则整笔等待；终形态不再合成；勇基拉/豪力/鬼斯通不走三合一，唯一通道是进化石（`sim/shop.py:182`、`sim/shop.py:207`、`sim/shop.py:212`）。
- 合成保留第一个实例 UID，继承一件装备，兼容教学优先继承，多余装备/教学回仓（`sim/shop.py:226`）。
- 玩家购买会先在深拷贝上预演容量和合成，失败购买不落盘；成功购买后立即调用 `combine_player()`（`tools/acceptance/demo.py:1249`、`tools/acceptance/demo.py:556`）。
- 通信石每局限一次，触发后变成不可卸下的 `evo_stone`，同时占用目标形态一张池（`tools/acceptance/demo.py:1401`）。
- 现行保存 schema 4 逐棋子记录 `sources`、`invested`、UID 和教学，解码时校验来源账，不能从当前物种反推出合并历史（`tools/acceptance/session_save.py:50`、`tools/acceptance/session_save.py:151`）。
- `tactics_v2` 只给九尾日照、拉普拉斯降雨两个固定入场特性；六尾没有该特性（`sim/abilities.py:12`）。

静态核对当前 roster：47 条直接进化边中，38 条改变费档，13 条改变射程/属性/招式这类可读行为，二者并集 41 条；另有六尾→九尾是在 `tactics_v2` 获得入场特性。这说明进化确实存在，但多数主要仍是强度/费档跳升。上游另有一条同预算“鬼前排＋阵型”探索：对突进有优势、对花园和控场弱。该读数只说明**岗位和站位可以压过 BST**，是探索信号，不计入已交付强度结论。

### 1.2 文档冲突与裁定

1. **伊布分支**：旧 S2 写“三只伊布弹出三选一”，但当前 `next_evolution()` 固定取最小子形态水伊布，`try_combine()` 也直接合成水伊布；24 号与代码一致地承认真三选一尚未实现。以 24 号和代码为准。
2. **自动合成与拒绝**：S2 曾倾向不提供拒绝；24 号把暂缓/锁定列为未实施。这不是数值冲突，而是设计状态更新：当前代码确实无法拒绝。
3. **经济/商店历史文档**：S4 写 5 格商店和 R1-8/R9-16/R17+ 掉血阶段；当前代码是 4 格商店、R1-10/R11-19/R20+（`sim/shop.py:28`、`sim/economy.py:47`）。评估以当前代码和 24/交接优先级为准。
4. **训练语义**：22 号 D09 给出训练、补差价、转训、退款设计；24 号明确这些未实现。当前 `OwnedPiece` 只有 `invested` 购棋/合成投入，没有训练本金字段，不能把 D09 当作已交付。
5. **“最终形态”称呼**：当前 37 个无子形态中有 19 个是 2 费、18 个是 3 费；3 费并不等于全部终点，也有无进化成品棋。移除方案不能简单“只保留 3 费”，否则早期商店没有 1 费供给。

## 2. 两种连贯设计

### A. 保留进化：形态经济与转型游戏

**游戏哲学**：玩家先买便宜、可上场的幼年/中段形态，用重复卡解决“这局如何走到核心”；进化时接受一次明确的职责/属性/位置变化。进化的价值不是“多一层数值”，而是把收集、转型和队伍人口压在一个决策里。终形态之后再通过实例训练继续投资，而不是用同名卡自动升星。

- **成长叙事**：低费形态是过程资产，中段形态可先上场，三合一后变成更高费/不同职责的目标。
- **核心张力**：三只同名卡会减少上场人口、羁绊计数和备战位；玩家要用更强的形态或更清晰的岗位换掉这些即时价值。
- **长线身份**：一个 UID 可以从低形态、教学和装备一路继承到终形态；训练若实现，也应绑定这个实例，而不是给账号永久数值。

**具体例子**：三名六尾合计 3 金，目标池有九尾时自动合成。合成品落到备战席，保留第一只的 UID，若其中一只学会晴天且九尾兼容则教学继承；六尾本身没有入场特性，九尾部署后按 `tactics_v2` 在开战申请 8 秒日照。这个例子同时展示收益（1 费过渡变成三费天气手）和代价（三个单位变成一个，羁绊计数和站位空间减少；合成后仍需部署才触发特性）。

### B. 移除进化：主角直售与星级游戏

**游戏哲学**：商店里出现的就是玩家最终要使用的英雄。玩家从第一天就知道自己追的是哪张卡；三张同名卡升 2 星、九张升 3 星，升级不改变身份。进化动画最多作为升星演出，不再承担规则。这个方向优先解决目标可读性和重复终卡用途，适合“英雄单体设计”而不是“形态收集”。

一个不引入二世代的可行原型应显式重造卡池，不能直接取当前全部 37 个叶子：当前叶子没有 1 费，直接沿用会让 1–2 级商店无牌可抽。应从 37 个关都终点中选约 28 个，重新分成 1 费开局位 / 2 费中坚 / 3 费旗舰，并按“一人追三可达、两人同行可行、三人争抢才枯竭”重设张数。进化石可改为星级护符：把一个 2 星棋升到 3 星，保留每局一次的稀有通道语义；具体星级倍率、张数和费档必须另行实验。

**具体例子**：九尾直接作为 2 费主角出售，商店目标就是九尾而不是六尾。买到 3 张合成 2 星九尾，共 9 张合成 3 星；所有星级都保留日照特性，改变的是生命/输出等实例强度。若拿到星级护符，可将一个 2 星九尾升 3 星。这个例子目标清楚、重复卡有用，但费档、九张可达性和星级强度都未定，不能宣称平衡。

## 3. 逐项比较

| 维度 | A. 保留进化 | B. 移除进化，直售＋星级 |
|---|---|---|
| 进局/成长 | 34 张 1 费给 R1–R2 提供可用棋；中后段有 2/3 费和三合一目标。现有升级、利息、刷新与人口已经同池竞争。 | 需要重分费档。目标更直观，低费“开局英雄”必须真的可上场；星级倍率决定成长是否可读。 |
| 招募经济 | 共享池和 `sources` 已能表达三张基础卡＋一张目标卡的竞争；AI 已给复制件加分。 | 牌池缩小会显著提高指定牌命中率，必须重设张数和等级概率，否则追牌过容易或三星不可达。 |
| 重复卡 | 三张非终形态是进化材料；重复终形态目前只能再上场或卖出，没有自动升星。训练是候选，不是现状。 | 同名重复卡成为主要后期资源，天然有追卡目标；但转型时未合成副本更容易变成沉没成本。 |
| 战术职责 | 47 条边里 13 条改变射程/属性/招式，六尾→九尾增加特性；鬼前排探索也说明岗位/阵型重要。需要更多这样的显式职责差。 | 每张英雄从买入起职责固定，教学/装备/星级改变强度；更容易解释，但会失去形态换职责的决策。 |
| 转型灵活性 | 低/中段形态能当过渡，但自动合成可能提前丢人口或羁绊；预览/暂缓是必要补丁。 | 直售英雄便于换核心，但已投入的同名星级资产不易迁移；需要卖出/转训类补偿。 |
| 局长 | 训练或星级都能增加后期消费，但当前第九批 32 局仍有 25 局 R31 强制排名，说明进化本身不是局长答案。 | 星级追卡可能延长或加速局长，取决于掉血和三星可达性；仍须独立做终局实验。 |
| 三键负担 | 现行自动合成没有额外按键，但也剥夺拒绝权。合成预览/暂缓必须走 A/B 选择、C 确认、长按 C 详情，不新增第四键。 | 规则更容易讲；仍需星级合成预览、资源不足/过期目标处理和星级护符确认。 |
| 离线重玩 | 形态线、图鉴发现和路线差异更适合本地横向解锁；但当前只有四项挑战，保留进化本身不自动给长期目标。 | 28 英雄更容易逐只做档案、旅程和挑战；若只删进化而不补横向内容，重玩内容反而变少。 |
| 迁移成本 | 暂缓/预览需新增持久状态和原子事务；训练需新增实例本金账。现有 schema 已保存来源账，改法可分批。 | 需重造 roster、商店概率/张数、星级战斗字段、AI 估值、进化石、UI、测试和存档规则。现行含非终形态的存档不能静默迁移，只能旧规则继续或整笔映射为新局。 |

## 4. 推荐与放行条件

### 4.1 当前主线：保留并补齐决策权

1. **先做合成前后预览与暂缓/锁定**。预览必须展示目标形态、UID/装备/教学继承、人口和羁绊变化、目标池余量；确认前不扣目标池、不移除材料。锁定状态要进保存和恢复，重复提交幂等。
2. **按职责而非 BST 审计每条进化边**。指标至少包括费档、射程、属性、招式、固定特性、常用站位、人口/羁绊损失、合成前后同预算胜率。上游鬼前排探索说明同预算阵型候选可能对突进有效但对花园/控场弱，这类多对手结果才可比，不能只看面板。
3. **再决定实例训练**。训练必须解决真实付款、免费奖励本金、跨费档补差价、材料折损退款、转训、卖出封顶和旧档不凭空获得练度。没有这些账本前，不为“终形态有用”拍强度数值。
4. **重复终形态先保留现有语义**：可另上场或卖出。只有当真实整局数据显示重复卡频繁变成无选择垃圾，才进入训练或移除原型的强优先级。

### 4.2 移除原型的启动门

只有同时出现以下证据，才值得开独立 `finals_v0`：

- 职责审计显示多数进化边只是 BST 跳升，补预览/岗位后仍不能形成可读取舍；
- 重复终形态在完整真人/代操作局中长期无有效用途；
- 玩家无法从商店目标理解当前形态线的终点；
- 愿意接受 28 英雄池、星级、张数、AI、装备通道和存档规则的独立重造。

该原型必须新规则新对局，不改旧档；至少 100 个独立完整局种子比较成型率、转型次数、局长、存款、自然终局和同行争池。不通过前不得替换现行 84 形态池。
