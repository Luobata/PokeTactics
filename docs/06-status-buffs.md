# 06 · 状态与 Buff 系统（概念设计，2026-09-13）

状态：**概念稿**。S1 的「状态招式轻量化」升格为独立系统——
减益六种 + 增益五种，全部复用现有结算维度，少发明新机制。

## 1. 减益（六种，来源 = 对应属性招式命中）

| 状态 | 效果 | 来源属性几率 | 时长 | 宝可梦依据 |
|---|---|---|---|---|
| 灼伤 | -0.8%/s DOT + 物攻 -10% | 火 30% | 6s | 经典灼伤 |
| 中毒 | -0.5%/s 递增 DOT（每秒 +0.2%） | 毒 35% | 8s | 剧毒递增 |
| 麻痹 | 攻速 -30% + 每 3s 停顿 0.4s | 电 25% | 8s | 麻痹 |
| 冰冻 | 眩晕（不可行动） | 冰 12% | 1.2s | 冰冻（短而强） |
| 睡眠 | 禁锵 2s，受击即醒 | 超能 20% | 2s | 催眠术 |
| 畏缩 | 行动停顿 | 受击 8% | 0.3s | 畏缩（打击感调味） |

**免疫规则（宝可梦常识 = 免费的可学习性）**：火系免疫灼伤、毒/钢免疫中毒、
电免疫麻痹、冰免疫冰冻——知道属性表就懂谁怕什么。

**防连锁控制**：同一单位被冰冻/睡眠/麻痹控制类命中后，5s 内对控制类免疫
（递减），杜绝无限连控。

## 2. 增益（五种，来源 = 招式/羁绊/道具）

| Buff | 效果 | 时长 | 来源 |
|---|---|---|---|
| 光墙 | 全队特防 +30% | 8s | 超能系招式/羁绊 |
| 反射壁 | 全队物防 +30% | 8s | 超能系招式 |
| 剑舞 | 自身物攻 +25%，可叠 2 层 | 持续 | 格斗系招式 |
| 蓄气 | 下次大招必定最高浮动 | 持续 | 一般系招式 |
| 降雨 | 水系伤害 +15%（微型天气） | 6s | 水系齐射（docs/04 联动） |

上限纪律：每单位同时 **1 减益 + 2 增益**，后进先出——小屏可读、结算有界。

## 3. 棋盘特效语言

| 状态 | 单位身上 | 图标（6×6，底座上方） |
|---|---|---|
| 灼伤 | 精灵底部橙红渐隐粒子（2 个/帧） | 火苗点（橙） |
| 中毒 | 紫色 tint 呼吸（隔帧 15%） | 骷髅点（紫） |
| 麻痹 | 偶发黄色电火花点 | 闪电点（黄） |
| 冰冻 | 白色 tint + 完全静止 | 雪花点（白） |
| 睡眠 | 「Z」小字上飘（2×3 像素字） | Z 字（蓝） |
| Buff 类 | 底座外圈对应色细环（金=剑舞、蓝=光墙） | 右上角色点 |

DOT 跳字：小号（scale 1）绿色/紫色数字，不与伤害数字同帧同位（复用伤害数字
的避让逻辑）。所有状态图标集中在底座上方一条 6px 图标带，最多 3 个并排——
**看一眼棋盘就知道全场谁在烧谁在冻**。

## 4. 事件流与结算

- 新事件：`(t, "status", unit_idx, kind, apply|expire)` ——渲染端零特判（宪法 2.6）；
- 结算维度全部现成：DOT 走 tick、攻速走 interval 乘区、防走减伤乘区；
- 确定性：几率判定走既有 rng 流，不新增随机源。

## 5. 开放问题

1. 几率表整体偏高/偏低？——与天气乘区一起进 sim 联合数值臂；
2. 睡眠「受击即醒」会不会让 BOSS 战太简单；
3. 图标带的 6×6 图标是否够认（备选：状态色染血条端帽）。

## 6. 落地顺序

事件骨架 + 六减益 → 图标带/粒子渲染 → 增益五种 → 与羁绊/道具/天气联动标定。

## 7. 数值臂读数（2026-09-13）

实现 `sim/status.py`（开关 `STATUS_ON` 默认 False，桩接口不变），实验
`sim/experiment_status.py`，完整读数见
[reports/status-experiment-2026-09-13.md](../reports/status-experiment-2026-09-13.md)。
要点（回答 §5 的开放问题）：

1. **§5-1 几率表：维持 §1 原表，问题不在数字在来源频率**。状态只吃大招
   命中（普攻无属性），充能 ~5-6s vs 中位战斗 7.7s → 全场大招仅 ~3.6 次，
   压制面还有 91% 的命中直接击杀目标（死人无状态可挂）；五系减益合计
   0.07 次/场，几率 ×3 也救不动。联合重标挂 S5 招式系统接线
   （低威力高附加的状态招选择器）——压力臂标定量级上界：灼伤必中时
   DOT 占总伤 18.5%、时长仍持平。
2. **DOT 不拖场**：占总伤害 0.00%，时长中位 7.7→7.6s、最长 18.9→18.7s，
   离 MAX_BATTLE_SECONDS=45s 一个数量级，45s 线无需调整。
3. **连控被递减压住**：递减不变量（同单位相邻控制命中间隔 ≥5s）在
   DR 开的 200 场 × 常规/必中两臂中违反 **0 次**；DR 关时必中臂出现
   136 对 <5s 连控。递减保留——当前连控风险被大招低频掩盖，
   S5 接线后频率上升它是必要防线。
4. **新发现：冰冻来源不可达**。现池唯一 ICE 单位拉普拉斯带水炮
   （signature_move 取最高威力本系招，水炮 120 > 冰束 90），ICE 状态
   携带者 0 只、随机臂冰冻恒 0。修法归 S5 招式选择器或扩冰池。
5. **畏缩 8% 定位合适**：3.27 次/场（当前唯一高频状态）、对时长/胜率
   无可测影响——打击感调味的量级。
6. **增益 v1 免费施加上界**：光墙 +23pp / 反射壁 +33pp / 剑舞 +47pp
   （镜像局 45% 基数，t=0 免费施加的读数）；接线招式时按施放成本重标，
   剑舞（持续+叠 2 层）最需要收费。
7. **§5-2 睡眠受击醒的方向性回答**：15 次施加 13 次被唤醒——集火下
   近乎秒醒，BOSS 战「太简单」的担忧实为反向（太弱）；接线时若要加强
   可考虑受击后延迟醒或每场限醒一次。

翻默认（STATUS_ON=True）的前置条件：S5 状态招接线、冰冻来源可达、
渲染端 status 图标带——三者齐备后复跑两臂联合重标。
