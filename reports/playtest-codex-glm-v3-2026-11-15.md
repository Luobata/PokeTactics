## 三、新机制逐项评价

### 1. 战术指令：可用，且比站位单变量更有表达力

- **突袭**：G1 R1我方+50能量、对方突袭暴露约32，账本可审计；但受击代价在脆皮阵容中很直接。
- **稳守**：G1 R15挡96、R16挡202、R18挡306；G2 R19挡125。它是1★前排阵容的默认止损令。
- **断补给**：G2 R8估算143、R11估算102、R17估算175；G1 R20估算132。对手辅助≥2时价值很高。
- **护驾**：G1 R10起多次66盾；G2 R20/R21/R22为127/120/120。它针对威胁预览的“核心被锁定”信号，但相邻防守型嘲讽依赖正确站位。
- **集火**：G2 R22切换后模拟仍0/6，实战也败；对方无明显核心/残血收益时收益不稳定。

评价：指令已经能改变开战节奏，不再只是装饰。建议在战前显示敌方辅助/防守型数量与“本指令会命中的单位数”；否则断补给和护驾仍像半盲选。

### 2. 威胁预览：方向正确，但不是承伤预测

有效案例：G2 R16八名敌人全部预测1★青绵鸟；卖出青绵鸟、放入宝贝龙后，R18预测立即转为3★猫头夜鹰。玩家确实能据此调整保护对象。

边界案例：G1 R22把电灯怪移到雷丘旁后，9名敌人仍全部预测同一uid；实际稳守挡267并胜利。首轮目标预测可以是对的，但它不表达转火、穿透、范围与5秒累计承伤。

建议把 `threat.counts` 升级为两层：保留 `first_target`，新增每单位前5秒预计承伤区间、是否会被远程越过前排、以及“移动后已重算”时间戳。

### 3. 羁绊任务：真实目标，不再只是断点面板

G1电4长期激活但任务必须等实际收益：R14电弧1/3/27伤，R15 2/3/35伤，R17完成3/3；R24决赛电弧仍有2次/18伤。G2俯冲R5 2/3、R8完成3/3，账本R8 3次/88盾、R11 2次/83盾、R17 2次/29盾。

这个机制让断点从被动面板变成局内小目标。问题是对“还差什么才能触发”仍不直观：G1电弧多次因为有效普攻次数不足而0次，玩家只能复盘账本。建议任务条下加最后一轮 `trigger_count / needed_attacks / no_trigger_reason`。

### 4. 技能强化：成长选择仍然成功

- G1雷丘选3★“汲取”，R14治疗23、R15治疗48；R24决赛虽未触发，但前中期是续航关键。
- G2猫头夜鹰2★“迅捷”、3★追加“强化”，R17迅捷7次/175能量，溢流3次/67盾；R19溢流3次/176盾；R20护驾127+溢流150。
- 强化继承规则可读：3★猫头夜鹰同时保留迅捷与强化，没有出现上一轮的模糊感。

技能强化已经能定义同一棋子的不同玩法。建议给每个候选显示本轮阵容的预计施法次数区间，避免“迅捷”在短战斗里价值骤降。

### 5. 核心：保护信号与风险信号同时存在

G1雷丘核心是稳定主C；G2把核心从大舌头转移到3★猫头夜鹰后，威胁预览立刻把敌方火力集中到核心。R18核心承635、只打65；R20承974、盾201仍被击穿；R22承600、只打83。这说明核心加成只有在真实前排后面才能兑现。

建议在核心面板增加“当前被N个敌方首轮目标锁定；相邻防守型：有/无”的提示，把核心收益与暴露风险放在同一处。

### 6. 选秀、商店买性与经济

选秀卖0修复实际生效；G2 R19第3顺位拿飞天螳螂+专爱头巾，再买商店一只直接2★巨钳螳螂，是整局转折。传说限一提示已提前到商店卡。经济/经验条已能算出升级金，G2 R17用36金满级没有试错。

剩余问题是追星进度：商店卡只显示买入即升星或限一，未显示“当前2★ + 1★仍差2张到3★”。G2 R21我因此误判买入即可追3★。

### 7. 模拟：能纠错，但高压下像抽样器

正向：G2 R18/R20都0/6并实际大败；R19调整后6/0并实胜。
反向：G2 R17稳守0/6但断补给实胜；R21护驾1/5但实际险胜；R22两种指令都0/6。血量5时，1/5与0/6给出的信心完全不同。

建议：第一次模拟固定为当前真实对手和种子，输出8场或10场的胜负均值、中位存活数、核心预计承伤；第二次才做悲观样本。当前6场小样本在终局不足以区分“劣势”和“侥幸可赢”。

### 8. 定向刷新与拆解/出售

定向刷新同轮递增已生效：G2 R22首次3金、第二次4金。G1 R7用约21金完成3★雷丘，说明低费路线仍可行；R20继续追星未成，说明追加边际成本已上升。G2 R22两次定向飞行7金没有关键卡，也显示高方差。

拆解/出售闭环正常：G1 R9卖专爱头巾+2、黑暗鸦+0；G2 R11卖甘露坠饰+2并给七夕青鸟装专爱头巾，R14选秀棋卖0，R15盔甲鸟试后卖出，R22给火焰鸟装红围巾。装备转移依然是后期最重要的纠错手段。

## 四、新主导策略与伪决策

1. **低费定向3★没有死，但必须配质量兜底。** G1 R7完成3★后仍要买电击兽、电灯怪、急冻鸟、化石翼龙和金属怪；纯粹“9人口低费挂件”在R20后会被野怪斩杀。
2. **前排星级比3★远程更先决定生死。** G2 R18/R20/R22中3★猫头夜鹰被贴脸或远程越前排时输出骤降，1★铁哑铃/小锯鳄/化石翼龙不足以分担。
3. **“威胁全锁核心 + 护驾”是强读条组合，但要求防守型真的相邻。** 若只有攻击型前排，护驾只剩20%盾。
4. **断补给在辅助≥2时是隐性必选。** G2 R17对手有4辅助，模拟虽然0/6，实战175估算和胜率改善明显；无辅助局则应明确显示零目标。
5. **任务诱导出现局部伪决策。** G2伏击已2/3，但为了凑暗系而牺牲飞行/前排质量并不划算；系统没有提示“差1次且本队是否能触发”。
6. **高连胜经济不是无脑存钱。** G2理财专家提高上限，但R17-R22连续花36金升级、4金传说、7金定向仍未换到生存；说明低血时经济应转质量，而不是吃利息。

总体：1,014个动作的 `start <= release <= impact <= end` 全部正确；6场事件的表现时间均未倒退；效果链共578个显式索引，571个有效，**7个无效**。地形、双方队伍、死亡与状态快照完整，`result_time` 都早于总时长。

注意两类现象：

- 同一单位的“重叠”样本是主施法动作内锚定在其 impact 上的 secondary 命中，例如G1 R22动作290为 `cast`（6.80-7.60），动作295为secondary `attack`（7.40）。这不是玩家可见的两个完整动画窗口，但渲染器必须继续把它作为主动作 outcome 处理，不能再排一个独立攻击动画。
- G2 R17/R19的无效索引是实际缺陷。R17 t=2.6的 `sky_dive.absorb` payload `cast_index=166`、t=4.8的 `storm_chime.energy` payload `action_index=263`，都不在该脚本 `actions[].i` 集合中；R19 t=1.9 `cast_index=175`、t=6.05 `action_index=295` 同样缺失。

## 六、Bug、可疑问题与复现请求

### Bug 1：回放效果链存在孤儿索引

复现：

```http
GET /api/battle/script?sid=5df38c3c66ec&round=17
GET /api/battle/script?sid=5df38c3c66ec&round=19
```

遍历 `events` 中 `combo_effect/skill_effect` 的 payload，收集 `cast_index`、`action_index`、`source_cast_index`，与 `actions[].i` 集合求差。R17有4个、R19有3个不命中。渲染器文档说明这些字段应指向原始动作 `i`；当前部分效果只能走“同时刻/来源目标”回退，镜头和链式联动会丢失因果关系。

### Bug 2：威胁预览在移动后缺少重算标记，甚至疑似未刷新

G1 R22历史快照 `states/b82ad5c5b61b/22_prep_22_order_hold.json` 中，电灯怪已从 `g0,4` 移到 `g1,2`，但9名敌人仍全部预测 `u00000028`。它可能仍是合法的远程首目标，但API没有 `recalculate_at`、`confidence` 或“是否仅首轮”说明。复现思路：

```http
GET /api/demo/action?cmd=new&seed=31101
# 按log_game1.md推进到R22并做同一路径站位
GET /api/demo/action?cmd=state&sid=<新sid>&expected_sequence=<seq>
```

或在服务端增加按 `sequence 220-223` 的状态重放接口。建议至少输出“上次站位变更后是否已重算”。

### Bug 3：追星入口/进度可读性不足

G2 R17：

```http
GET /api/demo/action?cmd=move&from=b1&to=g0,0&sid=5df38c3c66ec&expected_sequence=<当时seq>
```

返回同名单位“交换”，不合成。G2 R21板上2★巨钳螳螂、备战1★飞天螳螂时，商店第3张买入后只留备战，`merge_note` 未提示距3★还差2张。这不是数值错误，但会让玩家在HP5时做出错误经济决策。建议商店卡显示 `base_copies_to_next_star` 和 `can_merge_now`。

### Bug 4：R20阶段野怪断崖

G2 R20我方9人口、3★核心、飞行4，仍被2★皮可西、3★胡地、2★/3★水箭龟打掉21血；G1连胜7后更是全3★。复现：

### Bug 5：模拟没有固定对手/种子

当前两局在生死轮出现0/6实胜、1/5实胜。复现方式只能按日志重建，因为模拟结果未暴露 `opponent_seed`、`opponent_seat`、样本版本。建议 `depth.last_simulation` 增加：

## 七、具体数值与交互建议

1. **模拟**：第一次固定当前真实对手，样本从6场提到8-10场；显示胜率、平均存活、核心预计承伤。第二次保持悲观样本。目标是在HP≤10时，玩家能区分“劣势”和“有机会”。
2. **威胁预览**：`first_target` 外新增前5秒预计承伤和远程越前排标记；站位变更后显示 `threat_recalculated=true`。
3. **追星**：商店卡增加 `base_copies_to_next_star`。若仍要压制低费路线，可按目标家族已购基础卡数递增：第1-3张3金，第4-6张4金，第7张起5金；定向刷新保留现有同轮+1。
4. **R20野怪**：将普通3★野怪延后到R21或改成一主C3星+其余2星；G2 R20总野怪生命约1,619，而我方1★前排生命144-202，保护窗口不足。
5. **断补给**：敌方辅助少于2时，商店/指令按钮显示“0目标”；命中2个以上时保持现值。G2 R17估算175说明数值不弱。
6. **护驾**：若核心相邻无防守型，按钮显示“仅有20%盾，无嘲讽”；避免玩家误以为护驾等于完整保护。
7. **羁绊任务**：任务条加上一轮触发数据，如 `2/4 effective attacks` 或 `no_target`。电4从面板强度改为任务驱动后，这一点比再直接加伤害更重要。
8. **回放**：修复7个孤儿索引；对无法绑定动作的全局效果，改用显式 `anchor:"global"`，不要填假索引。
9. **传说限一**：保留现有 `buyable:false/reason`；再把可买原因显示在价格旁，而不是只放在hover或API字段。
10. **选秀**：卖0已修复，无需再削弱；可进一步显示“该棋若当轮卖出，成品保留但棋子+0”的提示，减少玩家把修复误认为显示错误。

## 八、下一步最值得做的5件事

1. **把模拟从抽样器升级为战前沙盘**：固定真实对手、显示置信区间与核心承伤，这是终局体验最大短板。
2. **修复回放效果链孤儿索引**：7/578虽少，但会直接破坏浏览器因果编排和镜头链。
3. **补齐追星与威胁的可读性**：`base_copies_to_next_star`、威胁重算时间戳、预计承伤三处收益最高。
4. **平滑R20野怪曲线**：按玩家强度插值，避免9人口成型阵容在非连胜局被一次性斩杀。
5. **继续用多种子平衡低费定向3★**：本轮G1冠军、G2同类低费3★辅助失败，说明不是简单“过强/过弱”；需要统计追3★时间、花金、HP损失与名次分布，而不是单局削数值。

## 结论

第三轮改动整体是成功的：传说买性、选秀卖0、羁绊任务、战术指令、威胁预览、经验金、账本零触发和定向刷新递增都从“文档声称”变成了可复现数据。低费定向3★路线没有退化成不可用，而是需要质量兜底；飞行4/高费路线也不再稳赢，说明平衡方向比上一轮健康。

当前最需要收敛的不是新增内容，而是决策反馈的一致性：模拟高压局噪声过大、威胁预览边界不清、追星进度不透明、R20质量断崖、回放效果索引有缺口。先修这五点，arena_v2的深度系统会从“机制丰富”进入“可靠可玩”。
