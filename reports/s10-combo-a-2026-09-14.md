# S10 组合技 A（齐射）sim v1 · 2026-09-14

机制：docs/04-combo-moves.md §2.A 的推荐首发——羁绊凑到高阶阈值时，开战演出
一次该属性的组合招。本期只做**事件 + 数值**（渲染端的迷你特效串/切镜横幅是
后续项，图形语言已就位于 docs/02 §4.9）。默认 **COMBOS_ON=False**（S3/S11/S12
同模式），翻开待主线裁定。

## 1. 设计参数（sim/combo.py）

| 参数 | 值 | 依据 |
|---|---|---|
| 触发档 | 计数 ≥ **各系最高档**（现表 17 系全为 (6)） | 「最高档」统一规则；BUG 自定义档 (1)(2)(4)(6) 的最高档同样是 (6)，**虫系齐射按 (6) 适用**——(1) 起步只改低档补偿，不改仪式回报门槛 |
| 每队轮数 | **至多 1 轮**：够格系中计数最高者，并列按属性名序取先 | docs/04 §2.A 单数语义「该属性的组合招」；连发两轮的否决读数见 §3 附读 |
| 参与者 | 全队每只 1 发（含非该系单位——全员齐射是队伍仪式） | docs/04 §2.A「开场全员齐射」 |
| 目标 | 各自最近敌人（同 `_target` 的 (曼哈顿距离, idx) 键），并锁定为目标滞回起点 | 复用既有索敌语义 |
| 威力 | 各自**招牌招威力 × 40%**（无威力招按 BASIC_POWER=40 折算，保底 1） | 一发 ≈ 0.4×招牌 ≤ 一次普攻（BASIC_POWER=40），全队六发 ≈ 2-3 发普攻——「仪式感 > 数值」量级；任务书骨架值，扫频见 §4 |
| 属性/STAB | 弹性 = 齐射系（非使用者本系）；本系单位吃 STAB 1.5 | WATER(6) 的非水单位也放水弹 |
| 命中 | 必中（不掷命中/闪避骰）；免疫目标过减伤链可归 0 | 开场演出不吞 miss 反高潮；伤害随机骰（0.85~1.0）仍掷、走本场 battle 子流 |
| 能量 | 不回能不耗能（不走 ENERGY_PER_* 两通道） | 齐射是回报不是起手引擎，不加速大招循环 |
| 结算 | 复用 `_final_damage` 全链：克制 × 天气 × 羁绊乘区 × 大招承伤上限 × 减伤 × 装备乘区；气势披带照常救场 | 「每发命中走既有 attack 事件、复用结算链」的接线要求 |
| 事件 | `(0.0, "combo", team, 属性, 名称)` 一条 + 每发一条既有 `(0.0, "attack", atk, def, dmg)`（+ 可能的 sash/die） | 渲染端零特判（宪法 2.6），§4.9 图形语言直接续用 |

组合技名（占「招式名」，docs/04 §4.3）：电「雷霆万钧」/水「潮汐」/火「烈焰地带」
定稿自 docs/04 §2.A，虫「群虫踊击」定稿自任务书；其余 13 系为 v1 占位名（按
synergy 主题取义：万众一心/疾风阵列/千藤缠绕/瘴气领域/斗魂风暴/精神海啸/
岩壁崩落/大地激震/钢铁洪流/百鬼夜行/龙鳞风暴/极寒领域/暗夜降临），定稿随
渲染端横幅审。

现池可达性：凑 (6) 需 6 单位全员供该属性 → 水/毒/飞/普/草/火/斗/超/虫/岩/地
可达，电 5 种需重复 1 只；钢/幽灵/龙/冰/恶不可达 = 齐射天然跟随扩池解锁。

## 2. 接线（sim/combat.py，最小改动）

- `__init__`：裸 Piece 化的 comp 存 `self._plain_comps`（原 synergy 分支内
  计算上移，S5 装备二元组协议不变）；
- `run()` 开头（deploy 事件后、主循环前）`_opening_volley()`：按队迭代 →
  combo 指令 → 逐发结算。COMBOS_ON=False 时零执行、零 rng 消耗。

## 3. 实验读数（sim/experiment_combo.py，1000 随机 + 200×定向，seed=5）

S3 羁绊两臂恒开（默认已翻开）→ 读数差**纯归因齐射**。

| 臂 | 随机 A/B/平 | 带宽 | 时长中位 | 电(6) vs 零羁绊 | 齐射伤害占比 |
|---|---|---|---|---|---|
| C0 关 | 477/523/0 | 17.8% | 7.2s | 0% | — |
| C1 开 | 476/524/0 | 17.8%（+0.0pp） | 7.2s（+0.0s） | 8% | 定向中位 **6.0%** / 最大 **11.9%** |

- 随机局触发率 0.3%（3/1000：随机 6 人队凑满 (6) 本就是小概率）——随机臂
  本质是「不误伤」回归，读数全绿（带宽/时长/平局零位移；未触发的战斗逐字节
  不变，齐射只在触发局改变 rng 演化）；触发局单局占比中位 6.3%；
- 定向臂：齐射把 0% 的对位抬到 8%——仪式感回报成立、不翻对位（远离 50%）；
- **附读①（每队至多一轮的依据）**：连发两轮的中间版读数——隆隆岩×6
  （ROCK(6)+GROUND(6)）vs 零羁绊：占比中位 **47.5%**、场均 **2.4 个 t=0 击杀**，
  远超 12% 线 → 改为单轮后同对位回落到中位 16.0% / 最大 31.5% / t=0 击杀
  0.52 每场。**仍是当前最重对位**（地震 100 威力 + 地面克制面广 + 该局本就
  100% 碾压使总伤变小、占比膨胀），列为 v2 护栏候选（见 §5）；
- 附读②（互相抵消）：电 vs 电双触发，占比中位 10.3%、胜率 55%（对称），
  「开场双方都触发时互相抵消大半」成立。

## 4. 威力扫频（定向 150 场/档，选型依据）

| frac | 电(6)vs零 中位/最大 | 岩地vs零 中位/最大 | t=0 击杀（电/岩地） |
|---|---|---|---|
| **0.40（选）** | 6.0% / 11.9% | 17.7% / 29.4% | 3 / 81 |
| 0.35 | 5.4% / 12.0% | 15.2% / 25.8% | 1 / 62 |
| 0.30 | 4.7% / 9.9% | 13.3% / 23.3% | 0 / 62 |
| 0.25 | 4.0% / 8.5% | 11.2% / 20.5% | 0 / 54 |

健康线（≤12%）在**规定臂**（电(6) vs 无羁绊）上 0.40 即达标（最大 11.9%），
且保住仪式感的最小数字量级 → 取任务书骨架值 0.40。岩地最重对位全线越线
（0.25 才回 11.2%），降全局威力会误伤普通对位（电臂已只有 6%），故不做
全局下调、走 §5 的结构性护栏。

## 5. 开放问题与 v2 候选

1. **docs/04 开放问题 1（齐射时机）的数据回答**：定稿建议「t=0 结算 +
   渲染端在 0~0.5s 窗口内编排演出」，不做战斗性的 0.5s 延迟。依据：
   正常局首次出手中位 **0.1s**（起手抖动 0~0.3s + back 布阵远程首轮即射程内）、
   0.5s 前已有减员的局占 **25%**——推迟到 0.5s 齐射会插进真实交火读作
   「战斗中噪音」，且引入新的时序交错；而 t=0 结算读数温和（定向 200 局
   仅 6 只 t=0 击杀、双方齐射互抵后胜率对称），事件流把齐射排在 deploy
   之后、一切 move/attack 之前，渲染端可自由把特效串铺在节拍表 §4.6 的
   0.3~0.9 相位。不抢读图时间由渲染端控制演出时长（≤0.9s）解决，战斗学
   不需要为演出让位。
2. 岩地对位越线（§3 附读①）：v2 候选 =「每发 ≤ 目标最大 HP 的 x%」结构性
   护栏（与 synergy ult_cap 同家族，天然消灭 t=0 击杀）或按系调威力
   （地震类 100 威力招牌单独折算）。COMBOS_ON 默认关，不阻塞。
3. bot 不感知齐射（v1 纯战斗层，任务边界）：L2+ 摆位启发式若日后加
   「同系凑档偏好」，齐射的仪式回报自动成为可感知信号（docs/04 §4.4）。
4. 渲染端后续项：`combo` 事件的横幅 + 迷你特效串（§4.9 按属性复用）、
   可选短切镜「雷霆万钧！」；验收后台事件格式器加 `combo` 分支。
