# 组合技（协奏招式）概念草案 · 2026-09-13

状态：**概念设计，未实现**。回答「自走棋里该不该有组合技、长什么样」。
定稿后拆进 systems（S3 羁绊 / S5 招式与 AoE）并进 sim 验证。

## 1. 先回答：该不该有

**该有，但必须是「位置与羁绊长出来的组合」，不是「配方表」。**

反例（不要做的）：指定配对表（皮卡丘+妙蛙花=合体技）——自走棋是共享卡池的
随机商店，指定配对在实战里很难凑齐，凑不齐时玩家体验到的是挫败而非策略；
且 151×150 对的配方表在小屏上不可学习。

正例（要做的方向）：组合条件用**已有的公开语言**表达——同属性、同进化族、
相邻站位、能量状态——玩家看棋盘就能推理出「这两个摆一起会发生什么」。

## 2. 三个候选机制（可并存，推荐先做 A）

### A. 齐射（羁绊阈值触发）★推荐首发

凑齐羁绊高阶阈值时，**开场全员齐射一次**该属性的组合招（纯演出+一次性伤害/
增益，数值走 sim 平衡）：

- 电 (6)：开局「雷霆万钧」——全队向最近的敌人各放一道迷你闪电（复用棋盘
  迷你特效的电弧，§4.9 的图形语言直接续用）；
- 水 (6)：开局「潮汐」——前排获得护盾波纹（rings 图形）；
- 火 (6)：开局「烈焰地带」——中场线两侧 1 格灼烧（AoE 预警高亮直接用上 ④）。

- **为什么先做它**：触发条件就是羁绊计数（已有系统）、演出就是已实现的
  特效模式、数值是一次性开场事件（sim 里加一个开场结算即可）——
  工程与认知成本最低，且强化「凑羁绊」的核心循环。

### B. 协奏（同族/对偶属性 + 相邻站位）

同进化族两只（皮卡丘+雷丘）或**对偶属性**（火+水、电+地面）相邻站位、
且双方能量同时满时，普攻触发「协奏一击」：两格之间出现连接特效，
下次攻击合并为一次高伤（各 60% 能量，不放大招）。

- 站位博弈：相邻 = 强但怕 AoE/集火，给摆位增加新决策；
- 对偶属性是宝可梦知识（水火不相容却共鸣），可学习性好；
- 风险：相邻条件 + 能量同步的触发率需 sim 验证，可能太低——阈值先放宽。

### C. 承接（招式连锁）

单位 A 的招式命中后 1 秒内，**被克制属性**的队友大招伤害 +30%（视觉：
数字染承接色）。把「克制链」从静态知识变成动态节奏——你打水，我接电。

- 最轻量（纯数值+染字），但观感最弱，作为 B/A 的调味而非主菜。

## 3. 与现有系统的关系

| 系统 | 关系 |
|---|---|
| 羁绊（S3） | A 的触发器；组合技是羁绊高阶的「仪式感回报」 |
| 事件流（宪法 2.6） | 组合技 = 新事件类型（如 `combo`），渲染端零特判，复用 FX_STYLE |
| 棋盘迷你特效（§4.9） | A/B 的演出素材已就位（电弧/波纹/预警高亮） |
| AoE（S5） | A 的烈焰地带/B 的溅射是 AoE 的第一批真实用例，④ 预警钩子届时接线 |
| 平衡 | 全部走 sim：先做 A 的数值臂（开场齐射的伤害/护盾区间实验） |

## 4. 开放问题

1. 齐射时机：开局 0.5s 还是首个准备结束？会不会抢开场读图时间；
2. 协奏的对偶表：17 系的对偶关系全表（8 对 + 龙？）需要设计定稿；
3. 组合技要不要占「招式名」——建议有（雷霆万钧/潮汐/烈焰地带），
   演出时切镜横幅用它，多巴胺时刻 +1；
4. 单机 bot 会不会用组合技站位：L2+ 的摆位启发式需加「相邻同族偏好」。

## 5. 建议的落地顺序

1. sim 加 `combo` 事件骨架 + A 机制（电/水/火三系齐射）数值臂；
2. 渲染：齐射演出（迷你特效串 + 可选一次短切镜横幅「雷霆万钧！」）；
3. 平衡实验：羁绊 (6) 阈值带齐射 vs 不带，胜率带宽对比；
4. B（协奏）在 A 验证后再上。
